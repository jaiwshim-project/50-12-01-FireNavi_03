# 특허 명세서 P-D — 인프라프리 실내 다층 측위 시스템

> **출원 예정:** 한국특허청 (KIPO) | **국제출원:** PCT (12개월 내) | **발명자:** 심재우

---

## 발명의 명칭

**모바일 단말의 IMU·기압계·자력계와 기존 WiFi 인프라를 융합하여 신규 측위 하드웨어 설치 없이 실내 다층 위치를 추정하는 시스템 및 방법**
(System and Method for Multi-Floor Indoor Positioning via Fusion of Mobile Device IMU, Barometer, Magnetometer and Pre-existing WiFi Infrastructure without Additional Positioning Hardware)

---

## 기술분야

본 발명은 실내 측위 시스템에 관한 것으로, 더욱 상세하게는 **별도의 측위 전용 하드웨어(전용 BLE 비콘, UWB 앵커, 측위 전용 AP)를 설치하지 않고, 시설에 이미 존재하는 일반 WiFi 인프라와 사용자 모바일 단말 내장 센서(가속도·자이로·기압계·자력계)만으로 실내 다층 위치를 2~5m 정확도로 추정하며, 다수 단말의 집단 보정으로 1~3m 정확도까지 향상시키는 시스템 및 방법**에 관한 것이다.

---

## 배경기술

### 종래 기술의 한계

1. **GPS 실내 무력**: GPS는 실내·지하·선박에서 신호가 차단된다.
2. **전용 측위 인프라 비용**: BLE 비콘 망 또는 UWB 앵커 망 구축 시 시설당 $50~200K 비용 발생.
3. **단일 신호원 의존**: WiFi RSSI 단독 측위는 5~10m 정확도에 그치고, 다층 추적이 불가능하다.
4. **동적 환경 미대응**: 실내 무선 환경은 사람·금속·문 개폐로 신호가 변동하나, 종래 시스템은 정적 핑거프린트만 사용한다.

### 본 발명이 해결하는 문제

**시설에 이미 설치된 일반용 WiFi 인프라와 사용자 폰의 내장 센서만으로** 다음을 동시 달성한다:
- 개별 단말 2~5m 정확도
- 다수 단말 집단 보정으로 1~3m 정확도
- 다층(수직) 추적
- 동적 환경 적응

## 발명의 구성

### 1. 시스템 구성도

```
[Mobile Device]
   ├─ 가속도(Accelerometer)
   ├─ 자이로(Gyroscope)
   ├─ 자력계(Magnetometer)
   ├─ 기압계(Barometer)
   ├─ 마이크(Ambient)
   └─ WiFi Scanner (RSSI 수집)
        ↓
[Edge Server]
   ├─ WiFi 핑거프린트 매처
   ├─ IMU Dead Reckoning 적분기
   ├─ 기압 → 층 변환기
   ├─ 자력계 → 방위각 보정기
   ├─ 집단 그래프 SLAM 최적화
   └─ Kalman Filter 융합기
        ↓
[Output: (x, y, floor) ± σ]
```

### 2. 다중 신호원 융합

#### (1) WiFi RSSI 핑거프린팅
- 시설 내 일반용 AP 60~80개 활용
- 일상 사용자 데이터로 핑거프린트 DB 자동 학습
- 정확도: 5~10m

#### (2) IMU Dead Reckoning
- 가속도 적분 → 변위
- 자이로 적분 → 회전
- 단기(30초) 정확도: ±2m
- 장기 누적 오차는 WiFi로 보정

#### (3) 기압계 → 층 추정
- 표준 대기 모델: ΔP ≈ 12 Pa/m
- 층간 ~3.5m 높이차 → ~40 Pa 검출 가능
- 정확도: ±1층 (대부분 ±0.5층)

#### (4) 자력계 → 방위각
- 실내 자기 이상(rebar 등)으로 절대 방위 어려움
- 상대 방위 변화로 회전 추적 정확

#### (5) 마이크 → Acoustic Echo
- 객실/복도/홀 특성 음향 반사 차이로 공간 분류
- 보조 신호로 활용

### 3. 집단 그래프 SLAM 보정

```
N개 단말의 1차 위치 P_i ± σ_i가 있을 때:

(a) 단말 간 WiFi-Direct/BLE 신호 강도 측정으로 상대 거리 d_ij 추정
(b) 노드: 단말 위치, 엣지: 상대 거리 제약, 랜드마크: 알려진 출입구/엘리베이터
(c) 그래프 최적화 (Levenberg-Marquardt)로 전체 위치 동시 보정
(d) 결과: 개별 σ_i 가 σ_i / √K 로 감소 (K = 인접 단말 수)
```

이 단계로 **개별 2~5m → 집단 보정 1~3m** 정확도 향상.

### 4. 동적 환경 적응

| 환경 변화 | 대응 |
|----------|------|
| 사람 이동에 의한 신호 변동 | 다수 단말 합의로 anomaly 무시 |
| 문 개폐 | 베이즈 갱신으로 핑거프린트 자동 보정 |
| 새 가구 배치 | 일정 윈도우 후 자동 재학습 |
| WiFi AP 추가/제거 | 자동 매칭 후 가중치 재계산 |

### 5. 종래 대비 우위

| 항목 | 종래 BLE 비콘망 | 종래 UWB 앵커 | 본 발명 |
|------|----------------|--------------|---------|
| 신규 인프라 비용 | $50~100K | $200~500K | **$0** |
| 설치 기간 | 1~2주 | 2~4주 | **0일** |
| 정확도 | 2~5m | 0.5~1m | **2~5m (개별) / 1~3m (집단)** |
| 다층 추적 | 가능 | 가능 | **가능 (기압계)** |
| 동적 환경 적응 | 약함 | 약함 | **강함 (자동 학습)** |
| 배터리 영향 | BLE 광고 수신 | 강 | **WiFi 스캔만 (1~2%/h)** |

## 청구범위 (초안)

### 청구항 1 (독립항 — 시스템)

모바일 단말의 실내 다층 위치 추정 시스템에 있어서,
(a) 시설에 사전 설치된 일반용 WiFi AP들의 RSSI 핑거프린트 데이터베이스;
(b) 각 단말로부터 WiFi 스캔 결과를 수집하여 1차 위치를 추정하는 WiFi 매처;
(c) 단말의 가속도·자이로 센서로부터 단기 변위 및 회전을 추정하는 IMU Dead Reckoning 모듈;
(d) 단말의 기압계로부터 수직 위치(층)를 추정하는 층 추정 모듈;
(e) 단말의 자력계로부터 회전 보정을 수행하는 방위 모듈;
(f) 다수 단말 간 상대 거리 측정값을 입력받아 그래프 최적화로 전체 위치를 동시 보정하는 집단 SLAM 모듈;
(g) 상기 모듈들의 출력을 Kalman Filter로 융합하여 최종 위치 (x, y, floor) 및 불확실성 σ를 산출하는 융합부;
를 포함하며,
신규 측위 전용 하드웨어(전용 비콘, UWB 앵커, 측위 전용 AP)를 설치하지 않고 작동하는 것을 특징으로 하는 시스템.

### 청구항 2 (종속항)
청구항 1에 있어서, WiFi 핑거프린트 DB는 일상 사용자 데이터로부터 자동 학습 및 갱신되는 것을 특징으로 하는 시스템.

### 청구항 3 (종속항)
청구항 1에 있어서, 층 추정 모듈은 표준 대기 압력 모델 ΔP ≈ 12 Pa/m을 적용하며, ±1층 정확도를 갖는 것을 특징으로 하는 시스템.

### 청구항 4 (종속항)
청구항 1에 있어서, 집단 SLAM 모듈은 단말 간 WiFi-Direct 또는 BLE Peer-to-Peer 신호 강도 측정으로 상대 거리를 추정하는 것을 특징으로 하는 시스템.

### 청구항 5 (종속항)
청구항 1에 있어서, 다수 단말의 동시 보정에 의해 개별 위치 불확실성 σ가 σ / √K (K = 인접 단말 수) 로 감소하는 것을 특징으로 하는 시스템.

### 청구항 6 (종속항)
청구항 1에 있어서, 동적 환경 변화에 대응하기 위해 다수 단말의 합의로 단일 단말의 이상 측정값을 자동 배제하는 anomaly 필터를 더 포함하는 시스템.

### 청구항 7 (독립항 — 방법)

모바일 단말의 실내 다층 위치 추정 방법에 있어서,
(a) 각 단말이 WiFi 스캔과 IMU·기압·자력 센서 측정을 동시 수행하는 단계;
(b) WiFi RSSI를 사전 학습된 핑거프린트와 매칭하여 1차 위치를 추정하는 단계;
(c) IMU·기압·자력 출력으로 1차 위치를 단기 보정하는 단계;
(d) 다수 단말 간 상대 거리를 측정하여 그래프 SLAM으로 집단 보정하는 단계;
(e) Kalman 융합으로 최종 (x, y, floor, σ)를 출력하는 단계;
를 포함하는 방법.

### 청구항 8 (종속항)
청구항 7에 있어서, 신규 측위 전용 하드웨어를 설치하지 않고, 시설에 이미 존재하는 WiFi 인프라만으로 측위가 수행되는 것을 특징으로 하는 방법.

## 발명의 효과

1. **인프라 비용 100% 절감**: 신규 측위 하드웨어 0개
2. **즉시 도입 가능**: 설치 0일
3. **다층 추적**: 기압계로 층 ±1 정확도
4. **집단 보정**: 개별 σ → σ/√K 향상
5. **동적 환경 적응**: 자동 학습
6. **GPS 불가 환경 완전 커버**: 선박·지하·고층빌딩
