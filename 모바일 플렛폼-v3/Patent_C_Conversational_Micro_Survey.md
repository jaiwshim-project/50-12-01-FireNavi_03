# 특허 명세서 P-C — 대화형 마이크로 설문 기반 비상시 군중 상태 추정 시스템

> **출원 예정:** 한국특허청 (KIPO) | **국제출원:** PCT (12개월 내) | **발명자:** 심재우

---

## 발명의 명칭

**재난 상황에서 다수 사용자에게 3문항 이하 마이크로 설문을 자동 전송하고, 응답·미응답·센서 데이터를 통합 분석하여 군중 상태를 실시간 추정하는 시스템 및 방법**
(System and Method for Real-time Crowd State Estimation via Automated Micro-Survey and Multi-modal Response Analysis during Emergency)

---

## 기술분야

본 발명은 비상시 군중 상태 인식 시스템에 관한 것으로, 더욱 상세하게는 **재난 발생 시 다수 모바일 사용자에게 자동으로 3문항 이하의 짧은 설문(마이크로 설문)을 푸시하고, 명시적 응답·음성 응답·미응답자의 센서 추정을 통합하여 군중 전체의 실시간 상태를 추정하는 시스템 및 방법**에 관한 것이다.

---

## 배경기술

### 종래 기술의 한계

1. **단방향 안내만**: 종래 비상 시스템은 일방적 방송·문자 안내만 제공할 뿐, 사용자로부터 현장 정보를 수집하지 않는다.
2. **장문 설문 부적합**: 일반 설문 시스템은 5~20문항 구조로, 패닉 상태의 비상 사용자에게는 무용하다.
3. **미응답자 처리 부재**: 종래 시스템은 응답하지 않은 사용자의 상태를 추정할 메커니즘이 없다.

### 본 발명이 해결하는 문제

비상 상황의 시간 제약(평균 인지~행동 30초) 내에 수집 가능한 **3문항 이하의 마이크로 설문 + 음성 응답 + 미응답자의 IMU/마이크 자동 추정**을 통합 처리하여, 60~70% 응답률에도 100% 군중 상태 커버리지를 달성한다.

---

## 발명의 구성

### 1. 시스템 구성도

```
[Stage 1: 트리거]
   재난 자동 감지 (P-A 특허) → 4,000개 단말 활성화

[Stage 2: 마이크로 설문 전송]
   ├─ Q1. 불꽃 보임? (예/아니오/모름)
   ├─ Q2. 연기 보임/냄새? (없음/냄새/보임)
   └─ Q3. 주변 상태? (평온/달림/패닉)

[Stage 3: 다중 응답 모드]
   ├─ 터치 응답 (기본)
   ├─ 음성 응답 (Whisper STT)
   ├─ 비명 자동 감지 (Q3 자동 입력)
   └─ 무응답 대기

[Stage 4: 미응답자 센서 추정]
   ├─ IMU 분석 → 달림/넘어짐
   ├─ 마이크 분석 → 주변 패닉
   ├─ 조도 분석 → 연기/정전
   └─ 기압 분석 → 층 이동

[Stage 5: 군중 상태 통합 추정]
   ├─ 명시 응답 가중치 1.0
   ├─ 음성 응답 가중치 0.9
   ├─ 비명 추정 가중치 0.6
   └─ IMU/센서 추정 가중치 0.4
```

### 2. 마이크로 설문 설계 원칙

#### (1) 3문항 한도 원칙
- 3문항 초과 시 응답률 급감 (사용자 인지부하 한계)
- 각 문항 응답 시간 ≤ 2초로 설계

#### (2) 3지 선다 강제
- 텍스트 입력 금지 (패닉 시 타이핑 불가)
- 시각·후각·상태 각 차원에 대해 3개 옵션
- "모름" 옵션 포함 (불확실성 명시 허용)

#### (3) 화면 디자인
- 큰 버튼 (최소 5cm × 5cm)
- 고대비 색상 (시야 흐림 대응)
- 음성 옵션 항상 노출

### 3. 미응답자 자동 분류

| IMU 패턴 | 마이크 패턴 | 조도 패턴 | 추정 상태 |
|---------|-----------|---------|---------|
| 가속도 std > 2.0 | 80dB+ | 정상 | 달림+패닉 |
| 가속도 ≈ 0 (10초) | 정적 | 정상 | 정지/의식불명 가능 |
| 가속도 std 보통 | 비명 패턴 | 정상 | 주변 위험 인지 |
| 기압 급변 | — | — | 계단/엘리베이터 이동 |
| — | — | 급감 | 연기 또는 정전 |
| 자이로 회전 후 정지 | — | — | 넘어짐 가능성 |

### 4. 응답 데이터 정규화

| 입력 | 처리 |
|------|------|
| 다국어 음성 응답 | Whisper 다국어 STT |
| 의미 매핑 | LLM 기반 정규화 (10개국어 → 통일 라벨) |
| 손짓·이모지 | 패턴 인식 |
| 부분 응답 (1~2문항만) | 가중치 차등 처리 |

### 5. 응답 시간 분포

| 시간대 | 누적 응답률 |
|--------|------------|
| T+0~5초 | 10% (즉시 응답자) |
| T+5~15초 | 40% |
| T+15~30초 | 65% |
| T+30~60초 | 70~75% |
| 최종 미응답 | 25~30% (센서로 추정) |

## 청구범위 (초안)

### 청구항 1 (독립항 — 시스템)

비상시 군중 상태 추정 시스템에 있어서,
(a) 재난 트리거 발생 시 다수의 모바일 단말에 3문항 이하의 마이크로 설문을 자동 전송하는 설문 전송부;
(b) 단말로부터 터치 응답, 음성 응답, 비명 자동 감지 중 하나 이상으로 입력된 응답을 수집하는 응답 수집부;
(c) 미응답 단말의 IMU·마이크·조도·기압 센서 데이터를 분석하여 상태를 추정하는 센서 기반 추정부;
(d) 응답 데이터와 센서 추정 데이터를 입력원별 신뢰도 가중치로 통합하여 군중 상태를 산출하는 통합 추정부;
(e) 추정된 군중 상태를 실시간 동적 화재맵 또는 대피 경로 계산기에 제공하는 출력부;
를 포함하는 시스템.

### 청구항 2 (종속항)
청구항 1에 있어서, 상기 마이크로 설문은 다음을 포함하는 것을 특징으로 하는 시스템:
(a) 시각적 위험 확인 문항 (불꽃·연기 시각 인지);
(b) 후각적 위험 확인 문항 (연기 냄새);
(c) 주변 상태 문항 (평온·달림·패닉).

### 청구항 3 (종속항)
청구항 1에 있어서, 각 문항은 3지 선다이며, "모름" 또는 "확인 불가" 옵션을 포함하는 것을 특징으로 하는 시스템.

### 청구항 4 (종속항)
청구항 1에 있어서, 응답 수집부는 다국어 음성 응답을 자동 음성인식 후 의미 매핑하는 것을 특징으로 하는 시스템.

### 청구항 5 (종속항)
청구항 1에 있어서, 가중치는 명시 응답 1.0, 음성 응답 0.9, 비명 자동 감지 0.6, 센서 추정 0.4를 기본값으로 하는 시스템.

### 청구항 6 (종속항)
청구항 1에 있어서, IMU 분석부는 가속도 표준편차, 자이로 회전 패턴, 기압 변화율 중 하나 이상을 사용하여 사용자의 이동 상태를 분류하는 것을 특징으로 하는 시스템.

### 청구항 7 (독립항 — 방법)

비상시 군중 상태 추정 방법에 있어서,
(a) 재난 트리거 발생 시 다수 단말에 3문항 이하 마이크로 설문을 송신하는 단계;
(b) 응답을 수집하는 단계;
(c) 미응답 단말의 센서 데이터를 분석하여 상태를 추정하는 단계;
(d) 응답·추정 데이터를 가중 통합하는 단계;
(e) 군중 상태를 출력하는 단계;
를 포함하는 방법.

### 청구항 8 (종속항)
청구항 7에 있어서, 설문 응답률을 모니터링하며 시간 윈도우 내에 응답이 없는 단말에 대해 자동으로 센서 기반 추정으로 전환하는 단계를 더 포함하는 방법.

---

## 발명의 효과

1. **3문항 한도**: 패닉 상태 사용자에게도 응답률 60~70% 확보
2. **100% 커버리지**: 응답 70% + 센서 추정 30% = 4,000명 전체 상태 추정
3. **다국적 대응**: 음성 STT + LLM 정규화로 12개국어 자동 처리
4. **실시간성**: 30초 이내 군중 전체 상태 산출
5. **확장성**: 화재 외 지진·테러·전염병 시나리오로 확장 가능
