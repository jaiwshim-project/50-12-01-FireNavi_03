# FireNavi 청구항 구조 (단순화)

작성일: 2026-06-02  
목적: 특허 등록 가능성 높은 청구항 구조 설계  
방향: **1개 통합 특허 → 10개 독립항**

---

## 전략: 특허 등록 가능성 최대화

### 기존 방향 (복잡)
- 5개 특허 개별 출원
- 각각 독립항 1개 + 종속항 10개
- 총 5건 심사 → 시간·비용 증가

### 새로운 방향 (단순화)
- **1개 통합 특허** "스마트폰·온톨로지·AI 기반 재난대피 통합 플랫폼"
- **10개 독립항** (각 핵심 기술요소)
- **종속항 최소화** (각 독립항당 2~3개)
- 총 1건 심사 → 빠른 등록

---

## 청구항 구조

### 독립항 1: 음향 이벤트 온톨로지 기반 자동 재난 트리거
```
스마트폰 마이크로부터 수집된 음향 데이터를 분석하여 화재경보음, 폭발음, 비명 및 구조 요청 음성 중 적어도 하나를 포함하는 재난 관련 음향 이벤트를 분류하고,

분류된 음향 이벤트를 재난대피 온톨로지 지식그래프의 재난 이벤트 노드에 매핑하며,

매핑된 재난 이벤트 노드에 대응하는 대피 모드 또는 구조 요청 모드를 네트워크 연결 없이 로컬 단말에서 자동 활성화하는 것을 특징으로 하는 모바일 재난 트리거 시스템.
```

**종속항**:
- 1-1. 다수 단말의 동시 감지를 이용해 오탐을 줄이는 구성
- 1-2. 감지 결과를 위치 정보와 결합하여 검증하는 구성

---

### 독립항 2: 센서·인간보고 온톨로지 정규화 기반 동적 화재맵
```
스마트폰 센서 데이터 및 사용자 현장 보고 데이터를 수집하고,

상기 데이터를 화재, 연기, 혼잡, 정전, 출구폐쇄 및 구조손상 중 적어도 하나의 재난 온톨로지 의미 노드로 정규화하며,

정규화된 의미 노드의 시간·공간 관계 및 신뢰도를 기초로 화재·연기·군중·출구 장애를 포함하는 4채널 동적 화재맵을 생성하는 것을 특징으로 하는 재난 위험지도 생성 시스템.
```

**종속항**:
- 2-1. 다수 사용자 보고의 공간적 일치도를 이용해 신뢰도를 산출하는 구성
- 2-2. 베이지안 융합 알고리즘을 이용하는 구성

---

### 독립항 3: 공간 온톨로지 기반 인프라프리 실내 다층 측위
```
스마트폰의 WiFi 신호, 관성센서, 기압계 및 자력계 중 적어도 하나를 이용하여 사용자의 실내 위치와 층 정보를 추정하고,

추정된 위치와 층 정보를 건물의 층, 복도, 계단, 출구, 피난구역 및 폐쇄구역을 포함하는 공간 온톨로지 노드에 매핑하여,

매핑된 공간 온톨로지 노드와 위험 온톨로지 노드의 관계를 추론하여 대피 경로 결정에 사용하는 것을 특징으로 하는 실내 다층 측위 시스템.
```

**종속항**:
- 3-1. 신규 비콘 없이 기존 WiFi 인프라를 사용하는 구성
- 3-2. 기압계 변화를 통해 층 이동을 판단하는 구성

---

### 독립항 4: 취약계층 제약 온톨로지 기반 안전 마진 자동 적용
```
사용자의 연령, 이동능력, 감각 제약, 의료 상태 및 보호자 관계를 포함하는 취약계층 제약 온톨로지를 구성하고,

상기 온톨로지에 기초하여 사용자별 안전 마진 계수를 산출하며,

상기 안전 마진 계수를 경로 비용 함수에 반영하여 개인별 대피 경로를 생성하고,

어린이와 보호자의 경로를 동기화하거나 취약계층의 구조 우선순위를 산정하는 것을 특징으로 하는 개인별 대피 경로 생성 시스템.
```

**종속항**:
- 4-1. 휠체어 사용자에게 계단 사용 불가 규칙을 적용하는 구성
- 4-2. 호흡기 환자에게 연기 위험 가중치를 확대 적용하는 구성
- 4-3. 구조대 단말에 구조 우선순위를 제공하는 구성

---

### 독립항 5: 온톨로지 공유 기반 삼중 AI 엔진 동기 아키텍처
```
화재 위험을 예측하는 Prediction Engine, 군중 행동을 예측하는 Behavior Engine, 개인별 대피 경로를 결정하는 Decision Engine을 포함하되,

상기 세 엔진이 사람, 공간, 위험, 경로, 센서 및 규정 정보를 포함하는 재난대피 온톨로지 지식그래프를 공유하고,

각 엔진의 출력값을 상기 지식그래프의 의미 노드로 갱신하며,

갱신된 의미 노드를 기초로 개인별 대피 경로를 반복적으로 산출하는 것을 특징으로 하는 재난 대피 의사결정 시스템.
```

**종속항**:
- 5-1. 세 엔진이 일정 시간 간격으로 온톨로지를 갱신하는 구성
- 5-2. 추천 경로의 근거를 자연어 설명으로 제공하는 구성

---

### 독립항 6: 온톨로지 기반 주경로 및 대체경로 자동 전환
```
사용자 유형, 공간 연결성, 위험 요소 및 규정 정보를 포함하는 온톨로지 지식그래프를 참조하여 주경로와 대체경로의 의미 유형을 결정하고,

주경로의 위험도 또는 접근성 저하가 감지되는 경우 상기 의미 유형에 따라 대체경로로 자동 전환하며,

대체경로를 연기 회피, 혼잡 회피, 피난구역 경유, 보호자 동기화 경로 중 적어도 하나로 분류하는 것을 특징으로 하는 재난 대피 안내 시스템.
```

**종속항**:
- 6-1. 경로 전환 사유를 자연어로 제공하는 구성

---

### 독립항 7: 사용자 상태 온톨로지 기반 대화형 마이크로 설문
```
재난 발생 시 사용자 상태 온톨로지를 참조하여 사용자의 이동능력, 감각 제약, 인지 제약 및 현재 위치 중 적어도 하나를 판단하고,

판단된 사용자 상태에 따라 질문 내용, 질문 개수 및 응답 방식을 자동 조정하여 현장 정보를 수집하며,

시각장애인에게 냄새·열·소리 중심 질문을 제공하거나 청각장애인에게 화면·진동 기반 질문을 제공하는 것을 특징으로 하는 대화형 마이크로 설문 시스템.
```

**종속항**:
- 7-1. 미응답자를 센서 데이터로 상태 추정하는 구성

---

### 독립항 8: 사용자·위험·공간 온톨로지 기반 개인별 적응 경로 AI
```
사용자 온톨로지, 위험 온톨로지 및 공간 온톨로지를 참조하여 사용자별 대피 제약조건을 산출하고,

상기 대피 제약조건을 경로 비용 함수에 반영하여 사용자별로 서로 다른 적응형 대피 경로를 생성하며,

위험 온톨로지의 현재 위험과 미래 위험을 함께 반영하는 것을 특징으로 하는 AI 기반 재난 대피 경로 생성 시스템.
```

**종속항**:
- 8-1. 추천 경로와 추천 이유를 함께 출력하는 구성

---

### 독립항 9: 재난대피 온톨로지 기반 설명 가능한 경로 추천
```
사람, 공간, 위험, 센서, 경로 및 규정 정보를 포함하는 재난대피 온톨로지 지식그래프를 생성하고,

상기 지식그래프의 관계 추론을 이용하여 사용자별 대피 제약조건을 산출하며,

산출된 대피 제약조건을 기초로 개인별 대피 경로를 추천하고,

추천 경로의 이유를 온톨로지 관계 기반 자연어 설명으로 생성하는 것을 특징으로 하는 재난 대피 경로 추천 시스템.
```

**종속항**:
- 9-1. 규정 온톨로지를 이용해 법규 위반 경로를 제외하는 구성

---

### 독립항 10: 스마트폰·온톨로지·AI 기반 재난대피 통합 플랫폼
```
스마트폰 단말로부터 음향, 위치, 센서 및 사용자 보고 데이터를 수집하고,

수집된 데이터를 재난대피 온톨로지 지식그래프에 매핑하며,

상기 지식그래프와 AI 경로 엔진을 이용하여 개인별 대피 경로를 생성하고,

생성된 대피 경로를 사용자 단말, 관제센터 및 구조대 단말에 제공하며,

추천 경로의 이유를 사용자와 관리자에게 설명하는 것을 특징으로 하는 통합 재난대피 플랫폼.
```

**종속항**:
- 10-1. 엣지 서버가 온톨로지 추론을 수행하는 구성
- 10-2. 관제센터에 취약계층 위치와 구조 우선순위를 표시하는 구성
