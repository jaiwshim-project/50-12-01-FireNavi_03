## 1. 음향 이벤트 온톨로지 기반 자동 재난 트리거

### 핵심 내용
스마트폰 마이크가 화재경보음, 비명, 폭발음, 구조 요청 음성을 감지하고, 이를 재난 이벤트 온톨로지 노드로 자동 매핑하여 사용자 조작 없이 대피 모드를 자동 활성화하는 기술

### 기술적 차별점
- **기존**: 사용자가 직접 앱 실행, 서버 푸시 의존
- **FireNavi**: 로컬 음향 감지 → 온톨로지 매핑 → 자동 활성화
- **핵심 알고리즘**: 
  - FireAlarmSound → 화재 대피 모드
  - ExplosionSound → 폭발 위험 회피 모드
  - ScreamSound → 구조 요청 가능성
  - RescueCallVoice → 구조 우선 이벤트
  - CrowdNoiseIncrease → 군중 패닉 가능성

### 특허 가능성
- **신규성**: 음향을 단순 분류가 아닌 재난 의미 노드로 변환
- **진보성**: 네트워크 장애 시에도 로컬 단말 자동 작동
- **산업성**: 공연장, 학교, 병원, 크루즈선 등 광범위 적용

---

## 2. 스마트폰 센서·인간보고 온톨로지 정규화 기반 동적 화재맵

### 핵심 내용
스마트폰 센서 데이터(조도, 기압, IMU, 마이크)와 사용자 현장 보고("연기 냄새", "문이 막힘", "앞이 안 보임")를 재난 온톨로지 의미 노드(SmokeOdor, ExitBlocked, LowVisibility)로 정규화하여 실시간 4채널 화재맵을 생성하는 기술

### 기술적 차별점
- **기존**: 고정 센서(천장형 감지기, CCTV) 의존
- **FireNavi**: 스마트폰 센서 + 크라우드소싱 보고 → 온톨로지 정규화 → 동적 화재맵
- **4채널 화재맵**:
  1. 화재 위험 채널
  2. 연기 위험 채널
  3. 군중 혼잡 채널
  4. 구조·출구 장애 채널

### 특허 가능성
- **신규성**: 센서값과 자연어 보고를 동일한 온톨로지 의미 노드로 통합
- **진보성**: 고정 센서 사각지대 보완, 베이지안 융합 기반 신뢰도 평가
- **산업성**: 저비용 스마트폰 기반 재난안전 시스템

---

## 3. 공간 온톨로지 기반 인프라프리 실내 다층 측위

### 핵심 내용
WiFi RSSI, IMU, 기압계, 자력계를 이용해 실내 위치와 층을 추정하고, 이를 공간 온톨로지 노드(층, 복도, 계단, 출구, 피난구역)로 매핑하여 대피 의사결정에 활용하는 기술

### 기술적 차별점
- **기존**: BLE 비콘, UWB 등 별도 인프라 설치 필요
- **FireNavi**: 기존 WiFi + 스마트폰 센서만으로 위치 추정 → 공간 온톨로지 매핑
- **핵심 프로세스**:
  1. WiFi 신호 수집
  2. IMU 이동패턴 분석
  3. 기압계 기반 층 변화 추정
  4. 공간 온톨로지 매핑 (x,y,floor → "4층 동쪽 복도")
  5. 대피 경로 연동 ("4층 동쪽 복도" → 계단 A 연결 → 연기 위험 높음 → 대체경로 추천)

### 특허 가능성
- **신규성**: 위치를 좌표가 아닌 "대피 의미를 가진 공간"으로 변환
- **진보성**: 신규 하드웨어 없이 기존 인프라 활용
- **산업성**: 병원, 호텔, 학교, 지하철, 공항, 크루즈 확장 가능

## 4. 취약계층 제약 온톨로지 기반 개인별 안전 마진 자동 적용

### 핵심 내용
사용자의 연령, 이동능력, 감각 제약, 의료 상태, 보호자 관계를 취약계층 제약 온톨로지로 구성하고, 이를 기반으로 개인별 안전 마진 계수(α)를 자동 산출하여 경로 비용 함수에 반영하는 기술

### 기술적 차별점
- **기존**: 모든 사용자를 동일한 기준으로 판단
- **FireNavi**: 사용자별 제약조건 온톨로지 → 안전 마진 자동 산출 → 맞춤형 경로
- **사용자 유형별 안전 마진 예시**:
  - 고령자: α 1.5 이상 (이동 속도 낮음, 완만한 경로)
  - 어린이: α 2.0 이상 (보호자 동기화 필수)
  - 휠체어 사용자: 계단 페널티 무한대 (경사로·엘리베이터 우선)
  - 호흡기 환자: 연기 위험 가중치 3.0 이상
  - 시각장애인: 음성·진동 안내, 복잡도 낮은 경로
  - 청각장애인: 시각·진동 안내 우선, 음향 의존 제외

### 특허 가능성
- **신규성**: 안전 마진을 단순 숫자가 아닌 온톨로지 기반 다차원 제약으로 구성
- **진보성**: 보호자 동기화, 구조 우선순위 자동 산정
- **산업성**: 병원, 요양시설, 학교, 공공시설 적용성 높음

## 5. 온톨로지 공유 기반 삼중 AI 엔진 동기 아키텍처

### 핵심 내용
Prediction Engine(화재 확산 예측), Behavior Engine(군중 행동 예측), Decision Engine(개인별 경로 결정)이 하나의 재난대피 온톨로지 지식그래프를 공유하여 실시간 동기화되며, 각 엔진의 출력값을 공통 의미체계로 해석하고 반복적으로 갱신하는 기술

### 기술적 차별점
- **기존**: 화재 예측, 군중 분석, 경로 계산이 각각 독립적으로 작동
- **FireNavi**: 세 엔진이 동일한 온톨로지를 공유 → 판단 충돌 감소 → 설명 가능성 강화
- **동기화 프로세스**:
  1. 센서·사용자 데이터 수집
  2. 재난대피 온톨로지 지식그래프로 변환
  3. Prediction Engine: 위험 노드 갱신 (FireSpreadZone, SmokeExpansionZone, ExitBlockProbability)
  4. Behavior Engine: 행동 노드 갱신 (CrowdDensity, Bottleneck, PanicFlow)
  5. Decision Engine: 온톨로지 참조 → 개인별 경로 생성
  6. 일정 주기마다 상호 출력값 공유 → 재계산
  7. 추천 사유 자연어 생성 → 사용자·관제센터 제공

### 특허 가능성
- **신규성**: AI 엔진 간 공통 온톨로지 공유 및 동기화
- **진보성**: 설명 가능한 AI (Explainable AI) 구현
- **산업성**: 재난안전 분야 핵심 원천기술
