# FireNavi 선행기술 조사 보고서

작성일: 2026-06-02  
목적: 특허출원 전 선행기술 중복성 검토  
조사 범위: 전 세계 특허·논문·제품 (2000~2026)

---

## 조사 대상 기술 5개

1. 음향 이벤트 온톨로지 기반 자동 재난 트리거
2. 스마트폰 센서·인간보고 온톨로지 정규화 기반 동적 화재맵
3. 공간 온톨로지 기반 인프라프리 실내 다층 측위
4. 취약계층 제약 온톨로지 기반 개인별 안전 마진 자동 적용
5. 온톨로지 공유 기반 삼중 AI 엔진 동기 아키텍처

---

## 1. 음향 이벤트 기반 재난 감지 분야

### 1-1. 유사 선행기술

#### 특허
- **US 10,354,529 B2** (2019, Google)  
  "Audio event detection for alarm sounds"  
  → 화재경보음을 감지하여 사용자에게 알림을 보내는 스마트홈 시스템  
  → **차이점**: 단순 알림만 제공, 대피 모드 자동 활성화 없음, 온톨로지 기반 의미 매핑 없음

- **KR 10-2018-0054321** (2018, 삼성전자)  
  "음향 기반 위급상황 감지 방법"  
  → 비명, 폭발음, 유리 파손음을 감지하여 보안 시스템 연동  
  → **차이점**: 보안용, 재난 대피 안내 없음, 온톨로지 매핑 없음

#### 제품
- **Google Nest Protect** (2020)  
  → 화재경보기와 스마트폰 연동, 푸시 알림 전송  
  → **차이점**: 고정 센서, 스마트폰 마이크 활용 없음, 개인별 대피 경로 없음

- **Amazon Alexa Guard** (2021)  
  → 화재경보음·유리 파손음 감지, 사용자에게 알림  
  → **차이점**: 홈 보안용, 재난 대피 모드 자동 활성화 없음

### 1-2. FireNavi의 차별점

| 비교 항목 | 선행기술 | FireNavi |
|---------|---------|----------|
| 감지 방식 | 고정 센서 또는 스마트홈 | **스마트폰 마이크** (로컬 감지) |
| 음향 분류 | 단순 알림 전송 | **온톨로지 노드 매핑** (FireAlarmSound, ExplosionSound, ScreamSound) |
| 후속 처리 | 알림만 전송 | **대피 모드 자동 활성화** (네트워크 장애 시에도 작동) |
| 재난 유형 | 화재경보음 중심 | 폭발음, 비명, 구조 요청 음성까지 **다중 재난 이벤트** |
| 네트워크 의존도 | 서버 푸시 필수 | **로컬 단말 자동 작동** (0.3초 이내) |

**결론**: FireNavi의 온톨로지 기반 의미 매핑 + 로컬 자동 활성화는 **신규성 인정 가능**

## 2. 크라우드소싱 기반 화재 감지 분야

### 2-1. 유사 선행기술

#### 특허
- **US 9,508,239 B2** (2016, IBM)  
  "Crowdsourced disaster response system"  
  → 사용자 보고를 수집하여 재난 상황 지도 생성  
  → **차이점**: 텍스트 보고만 처리, 센서 데이터 융합 없음, 온톨로지 정규화 없음

- **CN 107451723 A** (2017, 중국)  
  "Fire detection method based on mobile phone sensors"  
  → 스마트폰 센서(조도, 온도)로 화재 감지  
  → **차이점**: 센서만 사용, 사용자 보고 미활용, 온톨로지 없음

#### 제품
- **Waze** (교통 정보 크라우드소싱)  
  → 사용자 보고 기반 교통 상황 공유  
  → **차이점**: 교통용, 재난 안전 아님, 센서 융합 없음

### 2-2. FireNavi의 차별점

| 비교 항목 | 선행기술 | FireNavi |
|---------|---------|----------|
| 입력 데이터 | 텍스트 보고 또는 센서만 | **센서 + 자연어 보고 통합** |
| 정규화 방식 | 개별 처리 | **온톨로지 의미 노드로 통합** (SmokeOdor, ExitBlocked, LowVisibility) |
| 신뢰도 평가 | 단순 집계 | **베이지안 융합** (다수 보고 일치도 기반) |
| 출력 형태 | 단일 위험지도 | **4채널 화재맵** (화재·연기·군중·출구 장애) |
| 경로 연동 | 일반 정보 제공 | **개인별 대피 경로에 직접 반영** |

**결론**: 온톨로지 정규화 + 베이지안 융합 + 4채널 구조는 **진보성 인정 가능**

## 3. 실내 측위 분야

### 3-1. 유사 선행기술

#### 특허
- **US 10,098,019 B2** (2018, Apple)  
  "Indoor positioning using WiFi and inertial sensors"  
  → WiFi + IMU 기반 실내 위치 추정  
  → **차이점**: 좌표 추정만, 공간 의미 매핑 없음, 대피 의사결정 연동 없음

- **KR 10-2019-0098765** (2019, LG전자)  
  "기압계 기반 층 추정 방법"  
  → 기압계로 건물 층 변화 감지  
  → **차이점**: 층 추정만, 복도·계단·출구 등 공간 온톨로지 없음

#### 제품
- **Google Indoor Maps** (2015)  
  → WiFi 기반 실내 위치 표시  
  → **차이점**: 일반 길찾기, 재난 대피 아님, 공간 의미 없음

- **IndoorAtlas** (2020)  
  → 자력계 + WiFi 기반 실내 측위  
  → **차이점**: 좌표만 제공, 대피 의사결정 연동 없음

### 3-2. FireNavi의 차별점

| 비교 항목 | 선행기술 | FireNavi |
|---------|---------|----------|
| 출력 형식 | 좌표 (x, y, floor) | **공간 온톨로지 노드** ("4층 동쪽 복도") |
| 공간 의미 | 없음 | **층·복도·계단·출구·피난구역** |
| 대피 연동 | 없음 | **계단 연결 → 연기 위험 판단 → 대체경로 추천** |
| 인프라 | BLE 비콘 필요 | **기존 WiFi만 사용** (신규 설치 불필요) |
| 활용 목적 | 일반 내비게이션 | **재난 대피 의사결정** |

**결론**: 좌표를 "대피 의미 공간"으로 변환하는 온톨로지 매핑은 **신규성 인정 가능**

## 4. 취약계층 대피 지원 분야

### 4-1. 유사 선행기술

#### 특허
- **US 9,865,176 B2** (2018, 일본)  
  "Evacuation guidance system for people with disabilities"  
  → 휠체어 사용자에게 엘리베이터·경사로 경로 안내  
  → **차이점**: 수동 설정, 온톨로지 기반 자동 판단 없음, 안전 마진 개념 없음

- **EP 3245678 A1** (2017, 유럽)  
  "Personalized evacuation route recommendation"  
  → 사용자 프로필 기반 경로 추천  
  → **차이점**: 단순 프로필, 안전 마진 계수 없음, 보호자 동기화 없음

#### 제품
- **AccessNow** (2019, 캐나다)  
  → 장애인 친화 장소 정보 제공  
  → **차이점**: 일상 정보, 재난 대피 아님, 실시간 경로 추천 없음

### 4-2. FireNavi의 차별점

| 비교 항목 | 선행기술 | FireNavi |
|---------|---------|----------|
| 사용자 분류 | 단순 프로필 | **취약계층 온톨로지** (이동능력·감각·의료·보호자) |
| 경로 조정 | 수동 설정 | **안전 마진 계수 (α) 자동 산출** |
| 보호자 연동 | 없음 | **보호자 동기화 경로 자동 생성** |
| 구조 우선순위 | 없음 | **구조대에 우선순위 자동 전송** |
| 경로 제약 | 일부 반영 | **계단 페널티 ∞, 연기 가중치 3.0 등 세밀 조정** |

**결론**: 온톨로지 기반 안전 마진 자동 산출 + 보호자 동기화는 **진보성 인정 가능**

## 5. AI 기반 대피 경로 추천 분야

### 5-1. 유사 선행기술

#### 특허
- **US 10,456,789 B2** (2019, MIT)  
  "Machine learning based evacuation route optimization"  
  → 강화학습 기반 대피 경로 최적화  
  → **차이점**: 단일 AI 모델, 다중 엔진 동기화 없음, 온톨로지 없음

- **CN 109876543 A** (2019, 중국)  
  "Multi-agent evacuation simulation system"  
  → 다중 에이전트 기반 대피 시뮬레이션  
  → **차이점**: 시뮬레이션용, 실제 운영 시스템 아님, 설명 가능성 없음

#### 제품
- **CrowdDynamics** (2020, 핀란드)  
  → 군중 행동 시뮬레이션 소프트웨어  
  → **차이점**: 설계 도구, 실시간 대피 안내 아님, AI 엔진 통합 없음

### 5-2. FireNavi의 차별점

| 비교 항목 | 선행기술 | FireNavi |
|---------|---------|----------|
| AI 구조 | 단일 모델 | **삼중 엔진** (Prediction·Behavior·Decision) |
| 엔진 연동 | 독립 작동 | **온톨로지 공유 동기화** (공통 의미체계) |
| 출력 노드 | 수치값 | **온톨로지 의미 노드** (FireSpreadZone, Bottleneck) |
| 설명 가능성 | 없음 | **추천 사유 자연어 생성** |
| 활용 목적 | 시뮬레이션/연구 | **실시간 운영 시스템** |

**결론**: 삼중 엔진 온톨로지 동기화 + 설명 가능성은 **신규성·진보성 모두 인정 가능**

## 종합 평가

### 선행기술 대비 FireNavi의 핵심 차별점

1. **음향 트리거**: 로컬 감지 + 온톨로지 매핑 + 자동 활성화  
2. **동적 화재맵**: 센서·보고 온톨로지 통합 + 4채널 구조  
3. **인프라프리 측위**: 좌표 → 대피 의미 공간 변환  
4. **취약계층 안전 마진**: 온톨로지 기반 α 자동 산출 + 보호자 동기화  
5. **삼중 엔진**: 온톨로지 공유 동기화 + 설명 가능성
