## ▌2. 기술 명세

### 2.1 기술목적

**해결할 핵심 문제:**
1. 종래 화재 대피 시스템은 시설당 $1M+ 하드웨어 설치를 요구 → **선사·시설 진입장벽**
2. 고정 IoT 센서는 500개 한계 + 시각·후각 감지 불가
3. 정적 대피도는 화재 위치 변화 반영 못함
4. 취약계층 별도 대응 부재

**v3.0 해결책:**
- **Stage 1 음향 트리거**: 4,000개 폰이 SOLAS 표준 화재경보음을 동시 자동 감지
- **Stage 2 인프라프리 측위**: 기존 WiFi + 폰 IMU/기압 → 2~5m (집단 보정 1~3m)
- **Stage 3 마이크로 설문**: 3문항 × 3초 → 응답 70% + 센서 추정 30% = 100% 커버
- **Stage 4 패시브 센서**: 4,000대 × 7센서 = 28,000+ 데이터 포인트
- **Stage 5 베이지안 융합 + 적응 경로**: 5초마다 화재맵 갱신, 개인별 경로 즉시 보정

**목표:**
- 대피 시간 40% 단축
- 도입비 95% 절감 ($1.5M → $50K)
- 시장 진입 기간 80% 단축 (5~10년 → 6~12개월)

### 2.2 기술구조 (5단계 파이프라인)

```
[Stage 1] 음향 자동 트리거
   ├─ SOLAS 화재경보음 패턴 (500~1000Hz)
   ├─ 경량 신경망 (~50KB) 추론
   └─ 다중 폰 공간 일치 검증
                 ↓
[Stage 2] 인프라프리 분산 측위
   ├─ 기존 WiFi RSSI 핑거프린팅 (5~10m)
   ├─ 폰 IMU Dead Reckoning (±2m/30초)
   ├─ 기압계 → 층 추정 (±1층)
   ├─ 자력계 → 방위
   └─ 집단 SLAM 보정 (1~3m)
                 ↓
[Stage 3] 대화형 마이크로 설문
   ├─ Q1. 불꽃 보임? (예/아니오/모름)
   ├─ Q2. 연기 보임/냄새? (없음/냄새/보임)
   ├─ Q3. 주변 상태? (평온/달림/패닉)
   └─ 음성 응답 옵션 (Whisper STT)
                 ↓
[Stage 4] 패시브 폰 센서 융합
   ├─ 마이크 음압 → 패닉 감지
   ├─ IMU → 달림/넘어짐
   ├─ 조도 → 연기 농도
   ├─ 기압 → 층 이동
   └─ 카메라 → CV 분석 (선택)
                 ↓
[Stage 5] 베이지안 화재맵 + 적응 경로
   ├─ 4채널 (Fire/Smoke/Damage/Crowd)
   ├─ 5초 갱신, 2m × 2m 격자
   ├─ A* Dynamic + Risk Penalty
   ├─ 6유형 Health-Aware
   └─ 푸시 + 음성 + 진동 안내
```

### 2.3 주요 기능

| 엔진 | 역할 | 핵심 기술 |
|------|------|----------|
| 🔊 Acoustic Trigger | 음향 자동 활성화 | MobileNet/YAMNet 경량 분류 |
| 📍 Localization | 인프라프리 측위 | WiFi 핑거프린팅 + IMU + Graph SLAM |
| 💬 Survey AI | 마이크로 설문 | 3문항 + Whisper STT + LLM 정규화 |
| 📱 Sensor Fusion | 패시브 센서 | Kalman + 이상 탐지 |
| 🗺️ Bayesian Map | 동적 화재맵 | Bayesian Inference + 시공간 스무딩 |
| 🛣️ Route Optimizer | 개인별 경로 | A* Dynamic + Risk Penalty + α=2.0 |
| ♿ Priority AI | 취약계층 우선 | 6유형 Health-Aware Routing |
| ⚖️ Exit Balancer | 출구 분산 | 동적 혼잡 패널티 |

### 2.5 배포 방식

- **앱 SDK**: 시설 운영자의 기존 앱에 모듈 임베드 (별도 설치 마찰 X)
- **Edge Server**: 시설 내 서버실 1~2대 (Docker)
- **Cloud Backup**: AWS/GCP 백업 (선내 단독 작동도 가능)
- **CI/CD**: GitHub Actions + 자동 배포
- **SaaS 모델**: 월 정액 구독 (시설당 $5K~50K/월, 규모별)

### 2.6 혁신적 요소

1. **세계 최초 크라우드소싱 화재 대피** — 4,000명의 눈/코를 분산 센서로 활용
2. **하드웨어 0개 도입** — 신규 디바이스 설치 없이 즉시 작동
3. **인간 = 센서 패러다임** — 인접 객실 거주자의 후각이 IoT보다 30~120초 빠름
4. **자가 진화 데이터 플라이휠** — 매 항차/매일 학습, 후발 진입자 따라잡기 어려운 데이터 해자
5. **SaaS 즉시 배포** — 1척 도입 후 다음 척 즉시, 도메인 확장 즉시
