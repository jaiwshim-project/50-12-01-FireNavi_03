# 명령 5. 선행기술 조사 보고서

## 조사 요약
실내 화재 대피, 스마트폰 기반 대피 안내, 온톨로지 기반 대피 모델, 실내 측위 관련 선행기술이 존재한다. 다만 FireNavi의 핵심인 “다중 외부 자극 트리거 + 스마트폰 분산 인간센서 + 온톨로지 의미 정규화 + 개인별 경로 AI + 취약계층 안전 마진 + 관제·구조 연계”를 하나의 플랫폼으로 결합한 구조는 차별화 가능성이 있다.

## 주요 선행기술 유형
1. IoT 센서 또는 화재감지기 기반 대피 경로 안내
2. BLE 비콘 기반 실내 위치 추정 및 대피 안내
3. 스마트폰 음성 안내 기반 화재 대피 시스템
4. BIM·온톨로지 기반 실내 화재 대피 모델
5. 접근 가능한 대피 경로를 위한 사용자 프로파일 온톨로지
6. 스마트폰 IMU·WiFi 기반 실내 측위
7. 군중 상태 및 위험지도 생성 관련 연구

## 차별 후보
- 신규 하드웨어 설치를 전제로 하지 않는 스마트폰 우선 구조
- 음향, 진동, 조도, 네트워크, 사용자 신고, 설비 API의 다중 외부 자극 트리거
- 센서값과 인간보고를 온톨로지 의미 노드로 정규화하는 위험지도 생성
- 취약계층 제약 온톨로지와 안전 마진을 경로 비용 함수에 반영
- 추천 경로의 설명 가능성 제공
