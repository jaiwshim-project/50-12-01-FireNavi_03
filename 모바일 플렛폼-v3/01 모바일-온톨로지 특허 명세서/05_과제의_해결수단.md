# 05. 과제의 해결수단

본 발명은 상기 과제를 해결하기 위하여 스마트폰, 선박 또는 시설 설비, 관제센터, 온톨로지 지식그래프 및 인공지능 경로 엔진을 결합한 재난대피 시스템을 제공한다.

## 1. 시스템의 기본 구성

본 발명의 시스템은 다음 구성요소를 포함할 수 있다.

1. 사용자 단말
2. 다중 외부 자극 수집부
3. 재난 이벤트 온톨로지 매핑부
4. 신뢰도 점수 산출부
5. 사용자 상태 추론부
6. 공간 온톨로지 관리부
7. 위험지도 생성부
8. 개인별 경로 산출부
9. 취약계층 안전 마진 적용부
10. 주경로·대체경로 전환부
11. 관제센터 연동부
12. 구조대 연계부
13. 선박 또는 시설 시스템 API 연동부
14. 사용자 역할 관리부
15. 엣지-서버 분리 처리부
16. 대피 그룹 관리부

## 2. 다중 외부 자극 수집부

다중 외부 자극 수집부는 사용자 단말의 마이크, 가속도계, 자이로센서, 조도센서, 기압계, 자력계, WiFi/BLE 신호, 사용자 입력 및 앱 실행 상태를 통해 재난 가능성과 관련된 신호를 수집한다.

또한 선박 또는 시설의 화재감지기, 연기감지기, 스프링클러, 방화문, 비상방송, CCTV 분석 시스템, 출입통제 시스템, 공조 시스템, 관제센터 비상 푸시 또는 API 신호를 수신할 수 있다.

## 3. 재난 이벤트 온톨로지 매핑부

재난 이벤트 온톨로지 매핑부는 수집된 신호를 다음과 같은 의미 노드로 변환한다.

- 화재경보음
- 화재 의심 음성
- 비명
- 폭발음
- 유리 파손음
- 연기 보고
- 출구 폐쇄 보고
- 군중 혼잡
- 정전
- 방화문 폐쇄
- 스프링클러 작동
- 미응답 상태
- 낙상 또는 충격
- 관제센터 비상 명령

이를 통해 단순 센서값을 재난상황 판단에 필요한 의미 정보로 정규화한다.

## 4. 신뢰도 점수 산출부

신뢰도 점수 산출부는 개별 신호의 강도, 발생 빈도, 동일 구역 내 다수 단말의 일치성, 선박 설비 신호와의 교차 검증, 시간적 연속성, 공간적 근접성을 고려하여 재난 트리거 신뢰도 점수를 산출한다.

신뢰도 점수에 따라 시스템은 다음 모드 중 하나를 활성화한다.

1. 주의 모드
2. 확인 모드
3. 대피 모드
4. 구조 모드

## 5. 사용자 상태 추론부

사용자 상태 추론부는 사용자의 위치, 움직임, 응답 여부, 신고 내용, 이동 속도, 등록된 취약정보 또는 일시적 상태를 분석하여 사용자 상태 온톨로지에 매핑한다.

예를 들어 고령자, 어린이, 휠체어 사용자, 청각장애인, 시각장애인, 호흡기 환자, 임산부, 부상자, 미응답자, 보호자 동반자 등의 상태를 추론할 수 있다.

## 6. 공간 온톨로지 관리부

공간 온톨로지 관리부는 시설 또는 선박의 도면 정보를 기반으로 객실, 복도, 계단, 비상구, 피난구역, 방화문, 엘리베이터, 데크, 집결장소, 구조대 접근로 등의 공간 노드와 연결관계를 관리한다.

## 7. 위험지도 생성부

위험지도 생성부는 재난 이벤트 온톨로지, 사용자 보고, 센서 데이터, 선박 설비 신호를 결합하여 실시간 위험지도를 생성한다.

위험지도는 화재, 연기, 혼잡, 정전, 출구 폐쇄, 구조 위험, 스프링클러 작동, 방화문 폐쇄, 미래 위험 예측 정보를 포함할 수 있다.

## 8. 개인별 경로 산출부

개인별 경로 산출부는 사용자 위치, 사용자 상태, 공간 구조, 위험지도, 출구 상태, 취약계층 안전 마진, 주경로 및 대체경로를 종합하여 사용자별 대피 경로를 산출한다.

## 9. 취약계층 안전 마진 적용부

취약계층 안전 마진 적용부는 사용자 상태 온톨로지에 따라 위험 가중치, 경로 비용, 이동 시간 여유, 연기 회피 기준, 계단 사용 가능 여부, 보호자 동기화 조건, 구조 우선순위를 자동으로 조정한다.

## 10. 관제센터 및 구조대 연동

관제센터 연동부는 전체 위험지도, 사용자 위치, 미응답자, 취약계층 위치, 출구 혼잡도, 대피 진행률, 구조 우선순위를 관제센터 화면에 제공한다.

구조대 연계부는 구조가 필요한 사용자와 접근 가능한 구조 경로를 제공한다.

## 11. 사용자 역할 관리부

사용자 역할 관리부는 일반 사용자, 보호자, 승무원, 관제센터, 구조대의 역할을 구분하고 역할별로 정보 조회 권한, 경로 변경 권한, 구조 우선순위 설정 권한을 차등 부여한다.

일반 사용자는 본인 위치와 본인 경로만 조회할 수 있고, 보호자는 피보호자의 위치와 경로를 추가로 조회할 수 있다.

승무원은 담당 구역 내 모든 사용자의 위치와 상태를 조회하고 일부 경로를 수동으로 변경할 수 있다.

관제센터는 전체 시설의 위험지도와 모든 사용자 위치를 조회하고 구조 우선순위를 관리할 수 있다.

## 12. 엣지-서버 분리 처리부

엣지-서버 분리 처리부는 사용자 단말(엣지 레이어)에서 센서 데이터 수집, 로컬 전처리, 공간 온톨로지 캐싱, 오프라인 대피 경로 표시를 수행하고, 서버 레이어에서 다중 단말 신호 융합, 신뢰도 점수 산출, 위험지도 생성, 개인별 경로 산출, 관제센터 연동을 수행한다.

엣지 레이어는 음성 키워드 감지, 낙상 패턴 인식, WiFi 신호 기반 위치 추정을 로컬에서 전처리하여 서버로 전송한다.

네트워크 단절 시에는 최근 캐시된 대피 경로를 표시하여 최소한의 대피 안내를 유지한다.

## 13. 대피 그룹 관리부

대피 그룹 관리부는 동일 객실, 가족 관계, 보호자-피보호자 관계, 교직원-학생 관계 중 적어도 하나에 해당하는 복수의 사용자를 하나의 대피 그룹으로 묶는다.

그룹 내에서 가장 취약한 사용자의 제약조건을 그룹 전체의 경로 비용 함수에 적용한다.

예를 들어 그룹 내에 휠체어 사용자가 포함된 경우 그룹 전체가 계단을 사용하지 않는 경로를 산출하고, 호흡기 환자가 포함된 경우 연기 위험 가중치를 그룹 전체에 높게 적용하며, 어린이가 포함된 경우 보호자와의 거리를 최소화하는 경로를 우선 추천한다.

## 14. 시설 유형별 특수성 대응부

시설 유형별 특수성 대응부는 공간 온톨로지와 규정 온톨로지에 시설 유형별 제약조건을 반영한다.

**초고층 빌딩(50층 이상)**에서는:
- 화재층 기준 상향/하향 대피 방향 자동 결정
- 엘리베이터 자동 사용 불가 처리
- 층별 피난 안전 구역 활용
- 연기의 수직 확산 예측 및 우선 경보

**대형 공연장/경기장(5,000석 이상)**에서는:
- 다수 출구(8개 이상)의 혼잡도 실시간 모니터링
- 좌석 위치별 최적 출구 분산 배정
- 급격한 이동 패턴 + 비명 음향 → 군중 패닉 자동 감지
- 출구별 예상 병목 지점 사전 식별 및 우회 안내

**복합 지하철역(환승역, 지하 상가 연결)**에서는:
- 지상 출구까지 최단 경로 우선 계산
- 연기 빠른 확산 대응 (지하 공간 특성)
- 다국어 자동 번역 (한·영·중·일·베·태·러·아·스·프·독·포 12개 언어)
- 방화문 폐쇄 상태 실시간 반영 및 연결 통로 자동 차단
- 승강장 대기자 즉시 지상 대피 안내

이를 통해 동일한 시스템 구조로 다양한 시설에 적용 가능하다.
