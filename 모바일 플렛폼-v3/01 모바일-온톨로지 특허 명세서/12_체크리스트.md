# 12. 체크리스트

## 1. 출원 전 기술 정리 체크리스트

- [ ] 발명의 명칭이 기술적 핵심을 충분히 포함하는가?
- [ ] 기술분야가 재난안전, 모바일 센서, 온톨로지, AI 경로 추천으로 명확히 정리되었는가?
- [ ] 기존 기술의 한계가 구체적으로 제시되었는가?
- [ ] 해결하려는 과제가 기존 기술의 문제와 직접 연결되는가?
- [ ] 과제의 해결수단이 시스템 구성요소별로 명확히 서술되었는가?
- [ ] 발명의 효과가 기술적 효과와 사업적 효과로 구분되어 있는가?
- [ ] 실시예가 실제 적용 장면을 충분히 설명하는가?

## 2. 청구항 체크리스트

- [ ] 독립항이 너무 좁지 않은가?
- [ ] 독립항에 핵심 구성요소가 모두 포함되어 있는가?
- [ ] 종속항이 독립항을 적절히 한정하고 있는가?
- [ ] 청구항 간 중복이 지나치게 많지 않은가?
- [ ] 스마트폰 센서 관련 청구항이 포함되어 있는가?
- [ ] 온톨로지 지식그래프 관련 청구항이 포함되어 있는가?
- [ ] 신뢰도 점수 산출 관련 청구항이 포함되어 있는가?
- [ ] 개인별 대피 경로 관련 청구항이 포함되어 있는가?
- [ ] 취약계층 안전 마진 관련 청구항이 포함되어 있는가?
- [ ] 관제센터 또는 구조대 연계 관련 청구항이 포함되어 있는가?
- [ ] 설명 가능한 경로 추천 관련 청구항이 포함되어 있는가?
- [ ] 역할별 권한 관리 청구항이 포함되어 있는가?
- [ ] 엣지-서버 분리 아키텍처 청구항이 포함되어 있는가?
- [ ] 대피 그룹 관리 청구항이 포함되어 있는가?

- [ ] 온톨로지 기반 대피 경로 관련 특허를 검색했는가?
- [ ] 취약계층 대피 경로 관련 특허를 검색했는가?

## 4. 도면 준비 체크리스트

- [ ] 전체 시스템 구성도가 있는가?
- [ ] 다중 외부 자극 트리거 엔진 도면이 있는가?
- [ ] 온톨로지 지식그래프 구조도가 있는가?
- [ ] 위험지도 생성 흐름도가 있는가?
- [ ] 개인별 경로 산출 흐름도가 있는가?
- [ ] 취약계층 안전 마진 적용 도면이 있는가?
- [ ] 관제센터 화면 예시가 있는가?
- [ ] 크루즈선 객실 복도 적용 예시 도면이 있는가?
- [ ] 도면 부호 체계가 정리되었는가?
- [ ] 명세서 본문과 도면 참조가 일치하는가?
- [ ] 엣지-서버 분리 아키텍처 구조도가 있는가?
- [ ] 역할별 UI 예시 도면이 있는가?
- [ ] 대피 그룹 관리 흐름도가 있는가?

## 5. 변리사 상담 전 체크리스트

- [ ] 출원 범위를 1건으로 할지, 분할 출원할지 정했는가?
- [ ] 핵심 독립항의 보호 범위를 검토했는가?
- [ ] 선행기술 대비 차별성 문장을 준비했는가?
- [ ] 구현 가능한 기술요소와 아직 개념 단계인 요소를 구분했는가?
- [ ] 1차 출원 후 후속 출원 후보를 정리했는가?
- [ ] 국내 우선 출원 후 PCT 출원 여부를 검토했는가?
- [ ] 사업화 대상 시장을 정리했는가?
- [ ] 중간심사 또는 투자자 발표자료와 특허 전략이 일치하는가?

## 6. 위험 요소 체크리스트

- [ ] “온톨로지” 표현이 너무 추상적이지 않은가?
- [ ] AI 경로 엔진의 입력·처리·출력이 구체적으로 서술되었는가?
- [ ] 스마트폰 센서 활용 방식이 구체적인가?
- [ ] 시설 설비 API 연동이 선택적 구성으로 처리되었는가?
- [ ] 개인정보 및 위치정보 처리 이슈를 고려했는가?
- [ ] 화재 외 재난으로 확장 가능한가?
- [ ] 크루즈선에 한정되지 않고 다중이용시설로 확장 가능한가?

## 7. 최종 판단

현재 자료는 변리사 상담용 1차 특허 초안으로 활용 가능하다.

다만 실제 출원 전에는 선행기술 정밀 조사, 청구항 정제, 도면 부호 정리, 법률적 표현 조정이 필요하다.
