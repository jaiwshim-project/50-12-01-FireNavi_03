# 07. 발명의 상세한 설명

## 1. 전체 개요

본 발명은 스마트폰 센서, 사용자 보고, 선박 또는 시설 설비 신호, 관제센터 신호를 수집하고, 이를 온톨로지 지식그래프를 이용하여 의미 기반으로 해석한 후, 인공지능 경로 엔진을 통해 개인별 재난 대피 경로를 제공하는 시스템 및 방법에 관한 것이다.

본 발명은 특히 크루즈선과 같이 복도, 객실, 비상구, 계단, 방화문, 집결장소가 복잡하게 연결된 다중이용시설에서 유용하다.

## 2. 구성요소

본 발명은 다음 구성요소를 포함할 수 있다.

### 2.1 사용자 단말

사용자 단말은 스마트폰, 태블릿, 웨어러블 기기 또는 이에 준하는 모바일 단말일 수 있다.

사용자 단말은 마이크, 가속도계, 자이로센서, 조도센서, 기압계, 자력계, 위치 추정 모듈, WiFi/BLE 통신 모듈, 화면 출력부, 진동 출력부, 음성 출력부를 포함할 수 있다.

### 2.2 다중 외부 자극 수집부

다중 외부 자극 수집부는 다음 입력 신호를 수집한다.

- 화재경보음
- 화재 또는 구조 요청 음성 키워드
- 비명, 폭발음, 유리 파손음
- 비상방송 키워드
- 급진동, 충격, 낙상 패턴
- 다수 사용자의 동시 이동, 정체, 역방향 이동
- 조도 급감 및 비상등 점멸
- WiFi/BLE 신호 이상 또는 구역 비상 패킷
- 사용자 SOS, 연기 신고, 문 막힘 신고
- 미응답 및 무이동 상태
- 선박 설비 신호
- 관제센터 비상 푸시 또는 API 신호

### 2.3 온톨로지 지식그래프

온톨로지 지식그래프는 다음 하위 온톨로지를 포함할 수 있다.

1. 사용자 온톨로지
2. 공간 온톨로지
3. 위험 온톨로지
4. 센서 온톨로지
5. 경로 온톨로지
6. 규정 온톨로지
7. 구조 우선순위 온톨로지

사용자 온톨로지는 일반 사용자, 고령자, 어린이, 휠체어 사용자, 시각장애인, 청각장애인, 호흡기 환자, 임산부, 부상자, 미응답자, 보호자 등을 포함할 수 있다.

공간 온톨로지는 객실, 복도, 비상구, 계단, 방화문, 피난구역, 집결장소, 엘리베이터, 데크, 구조대 접근로를 포함할 수 있다.

위험 온톨로지는 화재, 연기, 유독가스, 열, 정전, 혼잡, 출구 폐쇄, 침수, 충격, 스프링클러 작동 등을 포함할 수 있다.

### 2.4 재난 이벤트 매핑부

재난 이벤트 매핑부는 수집된 외부 자극을 온톨로지 노드로 변환한다.

예를 들어 “연기가 난다”는 사용자 보고는 SmokeReport 노드로 변환되고, 조도 급감은 LowVisibility 또는 PowerFailure 후보 노드로 변환될 수 있다.

### 2.5 신뢰도 점수 산출부

신뢰도 점수 산출부는 다음 요소를 이용하여 신뢰도 점수를 산출한다.

- 신호 강도
- 동일 구역 내 발생 빈도
- 시간적 연속성
- 공간적 근접성
- 다수 단말의 일치성
- 선박 설비 신호와의 교차 검증
- 사용자 보고의 반복성
- 관제센터 신호 여부

신뢰도 점수에 따라 주의 모드, 확인 모드, 대피 모드, 구조 모드 중 하나가 활성화될 수 있다.

### 2.6 위험지도 생성부

위험지도 생성부는 화재, 연기, 혼잡, 정전, 출구 폐쇄, 방화문 폐쇄, 스프링클러 작동, 미래 위험 예측 정보를 공간 온톨로지에 매핑하여 실시간 위험지도를 생성한다.

### 2.7 개인별 경로 산출부

개인별 경로 산출부는 사용자 위치, 사용자 상태, 공간 연결성, 위험지도, 출구 상태, 취약계층 안전 마진을 기반으로 주경로와 대체경로를 생성한다.

경로 산출에는 A* 알고리즘, Dijkstra 알고리즘, 위험 가중치 기반 최단 경로 알고리즘, 베이지안 위험지도, 규칙 기반 추론 또는 인공지능 모델이 사용될 수 있다.

### 2.8 취약계층 안전 마진 적용부

취약계층 안전 마진 적용부는 사용자 상태 온톨로지를 기반으로 경로 비용 함수에 안전 마진을 반영한다.

예를 들어 휠체어 사용자는 계단을 사용할 수 없으므로 계단 경로의 비용을 무한대 또는 매우 큰 값으로 설정한다.

호흡기 환자는 연기 위험 가중치를 일반 사용자보다 높게 설정한다.

어린이는 보호자와의 거리 또는 교직원·승무원 인계 가능성을 경로 비용에 반영한다.

### 2.9 안내 출력부

안내 출력부는 사용자 단말에 시각, 음성, 진동, 텍스트, 아이콘, 화살표, 지도 형태로 대피 경로를 제공한다.

시각장애인에게는 음성 및 진동 안내를 강화하고, 청각장애인에게는 화면 점멸, 진동, 텍스트 안내를 강화할 수 있다.

### 2.10 관제센터 연동부

관제센터 연동부는 전체 위험지도, 사용자 분포, 취약계층 위치, 미응답자, 출구 혼잡도, 구조 우선순위를 표시한다.

### 2.11 구조대 연계부

구조대 연계부는 구조대에게 접근 가능한 경로, 구조 대상자 위치, 위험구역 회피 정보, 필요한 구조 장비 정보를 제공한다.

### 2.12 사용자 역할 관리부

사용자 역할 관리부는 다음 역할을 구분한다.

- **일반 사용자**: 본인 위치, 본인 경로 조회만 가능
- **보호자**: 본인 + 피보호자(어린이/장애인) 위치·경로 조회
- **승무원**: 담당 구역 내 모든 사용자 위치·상태 조회, 일부 경로 수동 변경 가능
- **관제센터**: 전체 시설 위험지도, 모든 사용자 위치, 구조 우선순위 관리
- **구조대**: 구조 대상자 위치, 접근 경로, 필요 장비 정보 조회

역할별 권한은 사용자 온톨로지에 정의되고, JWT 토큰 또는 세션 기반으로 검증된다.

이를 통해 개인정보 보호와 운영 효율을 동시에 달성할 수 있다.

### 2.13 엣지-서버 분리 아키텍처

본 발명은 엣지 레이어와 서버 레이어로 구성된다.

**엣지 레이어 (사용자 단말)**
- 센서 데이터 수집 (마이크, 가속도계, 조도센서, WiFi, BLE, 기압계)
- 로컬 전처리 (음성 키워드 감지, 낙상 패턴 인식, WiFi 신호 기반 위치 추정)
- 캐싱 (공간 온톨로지 일부, 대피 경로 최근 버전)
- 오프라인 대피 경로 표시 (최근 캐시된 경로)

**서버 레이어**
- 다중 단말 신호 융합
- 신뢰도 점수 산출
- 위험지도 생성 (화재 확산 시뮬레이션 포함)
- 개인별 경로 산출 (A* 알고리즘, 베이지안 추론)
- 관제센터 연동
- 온톨로지 지식그래프 관리

이를 통해 네트워크 단절 시에도 마지막 캐시된 경로를 표시할 수 있고, 서버는 실시간 위험 상황을 반영한 최적 경로를 제공한다.

또한 서버에서 복잡한 연산을 수행하므로 모바일 배터리 효율을 높일 수 있다.

### 2.14 대피 그룹 관리부

대피 그룹 관리부는 다음 경우에 복수의 사용자를 하나의 그룹으로 묶는다.

- 동일 객실에 체크인된 가족
- 보호자-피보호자 관계 (어린이, 장애인)
- 교직원-학생 그룹
- 승무원이 수동으로 편성한 그룹

그룹 내에서 가장 취약한 사용자의 제약조건을 그룹 전체 경로에 적용한다.

**예시 1: 휠체어 사용자 포함 그룹**
가족 4명 중 1명이 휠체어 사용자인 경우, 가족 전체가 계단을 사용하지 않는 경로로 안내된다.

**예시 2: 호흡기 환자 포함 그룹**
그룹 내에 호흡기 환자가 있으면 연기 위험 가중치를 그룹 전체에 높게 적용하여 연기가 없는 경로를 우선 추천한다.

**예시 3: 어린이 포함 그룹**
보호자와 어린이는 동일한 경로로 안내되며, 보호자와 어린이의 거리가 일정 범위를 초과하면 경고를 발생한다.

이를 통해 가족이 뿔뿔이 흩어지지 않고, 심리적 안정성과 실제 대피 성공률을 높일 수 있다.

## 3. 작동 절차

본 발명의 작동 절차는 다음과 같다.

1. 사용자 단말 및 시설 설비로부터 외부 자극 신호를 수집한다.
2. 수집된 신호를 재난 이벤트 온톨로지에 매핑한다.
3. 신뢰도 점수를 산출한다.
4. 신뢰도 수준에 따라 모드를 결정한다.
5. 사용자 상태와 위치를 추론한다.
6. 공간 온톨로지와 위험지도를 갱신한다.
7. 사용자별 주경로와 대체경로를 산출한다.
8. 취약계층 안전 마진을 적용한다.
9. 사용자에게 대피 경로와 추천 이유를 제공한다.
10. 관제센터와 구조대에 상황 정보를 공유한다.
11. 위험 상태가 변화하면 경로를 재계산한다.

## 4. 실시예

### 4.1 실시예 1: 크루즈선 객실 복도 화재

크루즈선 객실 복도에서 화재가 발생한 경우, 일부 사용자 단말은 화재경보음을 감지하고, 다른 사용자 단말은 “연기”라는 음성 키워드를 감지하며, 일부 사용자는 앱을 통해 연기 신고를 입력한다.

선박 시스템은 특정 구역의 연기감지기 작동 신호와 방화문 폐쇄 신호를 전송한다.

시스템은 이들 신호를 온톨로지 기반으로 통합하여 해당 복도를 위험구역으로 표시한다.

일반 승객에게는 가장 가까운 안전 비상구로 주경로를 제공하고, 우측 비상구가 혼잡하거나 연기 위험이 높을 경우 좌측 비상구를 대체경로로 제공한다.

휠체어 사용자는 계단 경로에서 제외되고 피난구역 또는 구조대 접근 경로로 안내된다.

미응답자는 관제센터에 표시되어 승무원 또는 구조대 확인 대상으로 분류된다.

### 4.2 실시예 2: 초고층 빌딩 화재 (50층 이상)

초고층 빌딩 42층 사무실에서 화재가 발생한 경우, 시스템은 다음과 같이 작동한다.

**층별 대피 방향 자동 결정:**
- 42층 이상 재실자 → 옥상 대피 또는 피난 안전 구역(45층) 안내
- 42층 이하 재실자 → 하향 계단 대피 안내
- 41층 재실자 → 즉시 하향 대피 (화재층 바로 아래)

**엘리베이터 자동 제어:**
엘리베이터는 자동 사용 불가 처리되며, 시스템은 모든 사용자에게 “엘리베이터 사용 금지, 계단 이용” 안내를 발령한다.

**취약계층 특별 대응:**
- 휠체어 사용자와 고령자는 피난 안전 구역(45층)에서 구조대 대기 경로로 안내
- 호흡기 환자는 연기 확산 방향을 회피한 우회 경로 제시

**연기 수직 확산 대응:**
연기의 수직 확산을 고려하여 43~45층 재실자에게 우선 경보가 발령되고, 층별 스프링클러 작동 상태와 방화문 폐쇄 상태가 위험지도에 실시간 반영된다.

### 4.3 실시예 3: 대형 공연장 화재 및 군중 패닉

5,000석 규모 공연장에서 무대 조명 장치 화재가 발생하고 군중 패닉이 발생한 경우, 시스템은 다음과 같이 작동한다.

**화재 및 패닉 구역 식별:**
시스템은 다수 스마트폰의 급격한 이동 패턴, 비명 음향, 조도 급감, 사용자 신고를 융합하여 무대 중앙 및 1층 좌석 구역을 화재·패닉 구역으로 식별한다.

**출구 분산 배정:**
시스템은 8개 출구의 혼잡도를 실시간 모니터링하여 좌석 위치별로 최적 출구를 분산 배정한다.
- A구역 좌석 → 출구 1, 2 (혼잡도 낮음)
- B구역 좌석 → 출구 3, 4 (무대 반대편)
- 2층 발코니 좌석 → 출구 5, 6 (직접 계단)

**취약계층 우선 안내:**
- 어린이 동반 가족 → 측면 출구 (인파 적음)
- 휠체어 사용자 → 1층 직접 출구 (계단 회피)

**관제센터 지원:**
관제센터는 출구별 혼잡도와 예상 병목 지점을 실시간 확인하여 구조대 배치를 최적화하고, 출구 6번의 혼잡도가 임계값을 초과하면 해당 구역 재실자에게 출구 7번으로 우회 안내를 자동 발령한다.

### 4.4 실시예 4: 복합 지하철역 화재 (환승역 + 지하 상가 연결)

지하 3층 환승역에서 전기실 화재 발생 시, 연기가 지하 공간 전체로 빠르게 확산된다.

**지상 출구 최단 경로 계산:**
시스템은 지상 출구까지의 최단 경로를 계산하되, 연기 확산 방향을 실시간 반영하여 우회 경로를 제시한다.

**다국어 자동 번역:**
다국적 이용자를 위해 12개 언어(한국어, 영어, 중국어, 일본어, 베트남어, 태국어, 러시아어, 아랍어, 스페인어, 프랑스어, 독일어, 포르투갈어)로 안내 메시지가 자동 번역된다.

**취약계층 안내 강화:**
- 시각장애인 → 음성 안내 강화 (“좌측으로 30m 직진, 우회전 후 계단 상행”)
- 청각장애인 → 화면 점멸 + 진동 + 화살표 애니메이션

**방화문 폐쇄 상태 반영:**
지하 상가 연결 통로의 방화문이 폐쇄된 경우, 해당 경로는 자동 차단되고 대체 경로가 즉시 제시된다.

**승강장 대기자 즉시 대피:**
승강장에서 대기 중인 이용자는 지하철 터널이 아닌 지상 출구 방향으로 즉시 안내되며, “승강장 대기 금지, 즉시 지상 출구로 이동” 메시지가 반복 발령된다.

## 5. 설명 가능한 경로 추천

본 발명은 추천 경로와 함께 추천 이유를 제공할 수 있다.

예를 들어 다음과 같은 문구가 생성될 수 있다.

“우측 비상구는 현재 혼잡도가 높고 연기 위험이 증가하고 있으므로 좌측 비상구를 통한 대체경로를 추천합니다.”

“사용자가 휠체어 사용자로 분류되어 계단을 제외하고 피난구역 경유 경로를 안내합니다.”

“현재 사용자가 응답하지 않고 이동이 없으므로 관제센터에 확인 요청이 전송되었습니다.”
