# 명령 6. 선행기술 대비 중복성 검토

## 중복 가능성이 있는 영역
- 스마트폰을 이용한 실내 대피 안내
- 화재 센서 또는 IoT 센서와 연동한 경로 안내
- WiFi·IMU 기반 실내 측위
- 온톨로지 또는 BIM 기반 대피 모델링
- 사용자 프로파일 기반 접근 가능한 대피 경로 제공

## FireNavi의 차별 영역
- 트리거 신호가 단일 화재경보음이 아니라 12종 이상의 외부 자극을 포함한다.
- 센서와 인간보고를 동일한 재난 온톨로지 노드로 정규화한다.
- 위험지도, 사용자 제약, 공간 의미, 규정 기준을 개인별 경로 비용 함수에 동시에 반영한다.
- 취약계층 안전 마진과 구조 우선순위를 자동 적용한다.
- 관제센터와 구조대 단말까지 포함한 운영 플랫폼으로 확장한다.
