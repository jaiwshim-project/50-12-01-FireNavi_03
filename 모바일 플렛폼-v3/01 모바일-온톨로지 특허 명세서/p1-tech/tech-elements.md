# 명령 2. FireNavi 특허출원 핵심 기술요소 5개

## 1. 다중 외부 자극 기반 재난 트리거 엔진
화재경보음, 비상 음성 키워드, 비명·폭발음, 스마트폰 급진동·낙상 패턴, 조도 급감, WiFi/BLE 이상, 사용자 SOS, 선박 설비 신호, 관제센터 API 신호 등을 통합하여 재난 모드를 자동 활성화한다.

## 2. 센서·인간보고 온톨로지 정규화 기반 실시간 화재맵
스마트폰 센서와 사용자 보고를 화재, 연기, 혼잡, 출구폐쇄, 구조손상 등 재난 온톨로지 노드로 변환하여 시간·공간 기반 위험지도를 생성한다.

## 3. 사용자·위험·공간 온톨로지 기반 개인별 적응 대피 경로 AI
사용자 상태, 이동능력, 취약도, 현재 위치, 위험지도, 공간 연결성, 출구 혼잡도, 미래 위험 예측을 종합하여 개인별 경로를 산출한다.

## 4. 취약계층 제약 온톨로지 기반 안전 마진 자동 적용
고령자, 어린이, 휠체어 사용자, 임산부, 호흡기 환자, 시각·청각장애인의 제약을 온톨로지로 정의하고, 경로 비용 함수에 안전 마진 계수를 자동 적용한다.

## 5. 스마트폰·온톨로지·AI 기반 재난대피 통합 플랫폼
스마트폰 앱, 엣지 서버, 온톨로지 지식그래프, AI 엔진, 관제센터, 구조대 단말을 통합하여 감지→판단→안내→관제→구조를 수행한다.
