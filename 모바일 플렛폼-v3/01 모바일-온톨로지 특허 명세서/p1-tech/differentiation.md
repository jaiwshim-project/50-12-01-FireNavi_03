# 명령 7. 차별성 근거

1. 화재감지기나 IoT 센서 하나가 아니라 스마트폰 마이크, IMU, 조도, 기압, WiFi/BLE, 사용자 신고, 미응답·무이동, 선박 시스템 API 등을 복합 입력으로 사용한다.
2. 입력값을 단순 이벤트로 저장하지 않고 재난 온톨로지 노드로 변환한다.
3. 이동능력, 감각 제약, 건강상태, 보호자 관계, 취약계층 안전 마진을 경로 비용 함수에 반영한다.
4. 추천 경로에 대해 위험 회피, 접근성, 혼잡도, 취약계층 보호, 규정 적합성 관점으로 이유를 설명한다.
5. 신규 하드웨어 설치 없이 기존 스마트폰과 기존 네트워크·설비 신호를 활용한다.
