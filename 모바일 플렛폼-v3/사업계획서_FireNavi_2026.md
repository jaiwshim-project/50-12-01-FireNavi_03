## 1. 사업 개요

### 1.1 사업 배경 및 필요성

#### 현황 및 문제점

**화재 대피 시스템의 구조적 한계:**
- 국내 다중이용시설 화재 시 사망자의 **70%가 대피 지연**으로 발생 (소방청, 2025)
- 기존 대피 시스템: 정적 대피도 + 고정 센서 → 실시간 화재 확산 반영 불가
- 고정 IoT 센서 설치 비용: 시설당 **15억~30억원** (병원·호텔 기준)
- 도입 기간: 설계~설치~시운전 **12~24개월**

**취약계층 대응 부재:**
- 휠체어 사용자, 시각장애인 등 별도 대피 경로 없음
- 외국인 관광객 언어 장벽 (다국적 승무원도 동일 문제)

**한국 시장의 기회:**
- 다중이용시설 안전 규제 강화 (특별법 개정, 2025)
- 스마트 안전 시스템 정부 지원 확대 (재난안전부, K-Startup)
- **즉시 적용 가능:** 크루즈선과 달리 인증 장벽 낮음

#### 기술 발전 기회

**스마트폰 보급률 98% + WiFi 인프라 보편화:**
- 이미 설치된 자산 활용 → 신규 하드웨어 비용 0원
- 4,000~6,000명의 스마트폰 = **28,000+ 데이터 포인트** (기존 IoT 500개 대비 56배)
- 인간 = 센서: 눈(시각), 코(후각), 귀(청각) → IoT보다 **30~120초 조기 감지**

**AI 기술 성숙:**
- 경량 음향 분류 모델 (~50KB) 모바일 실시간 추론 가능
- Bayesian Fusion으로 불완전한 데이터 통합
- 대화형 AI로 패닉 상황 3초 설문 응답률 70%

## 2. 기술 개발 계획

### 2.1 기술 아키텍처

#### 5단계 AI 파이프라인

```
[Stage 1] 음향 자동 트리거
   ├─ SOLAS 화재경보음 패턴 (500~1000Hz)
   ├─ 경량 신경망 (~50KB) 추론
   └─ 다중 폰 공간 일치 검증 (K=10)
                 ↓
[Stage 2] 인프라프리 분산 측위
   ├─ WiFi RSSI 핑거프린팅 (5~10m)
   ├─ IMU Dead Reckoning (±2m/30초)
   ├─ 기압계 → 층 추정 (±1층)
   ├─ 자력계 → 방위
   └─ Graph SLAM 집단 보정 (1~3m)
                 ↓
[Stage 3] 대화형 마이크로 설문
   ├─ Q1. 불꽃 보임? (예/아니오/모름)
   ├─ Q2. 연기 보임/냄새? (없음/냄새/보임)
   ├─ Q3. 주변 상태? (평온/달림/패닉)
   └─ Whisper STT + LLM 정규화
                 ↓
[Stage 4] 패시브 폰 센서 융합
   ├─ 마이크 음압 → 패닉 감지
   ├─ IMU → 달림/넘어짐
   ├─ 조도 → 연기 농도
   ├─ 기압 → 층 이동
   └─ Kalman Filter 융합
                 ↓
[Stage 5] 베이지안 화재맵 + 적응 경로
   ├─ 4채널 (Fire/Smoke/Damage/Crowd)
   ├─ 5초 갱신, 2m × 2m 격자
   ├─ A* Dynamic Routing
   ├─ Risk Penalty (α=2.0 취약계층)
   └─ 30개 유형 맞춤 안내
```

#### 핵심 AI 엔진

**1. Acoustic Trigger AI**
- 목적: 사이렌 자동 감지 → 시스템 활성화
- 모델: MobileNet / YAMNet (50KB)
- 정확도: 97% (실내 소음 환경)
- 검증: 다중 폰 공간 일치 (K=10 → 오탐 0.1%)

**2. Localization AI**
- 목적: GPS 없이 실내 2~5m 측위 (집단 1~3m)
- 기술: WiFi 핑거프린팅 + IMU + Graph SLAM
- 데이터: 첫 항차 자동 학습 → 후속 항차 정확도 ↑
- 층 추정: 기압계 ±1층

**3. Survey AI**
- 목적: 패닉 상황 3초 설문 응답률 70%
- 모달리티: 터치 / 음성 / 제스처
- LLM: 12개 언어 자동 번역 + 정규화
- 결측 처리: 미응답 30%는 IMU/마이크로 추정

**4. Sensor Fusion AI**
- 목적: 28,000+ 센서 데이터 실시간 융합
- 알고리즘: Kalman Filter + Bayesian Inference
- 채널: Fire (불꽃), Smoke (연기), Damage (구조), Crowd (혼잡)
- 갱신: 5초 주기

**5. Route Optimizer AI**
- 목적: 개인별 최적 경로 + 취약계층 우선
- 알고리즘: A* Dynamic + Risk Penalty
- 건강 유형: 30개 (휠체어, 시각장애, 임산부, 노약자 등)
- 안전 마진: α=2.0 (취약계층 위험 회피 2배 가중)
- 출구 분산: 실시간 혼잡도 균형

## 7. 부록

### 7.1 기술 상세

#### A. 음향 트리거 알고리즘

**SOLAS 화재경보음 표준:**
- 주파수: 500~1000Hz
- 패턴: 0.5초 on, 0.5초 off (반복)

**모델 아키텍처:**
- MobileNetV3 (50KB)
- 입력: 1초 오디오 (16kHz, Mono)
- 출력: 이진 분류 (Fire Alarm / Other)
- 정확도: 97% (실내 소음 환경)

**오탐 방지:**
- 다중 폰 공간 일치 검증 (K=10)
- 10대 이상 동시 감지 → 트리거
- 단독 감지 → 무시 (오탐률 0.1%)

#### B. 베이지안 화재맵

**채널 정의:**
1. **Fire (불꽃):** 응답 "불꽃 보임" + 카메라 CV
2. **Smoke (연기):** 응답 "연기/냄새" + 조도 센서
3. **Damage (구조):** IMU 낙상 감지 + 응답 "길 막힘"
4. **Crowd (혼잡):** GPS 밀도 + 응답 "패닉"

**베이지안 업데이트:**
```
P(Fire|Observation) = P(Observation|Fire) × P(Fire) / P(Observation)
```

**시공간 스무딩:**
- 가우시안 필터 (σ=3m)
- 시간 감쇠 (λ=0.9, 5초마다)

#### C. 30개 유형 Health-Aware

| # | 유형 | 경로 변경 | 안내 모드 |
|---|------|----------|----------|
| 1 | 휠체어 | 엘리베이터 우선 | TTS + 진동 |
| 2 | 시각장애 | 음성 상세 | TTS + 촉각 |
| 3 | 청각장애 | 시각 우선 | 진동 + AR |
| 4 | 임산부 | 계단 회피 | TTS |
| 5 | 노약자 | 완만 경로 | TTS + 큰 글씨 |
| ... | ... | ... | ... |
| 30 | 일반 성인 | 최단 경로 | 표준 |

**α=2.0 안전 마진:**
- 취약계층: 위험 페널티 2배
- 일반: 위험 페널티 1배
