# FireNavi v2.0 → v3.0 피벗 정리서

> **작성일:** 2026-05-26 | **목적:** v2.0 자료와 v3.0 자료의 관계 정리, 자료별 톤·메시지 정렬 가이드

---

## 1. 왜 피벗했는가

### 1.1 v2.0의 치명적 약점 (사용자 검증으로 확인됨)

| 약점 | 사용자 질문에서 드러난 진실 |
|------|---------------------------|
| 3개 AI 엔진 | 신경망/RL 코드 0줄, 명칭만 마케팅 |
| 0.5초 재계산 | 실제 1~2.5초 (개별 승객 단위) |
| WiFi 2~3m 측위 | 코드·하드웨어 모두 0개 |
| 6,000명 동시 처리 | 데모는 60~120명 |
| $230K 하드웨어 비용 | 실제 $1.1~1.7M (인증·드라이독 포함) |
| 크루즈 진입장벽 | 드라이독·선급·운영부담으로 5~10년 |

### 1.2 v3.0의 본질

> **"AI 챔피언 대회와 시장 모두에서 통하려면, 하드웨어를 설치하는 것이 아니라 *이미 있는 폰*을 활용해야 한다."**

스마트폰 우선 모델은 단순한 대안이 아니라 — FireNavi의 **진짜 형태**입니다.

## 3. 자료 사용 가이드 (청중별)

### 3.1 AI 챔피언 대회 심사위원

**제시 자료:**
- `구현제안서_v3_5페이지요약.md` (메인)
- `smartphone-poc.html` (실시간 시연)
- `patent_v3/README.md` (특허 9건 포트폴리오)

**이유:** AI 챔피언 = AI 핵심성·시연 가능성·사회 임팩트 평가 → v3.0이 압도적

### 3.2 크루즈 선사·조선소 (장기 비즈니스)

**제시 자료:**
- `total_firenavi.md` (v2.0) — 학술·기술 깊이
- `구현제안서_v3_스마트폰우선.md` (v3.0 풀) — 즉시 도입 가능성
- 두 자료를 함께 제시 — "심층 기술 보유 + 즉시 도입 가능"

**이유:** 선사는 학술적 신뢰성과 즉시 적용성을 모두 요구

### 3.3 종합병원·호텔·빌딩 운영자 (단기 영업)

**제시 자료:**
- `구현제안서_v3_5페이지요약.md` (메인)
- `smartphone-poc.html` (시연)
- 가격표: $50K + 월 SaaS

**이유:** 진입장벽 낮은 시장 → 즉시 도입 메시지가 우선

### 3.4 보험사 (파트너십)

**제시 자료:**
- `pages/d-insurance-risk-model.html` (v2.0) — Monte Carlo 분석
- `구현제안서_v3_스마트폰우선.md` 4장 (보험 절감 효과)

**이유:** 보험사는 v2.0의 리스크 모델 + v3.0의 보급성을 모두 평가

### 3.5 투자자

**제시 자료:**
- `구현제안서_v3_5페이지요약.md` (메인)
- `PIVOT_v2_to_v3.md` (본 문서) — 피벗 의사결정 합리성
- TAM/SAM/SOM 비교 (v2.0 $18B → v3.0 $208B)

**이유:** 투자자는 의사결정 합리성 + 시장 확장성을 평가

| 11 | Graph SLAM (신규) | — | **Stage 2 신규 핵심** | 🆕 설계 완료 |
