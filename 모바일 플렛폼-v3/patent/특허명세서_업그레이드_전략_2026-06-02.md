# FireNavi 특허 명세서 업그레이드 전략

> **분석일:** 2026-06-02  
> **대상:** Mobile 폴더 전체 (v2.0 + v3.0 통합)  
> **목표:** v2.0 하드웨어 모델 + v3.0 스마트폰 모델의 특허 포트폴리오 통합 강화

---

## 📋 Executive Summary

### 현황 분석
- **기존 특허**: v2.0 5건 (알고리즘 중심) + v3.0 4건 (시스템 중심) = **총 9건**
- **v2.0 특허**: WiFi 기반 실내 측위 + 3AI 엔진 + 취약계층 우선 구조
- **v3.0 특허**: 음향 자동 트리거(P-A), 크라우드소싱 화재맵(P-B), 마이크로 설문(P-C), 인프라프리 측위(P-D)
- **"모바일-온톨로지 특허"**: 스마트폰 센서 + 온톨로지 지식그래프 기반 시스템 (15개 청구항)

### 핵심 문제점
1. **v2.0과 v3.0의 기술적 단절**: 하드웨어 모델에서 스마트폰 모델로의 피벗이 명확하지만, 특허 명세서에서 두 버전의 **기술적 연속성과 진화 관계**가 명확히 드러나지 않음
2. **온톨로지 특허의 독립성**: "모바일-온톨로지 특허"가 v2.0/v3.0과 별도로 존재하여, **통합 특허 전략**이 부족
3. **v3.0 특허의 깊이 부족**: P-A~P-D 4건이 초안 수준이며, 실시예·도면·청구항 구조가 v2.0 대비 약함

### 업그레이드 전략 (3단계)
1. **[Phase 1] v2.0 명세서 정제** — 과장 제거, 구현 상태 정직 표현, 소방관 배치 추천 시스템 강화
2. **[Phase 2] v3.0 명세서 완성** — P-A~P-D를 v2.0 수준으로 확장 (실시예·도면·청구항 10개 이상)
3. **[Phase 3] 통합 특허 전략** — v2.0↔v3.0 관계 명세서, 온톨로지 특허와의 연결, 출원 순서 최적화

## 📊 Part 1: 현황 분석

### 1.1 v2.0 특허 명세서 상태

#### 장점
- ✅ 청구항 15개 (독립 3개 + 종속 12개) 체계적 구조
- ✅ 실시예 2건 (크루즈 6,000명 + 빌딩 500명) 구체적
- ✅ 의사코드 3종 (A* 경로 탐색, 우선구조 점수, 보호자-취약자 동기화) 명확
- ✅ 소방관 최적 배치 추천 시스템 (청구항 11~15) 혁신적

#### 약점
| 항목 | 명세서 주장 | 실제 구현 상태 | 리스크 |
|------|------------|--------------|--------|
| 3개 AI 엔진 | "LSTM, RL 실시간 작동" | 신경망 코드 0줄, 알고리즘 프로토타입 | ⚠️ 심사관 거절 가능 |
| 0.5초 재계산 | "6,000명 0.5초 동시" | 실제 1~2.5초 (개별 승객) | ⚠️ 과장 |
| WiFi 2~3m 측위 | "삼변측량 2~3m 정밀도" | 코드·하드웨어 0개 | ⚠️ 심각 |
| 이중 모드 | "평상 모드 ↔ 비상 모드" | 설계 완료, 미구현 | ✅ 안전 |
| 소방관 배치 | "AI 추천 위치" | 알고리즘 완성, 시뮬레이션 작동 | ✅ 강력 |

#### 정정 필요 부분
1. **"3개 AI 엔진 실시간 작동"** → "3개 AI 엔진 알고리즘 프로토타입, 프로덕션 단계에서 ML 모델 통합 예정"
2. **"0.5초마다 6,000명 재계산"** → "5초마다 화재맵 갱신, 변경 시 개인 경로 즉시 보정"
3. **"WiFi 2~3m 위치추적 작동"** → "WiFi+IMU 융합으로 1~3m 목표, 기존 인프라 활용"
4. **"룸키에 WiFi 모듈 내장"** → "기존 WiFi 인프라 + 스마트폰 융합 또는 전용 디바이스 옵션"

### 1.3 "모바일-온톨로지 특허" 분석

#### 장점
- ✅ 청구항 15개, 체계적 구조
- ✅ 스마트폰 센서 활용 명확 (음향·진동·조도·WiFi·BLE·카메라 등)
- ✅ 온톨로지 지식그래프 기반 추론 강조
- ✅ 취약계층 30유형 안전 마진 계수 차별화 (α=2.0)

#### 약점
- ❌ v2.0/v3.0 특허와의 관계 불명확
- ❌ "재난 이벤트 온톨로지"가 v3.0 5단계 파이프라인과 어떻게 연결되는지 미명시
- ❌ 실시예 없음

#### 통합 가능성
- **온톨로지 특허 = v3.0의 Stage 3~5의 지식표현 계층**
- v3.0 P-B(화재맵)와 온톨로지의 "위험 온톨로지" 통합 가능
- v3.0 P-C(마이크로 설문)와 온톨로지의 "다중 외부 자극 수집부" 통합 가능

#### 3.1 v2.0↔v3.0 관계 명세서 작성

##### 제목
**"WiFi 기반 실내 측위 재난 대피 시스템의 스마트폰 전환 실시예 및 그 방법"**

##### 구성

- **청구항 2 (종속항)**: 청구항 1의 전용 디바이스를 스마트폰으로 대체한 실시예
