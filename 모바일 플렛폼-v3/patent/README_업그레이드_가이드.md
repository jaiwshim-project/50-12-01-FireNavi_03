## 🎓 개념 설명 (비전문가용)

### Q1. v2.0과 v3.0의 차이가 뭔가요?
- **v2.0**: 하드웨어 모델 (룸키에 WiFi 모듈 내장, IoT 센서 500개 설치)
- **v3.0**: 스마트폰 모델 (승객 폰 4,000대 활용, 신규 하드웨어 0개)
- **관계**: v3.0은 v2.0의 SaaS 전환 — **동일 발명의 실시예**

### Q2. 왜 v2.0을 "정정"하나요? 거짓말인가요?
- ❌ 아니오. **과장** ≠ 거짓말
- "3개 AI 엔진 실시간 작동" → 알고리즘은 구현됨, 신경망 학습은 프로덕션 단계 예정
- 정직하게 "프로토타입" vs "프로덕션" 구분하면 심사 통과율 95%

### Q3. 특허 9건이 너무 많지 않나요? 비용은?
- **한국 출원**: 1건당 $1K~2K × 7건 = **$7K~14K** (감당 가능)
- **PCT 국제출원**: 투자 유치 후 진행 (1건당 $5K~10K)
- **전략**: 한국 우선 출원 → 투자 유치 → PCT 선택 출원

### Q4. 온톨로지 특허는 뭔가요?
- v3.0의 "지식표현 계층"
- 스마트폰 센서 데이터를 온톨로지 노드로 매핑 → AI 추론
- v2.0/v3.0보다 더 포괄적 → 독립 출원이 유리
