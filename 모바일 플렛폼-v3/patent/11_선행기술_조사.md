## 2. 본 발명의 차별적 기술 요소 정리

상기 선행기술 조사 결과, 본 발명은 다음의 기술 요소에서 선행기술과 차별화된다:

### 2.1 신규성 (Novelty) 관점

1. **WiFi 룸키/출입카드 내장 전략**: 별도의 디바이스 배포 없이 기존 룸키/출입카드에 WiFi 모듈을 내장하여 전 재실자 위치 추적을 실현한 구성은 선행기술에 존재하지 않음
2. **3중 AI 엔진 동시 병렬 가동**: 예측·행동·의사결정의 3개 독립 AI 엔진을 비상시 동시 가동하는 구성은 선행기술에 존재하지 않음
3. **우선구조 디바이스 차별화**: 표준 디바이스와 우선구조 디바이스를 물리적으로 구분하고, 취약 유형·이동능력 계수·보호자 연동을 포함하는 구성은 선행기술에 존재하지 않음
4. **보호자-취약자 동기화 경로**: 보호자와 취약자의 합류 지점 산출 및 합류 후 동일 경로 생성은 선행기술에 존재하지 않음

### 2.2 진보성 (Inventive Step) 관점

1. **4요소 동적 리스크맵**: 화재·연기·구조·군집의 4가지 위험 요소를 실시간 가중합산하여 시공간적 리스크맵을 생성하는 것은, 개별 기술의 단순 조합으로는 도출이 자명하지 않음
2. **이동능력 계수(μ) 기반 건강 인지 경로**: A* 알고리즘의 비용함수에 개인별 이동능력 계수를 통합한 경로 생성은 기술적 진보에 해당
3. **이중 모드 통합 플랫폼**: 보안 모니터링과 대피 관리를 하나의 플랫폼에서 원활히 전환하는 것은 기술적 진보에 해당
4. **9개 수리 모델 통합**: Social Force, KDE, LWR, Navier-Stokes, 이류-확산, LSTM, Beer-Lambert, A*, Monte Carlo의 9개 모델을 하나의 시스템에 통합 운영하는 것은 기술적 진보에 해당

## 2. 소방관 최적 배치 시스템의 선행기술 조사

### 2.1 소방 자원 배분 및 배치 관련 선행기술

소방관의 최적 배치 위치 결정 및 우선순위 산정 관련 선행기술을 검색한 결과, 다음과 같은 현황이 확인된다:

**A. 전통적 소방 전술 (Incident Command System, ICS)**
- NFPA (National Fire Protection Association) 기준의 ICS는 현장 지휘관의 경험과 직관에 의존
- 화재 상황의 동적 변화에 따른 실시간 소방관 배치 재조정 체계 부재
- 정량적 우선순위 산정 기준의 부재로 의사결정의 일관성 및 신속성 제한

**B. AI 기반 소방 배치 시스템의 부재**
- 특허 데이터베이스(KIPRIS, Google Patents, USPTO) 검색 결과, 화재 상황에 특화된 AI 소방관 배치 추천 시스템은 발견되지 않음
- 일반 응급차량(EMS) 배치 최적화 연구는 있으나, 화재 특화 시스템은 극히 제한적

### 2.2 본 발명의 소방관 배치 시스템의 차별성

본 발명이 제공하는 소방관 최적 배치 시스템의 혁신성:

| 항목 | 종래 방식 (수동 의사결정) | 본 발명 (AI 자동화) |
|------|------------------------|--------------|
| **배치 위치 결정** | 지휘관의 경험 및 직관 | 6개 요소 가중합산 Position Score 함수 |
| **평가 요소** | 화염 유무 (이진 판단) | Upwind(40) + ExitAccess(30) - PassengerBlock(5×N) + MultiFireCover(10) - FFOverlap(20) + CorridorBonus(15) |
| **다중 화재 우선순위** | 현장 관찰 기반 (시간 소비) | 6개 지표 가중합산 Priority Score: PassengersInFire×100 + BlockedPassengers×30 + PassengersInSmoke×15 + ExitBlocked×40 + FireSize×2 - FFAssigned×80 |
| **우선순위 산정 시간** | 3~5분 (수동 회의) | 10초 이내 (AI 자동화) |
| **도달 시간** | 기준 100% | 60% (40% 단축) |
| **소방관 경로** | 화재 회피 우회 경로 | findPathFirefighter: 직진 A* 최단 경로 |
| **실시간 갱신** | 수동 재지시 | 매 time step마다 자동 재산정 |
| **시각화** | 종이 지도 또는 간단한 아이콘 | 보라색 펄스 십자 마커 + 8방향 분석 + AI 판단 이유 텍스트 |

### 2.3 Position Score와 Priority Score의 혁신성

**Position Score 함수의 혁신성:**
```
Position Score = Upwind(40) + ExitAccess(30) - PassengerBlock(5×N) 
               + MultiFireCover(10) - FFOverlap(20) + CorridorBonus(15)
```

이 함수는 다음의 실시간 동적 요소를 종합하여 최적 배치 위치를 자동 결정한다:
- 기상 요소(바람 방향)
- 건물 구조(출구 위치, 복도 여부)
- 재실자 분포(대피 중인 승객 수)
- 다중 화재(인접 화재점 동시 커버 가능성)
- 소방관 자원(이미 배치된 소방관 중복 방지)

**Priority Score 함수의 혁신성:**
```
Priority Score = PassengersInFire×100 + BlockedPassengers×30 
               + PassengersInSmoke×15 + ExitBlocked×40 
               + FireSize×2 - FFAssigned×80
```

이 함수는 인명 피해 규모, 구조 난이도, 기존 자원 배치 상황을 종합하여 객관적이고 투명한 우선순위를 산정한다.

### 2.4 소방관 전용 경로 탐색 (findPathFirefighter)의 차별성

일반 경로 탐색(findPath)과 달리, 소방관 전용 경로 탐색은:
- **화재 회피 비용 무시**: fireDangerAt 비용을 A* 알고리즘에서 제거
- **직진 진입 원칙**: 소방관의 현실적 작전 특성 (화재 직진 진입) 반영
- **우회 거리 제거**: 화재를 회피하는 우회 경로 제거로 20~30% 거리 단축

선행기술 중 소방관 특화 경로 탐색 알고리즘은 발견되지 않음.

## 4. 조사 결론

상기 선행기술 조사 결과, 본 발명의 핵심 구성요소인:

1. **재실자 대피 측면**: (1) WiFi 룸키/출입카드 내장 위치추적 전략, (2) 3중 AI 엔진 동시 병렬 가동, (3) 우선구조 디바이스에 의한 취약 계층 차별화 대피, (4) 4요소 동적 리스크맵, (5) 보호자-취약자 동기화 경로 생성, (6) 이중 모드 통합 플랫폼

2. **소방관 배치 측면** (본 발명의 신규 특징): (7) Position Score 함수에 의한 최적 배치 위치 자동화, (8) Priority Score 함수에 의한 다중 화재 우선순위 자동화, (9) findPathFirefighter 소방관 전용 경로 탐색, (10) 보라색 펄스 마커 및 8방향 분석 시각화

상기 10가지 핵심 구성요소의 조합은 선행기술에서 발견되지 않았으며, 특히 **소방관 최적 배치 추천 시스템**은 기존 선행기술에 완전히 부재한 혁신적 구성이다. 이들의 유기적 결합에 의한 기술적 효과는 당업자가 선행기술로부터 용이하게 도출할 수 없는 것으로 판단된다.

따라서 본 발명은 **신규성** 및 **진보성** 요건을 충족하며, 특히 소방관 최적 배치 시스템에서는 **완전히 새로운 기술 영역**을 개척하는 것으로 사료된다.
