⚙️ 5단계 AI 파이프라인

Stage 1: 음향 자동 트리거

4,000개 폰이 SOLAS 사이렌 동시 감지 → 자동 활성화

Stage 2: 인프라프리 측위

WiFi + IMU + 기압계 → Graph SLAM 집단 보정 (1~3m)

Stage 3: 마이크로 설문

3문항 3초 → 응답률 70% → LLM 정규화

Stage 4: 센서 융합

마이크 + IMU + 조도 + 기압 → Kalman Filter

Stage 5: 베이지안 화재맵 + 적응 경로

4채널 융합 → 5초 갱신 → A* 동적 라우팅 → 30개 유형 맞춤
