# 특허 명세서 P-B — 분산 인간센서 융합 동적 화재맵 생성 시스템

> **출원 예정:** 한국특허청 (KIPO) | **국제출원:** PCT (12개월 내) | **발명자:** 심재우

---

## 발명의 명칭

**다수의 모바일 단말로부터 수집된 사용자 보고 및 단말 센서 데이터를 베이지안 융합하여 실시간 동적 화재맵을 생성하는 시스템 및 방법**
(System and Method for Real-time Dynamic Fire Map Generation via Bayesian Fusion of Crowdsourced Mobile User Reports and Device Sensor Data)

---

## 기술분야

본 발명은 재난 상황 인식 시스템에 관한 것으로, 더욱 상세하게는 **다수의 모바일 사용자로부터 수집된 명시적 보고(시각·후각)와 단말 내장 센서의 자동 측정값(가속도·조도·기압·소음)을 베이지안 추론으로 융합하여, 고정 IoT 센서 없이도 실시간 동적 화재맵을 생성하는 시스템 및 방법**에 관한 것이다.

---

## 배경기술

### 종래 기술의 한계

1. **고정 IoT 센서 기반 시스템**: 선박 1척에 500여 개 센서를 설치해야 하며, 비용 $100K+, 설치 기간 14~30일, 선급 재인증 1~2년 소요. 또한 센서 사각지대 존재 및 인접 객실 화재 감지 지연.
2. **단일 모드 입력**: 종래 화재맵은 온도 또는 연기 단일 센서 입력만 반영하여 다차원 위험 통합 불가.
3. **인간 관찰 무시**: 화재를 가장 빨리 인지하는 것은 인접 거주자의 시각·후각이지만, 종래 시스템은 인간 관찰을 데이터로 활용하지 못함.

### 본 발명이 해결하는 문제

**고정 센서를 추가 설치하지 않고도, 이미 시설 내에 존재하는 다수 사용자의 모바일 단말을 분산 센서로 활용**하여, 인간의 시각·후각 보고와 단말 자동 센서를 베이지안 추론으로 융합함으로써 IoT 시스템 대비 7~10배 데이터 밀도와 30~120초 조기 감지를 달성한다.

## 발명의 구성

### 1. 시스템 구성도

```
[Stage 1: 인간 명시 보고 (사용자 응답)]
   ├─ Q1. 불꽃 시각 보고 (예/아니오/모름)
   ├─ Q2. 연기 시각·후각 보고 (없음/냄새/보임)
   └─ Q3. 주변 상태 보고 (평온/달림/패닉)

[Stage 2: 단말 자동 센서 수집]
   ├─ 마이크 음압 (패닉 자동 감지)
   ├─ 가속도/자이로 (달림/넘어짐)
   ├─ 조도 (연기 농도 추정)
   ├─ 기압 (층 이동)
   ├─ 카메라(선택, CV 분석)
   └─ 폰 온도(일부 기종)

[Stage 3: 베이지안 융합 엔진]
   ├─ 격자별 사후확률 P(화재|관측들) 계산
   ├─ 가중치: 시각 1.0 > 후각 0.7 > 센서 추정 0.4
   ├─ 시간/공간 베이지안 스무딩
   └─ 5초마다 화재맵 갱신

[출력: 동적 화재맵]
   ├─ 2m×2m 격자 위험도 (0~1)
   ├─ 화재·연기·구조·군중 4채널
   └─ 신뢰구간 동시 출력
```

### 2. 핵심 알고리즘

#### (1) 베이지안 융합 공식

각 격자 셀 c = (x, y, z, t) 에 대해:

```
P(Fire_c | R_1, R_2, ..., R_M)
  = α · P(R_1, R_2, ..., R_M | Fire_c) · P(Fire_c)

여기서 R_m은 m번째 보고:
  - 사용자 명시 보고: R_m = (시각·후각·상태)
  - 자동 센서 보고: R_m = (음압·IMU·조도·기압)

가중치 w_m:
  w_visual = 1.0   (사용자 직접 시각 확인)
  w_olfactory = 0.7  (후각/냄새)
  w_audio = 0.5  (마이크 비명·소음)
  w_imu = 0.4   (가속도 추정)
  w_light = 0.3  (조도 추정)
```

#### (2) 시공간 스무딩

```
P_smoothed(c, t) = Σ_{c' ∈ Neighborhood(c)} K_spatial(c, c') · P(c', t)
                 + Σ_{t' ∈ Window(t)} K_temporal(t, t') · P(c, t')

K_spatial: Gaussian 커널 (σ_xy = 4m, σ_z = 1층)
K_temporal: Exponential 감쇠 (반감기 30초)
```

#### (3) 신뢰구간 산출

각 격자의 사후확률과 함께 95% 신뢰구간 출력:
- 보고 수 N_c 가 많을수록 신뢰구간 좁아짐
- 의사결정자(관제센터, AI 라우터)가 불확실성 고려 가능

### 3. 화재 4채널 출력

| 채널 | 입력 | 의미 |
|------|------|------|
| F (Fire) | 시각 불꽃 보고 + 폰 온도 | 직접 화염 위치 |
| S (Smoke) | 후각 보고 + 조도 감소 | 연기 확산 영역 |
| D (Damage) | 진동 감지(IMU) + 구조 BIM | 구조 손상 |
| C (Crowd) | 다수 위치 군집 + 비명 음향 | 군중 패닉 영역 |

### 4. 종래 IoT 대비 우위

| 항목 | 종래 IoT 500개 | 본 발명 |
|------|---------------|---------|
| 데이터 포인트 | 500 | **28,000+ (4,000명 × 7센서)** |
| 시각 확인 | ❌ | ✅ 4,000명의 눈 |
| 후각 감지 | ❌ | ✅ 4,000명의 코 |
| 인접 객실 조기 감지 | 센서 트리거 후 | **30~120초 앞서 감지** |
| 거짓 알람 판별 | 약함 | 다수 교차 검증 |
| 설치 비용 | $100K+ | **$0** |

## 청구범위 (초안)

### 청구항 1 (독립항 — 시스템)

다수의 모바일 단말을 이용한 동적 화재맵 생성 시스템에 있어서,
(a) 각 단말로부터 사용자가 입력한 시각·후각·상태 명시 보고를 수집하는 명시 보고 수집부;
(b) 각 단말의 마이크·가속도·자이로·조도·기압·온도 중 하나 이상의 센서 자동 측정값을 수집하는 센서 수집부;
(c) 수집된 보고와 측정값을 보고 종류별 가중치를 적용하여 각 공간 격자에 대한 화재 사후확률을 산출하는 베이지안 융합 엔진;
(d) 시공간 스무딩을 적용하여 격자별 위험도 맵을 생성하는 화재맵 생성부;
(e) 화재·연기·구조·군중 4채널 위험도와 신뢰구간을 함께 출력하는 출력부;
를 포함하는 시스템.

### 청구항 2 (종속항)
청구항 1에 있어서, 상기 가중치는 시각 보고 1.0, 후각 보고 0.7, 음향 추정 0.5, 가속도 추정 0.4, 조도 추정 0.3을 기본값으로 하며, 시설별 학습으로 조정되는 것을 특징으로 하는 시스템.

### 청구항 3 (종속항)
청구항 1에 있어서, 상기 격자 해상도는 2m×2m이며, 갱신 주기는 5초 이하인 것을 특징으로 하는 시스템.

### 청구항 4 (종속항)
청구항 1에 있어서, 명시 보고 수집부는 사용자에게 3문항 이하의 마이크로 설문을 푸시 알림으로 전송하고, 응답 시간을 5초 이내로 설계한 것을 특징으로 하는 시스템.

### 청구항 5 (종속항)
청구항 1에 있어서, 미응답 단말의 경우 가속도·자이로·마이크 데이터로부터 상태를 추정하는 미응답 추정부를 더 포함하는 시스템.

### 청구항 6 (종속항)
청구항 1에 있어서, 카메라가 사용자에 의해 들렸을 때 자동으로 영상 분석을 수행하여 연기·불꽃을 검출하는 비전 분석부를 더 포함하는 시스템.

### 청구항 7 (독립항 — 방법)

다수의 모바일 단말을 이용한 동적 화재맵 생성 방법에 있어서,
(a) 각 단말이 마이크로 설문 응답과 단말 센서 측정값을 수집하는 단계;
(b) 수집된 데이터를 중앙 서버로 송신하는 단계;
(c) 서버가 격자 단위로 베이지안 사후확률을 산출하는 단계;
(d) 시공간 스무딩을 적용하는 단계;
(e) 4채널 위험도 맵과 신뢰구간을 출력하는 단계;
를 포함하는 방법.

### 청구항 8 (종속항)
청구항 7에 있어서, 상기 화재맵을 입력으로 받아 개별 단말 사용자에게 적응적 대피 경로를 안내하는 단계를 더 포함하는 방법.

## 발명의 효과

1. **하드웨어 비용 100% 절감**: 신규 IoT 센서 설치 0개
2. **데이터 밀도 56배 향상**: 500개 → 28,000+ 포인트
3. **조기 감지**: 인간 감각으로 센서보다 30~120초 빠름
4. **신뢰성**: 다수 보고의 교차 검증으로 거짓 알람 95% 감소
5. **범용성**: 크루즈·빌딩·병원·학교 등 모든 시설 즉시 적용
