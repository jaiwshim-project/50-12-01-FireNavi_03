# FireNavi v3.0 신규 특허 4건 (Smartphone-First Pivot)

> **작성일:** 2026-05-26 | **발명자:** 심재우 | **출원 예정:** 한국특허청(KIPO) → PCT 국제출원

기존 v2.0 5건 특허(알고리즘 중심)에 더해, 스마트폰 우선 아키텍처 전환에 따른 신규 시스템 특허 4건을 추가합니다.

## 4건 개요

| # | 코드 | 발명 명칭 | 핵심 청구 |
|---|------|----------|----------|
| 1 | **P-A** | 음향 자동 트리거링 재난 대피 활성화 시스템 | 다수 단말 SOLAS/NFPA 표준 경보음 동시 감지 → 공간 일치 검증 → 동시 활성화 |
| 2 | **P-B** | 분산 인간센서 융합 동적 화재맵 생성 시스템 | 사용자 명시 보고 + 폰 자동센서 베이지안 융합 → 4채널 화재맵 |
| 3 | **P-C** | 대화형 마이크로 설문 기반 군중 상태 추정 시스템 | 3문항 한도 + 다중 응답 모드 + 미응답자 센서 추정 → 100% 커버리지 |
| 4 | **P-D** | 인프라프리 실내 다층 측위 시스템 | 기존 WiFi + 폰 IMU/기압/자력 + 집단 SLAM → 신규 하드웨어 0 |

## 특허 전략

### 알고리즘(v2) + 시스템(v3) 이중 방어
- v2는 *AI 알고리즘* 자체 (예: 6유형 α=2.0 안전마진)
- v3는 *시스템 구성·운영* (예: 다수 폰 동시 활성화)
- 모방자는 알고리즘 회피 + 시스템 회피를 동시에 해야 함 → **모방 난이도 ↑↑**

### 무하드웨어 차별성 강조
- v3-P-D는 "신규 측위 전용 하드웨어를 설치하지 않고"를 명시
- 경쟁사가 BLE/UWB 인프라로 대체 시 회피 가능하나, 우리만의 SaaS 진입성 확보

### PCT 국제출원 우선국 후보
- 한국 (KR) — 기준 출원
- 미국 (US) — 시장 규모
