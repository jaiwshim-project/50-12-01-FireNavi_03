# 특허출원 준비 체크리스트

## 출원 전 최종 점검표

본 체크리스트는 특허출원 전 **반드시 확인**해야 할 항목들을 정리한 것입니다.

---

## 1. 발명의 완성도 체크

### 1.1 발명의 명칭

- [ ] 발명의 핵심 기술요소 포함 여부 확인
- [ ] 40자 이내로 작성 (한글 기준)
- [ ] 영문 명칭 번역 완료
- [ ] 변리사 검토 완료

**현재 상태**: ✅ 완료  
**명칭**: 다중 외부 자극의 온톨로지 매핑 및 신뢰도 점수 기반 재난대피 모드 자동 활성화 시스템 및 방법

---

### 1.2 기술분야

- [ ] 발명이 속하는 기술분야 명확히 기재
- [ ] IPC/CPC 분류 확인 (G08B, H04W, G06N 등)
- [ ] 적용 대상 시설 구체적 열거

**현재 상태**: ✅ 완료

---

### 1.3 배경기술

- [ ] 종래 기술의 문제점 5가지 이상 기술
- [ ] 선행기술 문헌 최소 3건 이상 인용
- [ ] 본 발명의 필요성 명확히 기술

**현재 상태**: ✅ 완료

---

### 1.4 해결하려는 과제

- [ ] 과제 5가지 이상 구체적 기술
- [ ] 각 과제별 해결 방안 명시
- [ ] 종래 기술과의 차별점 명확히 기술

**현재 상태**: ✅ 완료

---

### 1.5 과제의 해결 수단

- [ ] 5개 주요 구성부 상세 기술
- [ ] 각 구성부의 동작 원리 명확히 기술
- [ ] 수학적 모델 또는 알고리즘 포함
- [ ] 12종 트리거 구체적 열거

**현재 상태**: ✅ 완료

---

### 1.6 발명의 효과

- [ ] 정량적 효과 3가지 이상 기재 (예: 80% 감소, 30% 단축)
- [ ] 종래 기술 대비 우수성 명확히 기술
- [ ] 산업적 적용 가능성 기술

**현재 상태**: ✅ 완료

---

### 1.7 발명의 상세한 설명

- [ ] 실시예 3개 이상 기재
- [ ] 각 실시예별 시간별 동작 상세 기술
- [ ] 알고리즘 의사코드 포함
- [ ] 하드웨어/소프트웨어 구성 명시

**현재 상태**: ✅ 완료

---

## 2. 청구범위 체크

### 2.1 독립항

- [ ] 시스템 독립항 작성 완료
- [ ] 방법 독립항 작성 완료
- [ ] 5개 주요 구성부/단계 모두 포함
- [ ] 핵심 차별점 명시 (온톨로지, 신뢰도 점수, 4단계 모드)

**현재 상태**: ✅ 완료 (독립항 2개)

---

### 2.2 종속항

- [ ] 종속항 20개 이상 작성
- [ ] 12종 트리거 구체화 종속항 포함
- [ ] 센서 구체화 종속항 포함
- [ ] 온톨로지 노드 구체화 종속항 포함
- [ ] 신뢰도 점수 함수 종속항 포함
- [ ] 4가지 모드별 동작 종속항 포함
- [ ] 취약계층 우선 고려 종속항 포함

**현재 상태**: ✅ 완료 (종속항 28개)

---

### 2.3 프로그램 청구항

- [ ] 컴퓨터 판독 가능 기록 매체 청구항 포함
- [ ] 컴퓨터 프로그램 청구항 포함

**현재 상태**: ✅ 완료 (프로그램 청구항 2개)

---

### 2.4 청구항 전체 점검

- [ ] 총 청구항 수 20개 이상 (권장: 30개 이상)
- [ ] 독립항과 종속항 일대일 대응 확인
- [ ] 명세서와 청구항 용어 일치 확인
- [ ] 변리사 검토 완료

**현재 상태**: ✅ 완료 (총 32개 청구항)

---

## 3. 도면 체크

### 3.1 도면 개수

- [ ] 총 도면 10개 이상 작성
- [ ] 대표도 지정 (도 1)

**현재 상태**: ⚠️ 진행 중 (도면 10개 계획 완료, 실제 제작 필요)

---

### 3.2 도면 내용

- [ ] 도 1: 시스템 전체 구성도 (대표도)
- [ ] 도 2: 다중 외부 자극 수집부 세부 구성도
- [ ] 도 3: 재난 이벤트 온톨로지 구조도
- [ ] 도 4: 신뢰도 점수 산출 과정 흐름도
- [ ] 도 5: 4단계 재난 모드 전환 상태 전이도
- [ ] 도 6: 대피 모드 사용자 인터페이스
- [ ] 도 7: 위험지도 생성 예시
- [ ] 도 8: 구조 모드 구조대 단말 인터페이스
- [ ] 도 9: 전체 방법 흐름도
- [ ] 도 10: 실시예 1 시간별 동작 순서도

**현재 상태**: ⚠️ 진행 중 (README 작성 완료, 실제 도면 제작 필요)

---

### 3.3 도면 형식

- [ ] A4 크기 (210mm × 297mm)
- [ ] 여백 상하좌우 25mm 이상
- [ ] 선 굵기 0.3mm 이상
- [ ] 글자 크기 10pt 이상
- [ ] 고해상도 (300dpi 이상)
- [ ] 흑백 출력 가능 확인
- [ ] 부호 일치 확인 (명세서와 도면)

**현재 상태**: ⚠️ 진행 중

## 긴급 조치 필요 항목

### 1순위 (즉시 진행)
1. **도면 10개 제작** → 변리사에게 의뢰 또는 자체 제작
2. **변리사 선정 및 검토 의뢰** → 정밀 선행기술 조사
3. **신규성 상실 위험 확인** → 공개 발표 이력 점검

### 2순위 (1주일 내)
1. **출원인/발명자 정보 확정** → 서명 확보
2. **출원 시기 결정** → 신규성 상실 전 출원
3. **출원 방법 결정** → 국내 출원 우선 추천

### 3순위 (출원 전)
1. **최종 서류 검토** → 오타, 부호 일치 확인
2. **출원료 납부 준비**
3. **최종 승인 확보** → 출원인, 발명자, 변리사
