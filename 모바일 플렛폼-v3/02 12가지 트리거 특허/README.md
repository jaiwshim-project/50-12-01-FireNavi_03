## 핵심 차별점 (본 발명의 고유 기술)

### 1. 다중 외부 자극 융합 (12종 트리거)
스마트폰 센서 + 사용자 입력 + 시설 설비 + 관제센터 명령을 통합 수집

### 2. 재난 이벤트 온톨로지 매핑
이질적 신호를 통일된 의미 노드(Fire, Smoke, Panic 등)로 정규화

### 3. 신뢰도 점수 기반 교차검증
7가지 인자 종합 + 다수 단말 일치성 + 설비 교차검증으로 오경보 방지

### 4. 4단계 재난 모드 자동 전환
주의 → 확인 → 대피 → 구조 모드 자동 전환 + 히스테리시스

### 5. 대피 연동부 자동 활성화
위험지도 + 개인별 경로 + 관제센터 + 구조대 자동 연계
