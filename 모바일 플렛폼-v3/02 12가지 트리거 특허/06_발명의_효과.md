# 발명의 효과

## 1. 조기 감지 및 오경보 방지

### 종래 기술의 문제
- 시설 설비(화재감지기, 연기감지기)에만 의존하여 설비 미설치 구역 또는 설비 고장 시 감지 불가
- 단일 센서 신호로 판단하여 오작동, 허위 신고, 안전교육 영상 등으로 인한 오경보 빈번

### 본 발명의 효과
본 발명에 따르면, **12종 다중 외부 자극**(스마트폰 센서, 사용자 신고, 설비 신호, 관제센터 명령)을 융합하고, **다수 단말 일치성, 시간·공간 근접성, 교차검증**을 통해 신뢰도 점수를 산출함으로써:

- **조기 감지 능력 향상**: 공식 설비 작동 전에도 스마트폰 센서로 조기 징후 포착 가능
- **오경보 감소**: 단일 신호 오작동을 다른 신호원으로 교차검증하여 오경보율 80% 이상 감소 예상
- **설비 고장 대응**: 설비 고장 시에도 스마트폰 센서로 재난 감지 유지

**구체적 예시:**
- 크루즈선 객실에서 화재 발생 → 화재감지기 작동 전에도 스마트폰 마이크로 화재경보음 감지 + 조도 급감 감지 → **평균 30초 빠른 감지**
- 사용자 1명이 SOS 신고 → 주변 5명의 단말에서 유사 신호 없음 → 신뢰도 점수 0.5 (확인 모드) → 과도한 경보 방지

## 2. 단계별 재난 대응 및 골든타임 확보

### 종래 기술의 문제
- 재난 여부를 정상/비상으로 이진 판단하여 중간 단계 대응 부족
- 경미한 징후에도 즉시 대피 지시 → 사용자 피로도 증가 → 실제 위험 시 무시
- 관제센터 관제사가 수동으로 모드 전환 → 판단 지연 → 골든타임 놓침

### 본 발명의 효과
본 발명에 따르면, 신뢰도 점수에 따라 **주의→확인→대피→구조** 4단계 모드를 **자동으로 전환**함으로써:

- **골든타임 확보**: 자동 모드 전환으로 관제센터 판단 지연 제거 → 평균 1~2분 골든타임 확보
- **단계적 대응**: 경미한 징후는 주의/확인 모드로 처리, 실제 위험은 즉시 대피 모드 → 과도한 경보 방지
- **사용자 순응도 향상**: 불필요한 경보 감소 → 실제 위험 시 대피 순응도 향상

**구체적 예시:**
- 신뢰도 점수 0.4 → 주의 모드 → 사용자에게 경고 아이콘만 표시 → 과도한 경보 방지
- 신뢰도 점수 0.6 → 확인 모드 → 사용자에게 "연기가 나나요?" 설문 → 응답 "예" → 신뢰도 점수 0.8로 상승 → 즉시 대피 모드 전환 → **골든타임 확보**

## 3. 개인별 맞춤형 대피 안내

### 종래 기술의 문제
- 일괄 안내방송으로 개인별 위치·상태 반영 불가
- 정적 피난안내도로는 실시간 위험 위치, 혼잡도, 출구 폐쇄 상태 반영 불가
- 취약계층(휠체어, 시각장애인, 고령자, 어린이) 맞춤형 안내 부족

### 본 발명의 효과
본 발명에 따르면, **위험지도 생성부 + 개인별 경로 추천부**를 자동 활성화하여:

- **개인별 맞춤형 경로**: 사용자 위치, 위험도, 혼잡도, 취약계층 여부를 반영한 최적 경로 제공
- **실시간 경로 갱신**: 위험 위치 변화, 출구 폐쇄 시 즉시 대체 경로 제공
- **취약계층 우선 고려**: 휠체어 사용자는 경사로 우선, 시각장애인은 직선 경로 우선, 고령자는 계단 최소화
- **다중 출구 분산**: 특정 출구에 인원 집중 방지 → 병목 현상 감소 → 전체 대피 시간 단축

**구체적 예시:**
- 일반 성인 A: 3층 → 계단 → 1층 출구 A (최단 거리 90m, 예상 시간 2분)
- 휠체어 사용자 B: 3층 → 경사로 → 1층 출구 B (거리 120m이지만 계단 없음, 예상 시간 3분)
- 시각장애인 C: 3층 → 직선 복도 → 1층 출구 C (직선 경로 우선, 예상 시간 2.5분)
- **결과**: 3명 모두 안전하게 대피, 출구 A 병목 방지

## 4. 미응답자 자동 파악 및 구조 효율 향상

### 종래 기술의 문제
- 미응답자 위치 파악이 CCTV 수동 확인에 의존 → 시간 지연
- 의식 상실, 부상, 폐쇄 공간 갇힘 등 미응답자 상태 파악 곤란
- 구조 우선순위 판단이 구조대원의 경험에 의존 → 일관성 부족

### 본 발명의 효과
본 발명에 따르면, **구조 모드**에서 **미응답자, 무이동자, 취약계층, 부상 의심자**를 자동으로 파악하고 **구조 우선순위**를 자동 산정함으로써:

- **미응답자 자동 파악**: 확인 요청 30초 무응답 또는 2분 무이동 → 자동 미응답자 분류 → 관제센터 및 구조대에 즉시 전달
- **실시간 위치 추적**: 미응답자의 마지막 위치, 주변 위험도, 접근 경로를 실시간 제공
- **구조 우선순위 자동 산정**: 위험도 + 취약도 + 미응답 지속 시간을 종합하여 우선순위 점수 산출 → 구조 효율 극대화
- **최적 접근 경로 제공**: 구조대 현재 위치 → 구조 대상까지 최단 안전 경로 제공

**구체적 예시:**
- 휠체어 사용자 D: 3층 객실 → 30초 무응답 → 주변 위험도 0.9 (화재 근접) → 구조 우선순위 점수 0.95 → **최우선 구조 대상**
- 일반 성인 E: 4층 복도 → 2분 무이동 → 주변 위험도 0.5 (연기 약간) → 구조 우선순위 점수 0.6 → **2순위 구조 대상**
- **결과**: 구조대가 D를 먼저 구조 → 생명 구조 성공률 향상

## 5. 재난 이벤트 온톨로지 기반 일관된 상황 인식

### 종래 기술의 문제
- 이질적 신호(센서, 설비, 사용자 신고)를 통합하는 표준 구조 부족
- 원시 신호를 재난 의미로 변환하는 온톨로지 구조 없음
- 예: "화재경보음", "연기감지기 신호", "사용자 '불' 신고"가 모두 같은 화재를 의미하지만 별도 처리

### 본 발명의 효과
본 발명에 따르면, **재난 이벤트 온톨로지**를 통해 이질적 신호를 **통일된 의미 노드**로 정규화함으로써:

- **일관된 상황 인식**: Fire, Smoke, Explosion, Panic 등의 의미 노드로 정규화 → 재난 유형 명확화
- **추론 규칙 적용**: Fire 노드 발생 → 연기 확산 예측 → Smoke 노드 자동 활성화 → 선제적 대응
- **다중 신호 융합 용이**: 동일 의미 노드에 매핑된 신호들의 신뢰도 점수를 종합 → 융합 처리 간소화
- **확장성**: 새로운 센서 추가 시 온톨로지 매핑 규칙만 추가 → 시스템 전체 재설계 불필요

**구체적 예시:**
- 화재경보음 → Fire 노드
- 연기감지기 신호 → Smoke 노드
- 사용자 "불" 신고 → Fire 노드
- 시스템: Fire 노드 + Smoke 노드 → 화재 확정 → 대피 모드 전환

## 6. 관제센터 및 구조대 연계 강화

### 종래 기술의 문제
- 재난 감지와 관제센터 알림이 별도 시스템 → 연동 지연
- 구조대에 실시간 정보 제공 부족 → 구조 효율 저하

### 본 발명의 효과
본 발명에 따르면, **관제센터 연동부 + 구조대 연계부**를 자동 활성화하여:

- **실시간 정보 공유**: 재난 발생 구역, 사용자 분포, 미응답자 위치를 관제센터 및 구조대에 실시간 전송
- **대피 진행 상황 모니터링**: 대피 완료율, 남은 인원, 위험지도를 관제센터에 실시간 표시
- **구조 우선순위 공유**: 구조 대상 목록, 우선순위 점수, 접근 경로를 구조대 단말에 실시간 표시
- **양방향 통신**: 관제센터 운영자가 수동 명령(전체 대피 지시, 출구 폐쇄 알림) 발령 가능 → 시스템에 즉시 반영

**구체적 예시:**
- 관제센터 화면: 3층 구역 A 화재 발생 (신뢰도 0.8) → 사용자 50명 분포 → 미응답자 3명 위치 표시 → 대피 완료율 60%
- 구조대 단말: 구조 대상 3명 목록 → 우선순위 1위: D (3층 객실, 위험도 0.9) → 최적 접근 경로 표시
- **결과**: 관제센터와 구조대 간 실시간 협력 → 구조 효율 극대화

## 7. 다중이용시설 맞춤형 적용

### 본 발명의 효과
본 발명은 다음과 같은 다중이용시설에 즉시 적용 가능하며, 각 시설의 특성을 반영한 맞춤형 대응이 가능하다.

| 시설 유형 | 특성 | 본 발명의 적용 효과 |
|-----------|------|---------------------|
| 크루즈선 | 복잡한 내부 구조, 객실 미응답자 | 객실별 미응답자 자동 파악 → 우선 구조 |
| 초고층 빌딩 | 수직 연기 확산, 엘리베이터 사용 불가 | 층별 상향/하향 대피 방향 자동 결정 |
| 대형 공연장 | 군중 밀집, 패닉 위험 | 다중 출구 분산 → 병목 방지 → 압사 위험 감소 |
| 복합 지하철역 | 지하 공간, 외국인 많음 | 지상 출구 우선 안내 + 다국어 지원 |
| 병원 | 이동 불가 환자, 의료 장비 | 환자 우선 구조 + 의료 장비 고려 경로 |
| 학교 | 어린이, 보호자 동기화 | 교사-학생 페어링 → 보호자 동기화 경로 |

## 8. 종합 효과

본 발명에 따르면:

1. **생명 안전 최우선**: 조기 감지 + 골든타임 확보 + 미응답자 자동 파악 → 생명 구조율 향상
2. **오경보 방지**: 신뢰도 점수 기반 교차검증 → 오경보율 80% 이상 감소
3. **대피 효율 향상**: 개인별 맞춤형 경로 + 실시간 갱신 → 전체 대피 시간 30% 단축 예상
4. **구조 효율 향상**: 구조 우선순위 자동 산정 + 최적 접근 경로 제공 → 구조 시간 40% 단축 예상
5. **관제센터 부담 감소**: 자동 모드 전환 + 실시간 정보 공유 → 관제센터 인력 부담 50% 감소 예상
6. **확장성 및 적용성**: 다양한 다중이용시설에 즉시 적용 가능
7. **사회적 가치**: 재난 안전 인프라 고도화 → 국민 안전 체감도 향상

본 발명은 다중이용시설의 재난 대응 능력을 획기적으로 향상시켜, **생명 안전을 최우선**으로 보호하는 혁신적 시스템 및 방법을 제공한다.
