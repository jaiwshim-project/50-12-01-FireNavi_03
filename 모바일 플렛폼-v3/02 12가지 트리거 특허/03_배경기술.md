# 배경기술

## 종래 기술의 문제점

### 1. 시설 설비 의존형 재난 감지 시스템

기존 재난 감지 및 피난 안내 시스템은 주로 **시설에 설치된 화재감지기, 연기감지기, 스프링클러, 안내방송, 정적 피난안내도, CCTV 관제**에 의존한다.

#### 장점
- 공식 설비 신호를 기반으로 하므로 일정한 신뢰성 확보
- 화재안전기준에 따라 설치 및 점검 의무화
- 관제센터와의 연동 구조 확립

#### 문제점
- **설비 미설치 구역**: 임시 공간, 외부 통로, 주차장 등에서는 감지 불가
- **설비 고장 시**: 센서 오작동, 배터리 방전, 통신 두절 시 감지 실패
- **초기 징후 감지 불가**: 공식 설비는 일정 기준(연기 농도, 온도 상승) 이상에서만 작동하므로 조기 징후 놓침
- **동적 상황 반영 불가**: 군중 이동, 출구 폐쇄, 혼잡도, 미응답자 상태 등 동적 상황 파악 곤란

**사례:**
- 2022년 이태원 압사 사고: 화재감지기는 정상이었으나 군중 밀집도 감지 불가
- 2014년 세월호 참사: 선박 설비는 작동했으나 실제 승객 위치 및 미응답 상태 파악 실패

---

### 2. 단일 센서 기반 스마트폰 안전 앱

일부 스마트폰 안전 앱은 **사용자의 수동 신고** 또는 **단일 센서 신호**(예: 가속도계 낙상 감지)에 의존한다.

#### 장점
- 사용자가 직접 위험 상황 신고 가능
- 스마트폰 보급률 높아 접근성 우수

#### 문제점
- **수동 신고 의존**: 사용자가 앱을 실행하지 않으면 재난 발생 감지 불가
- **허위 신고 위험**: 실제 재난인지 허위 신고인지 판단 어려움
- **센서 오류**: 단일 센서 신호는 오작동 가능성 높음 (예: 휴대폰 떨어뜨림 → 낙상 오인)
- **교차검증 부재**: 다른 센서 신호 또는 설비 신호와 교차검증 구조 없음
- **대피 안내 부재**: 단순 신고 기능만 있고 개인별 대피 경로 안내 없음

**사례:**
- 긴급 구조 요청 앱: 신고 버튼을 누르지 않으면 작동 불가
- 낙상 감지 앱: 단일 가속도계 신호로만 판단하여 오작동 빈번

### 3. 다중이용시설의 복합 재난 대응 한계

대형 공연장, 크루즈선, 초고층 빌딩, 복합 지하철역과 같은 다중이용시설에서는 **화재, 정전, 지진, 테러, 압사 위험, 출구 폐쇄, 군중 패닉** 등이 복합적으로 발생할 수 있다.

#### 문제점
- **단일 감지기 한계**: 화재감지기는 화재만 감지, 정전·압사·패닉은 감지 불가
- **안내방송 한계**: 일방향 방송으로 개인별 위치·상태 반영 불가
- **정적 피난안내도**: 실시간 위험 위치, 군중 이동 상태, 출구 폐쇄 상태 반영 불가
- **취약계층 고려 부족**: 휠체어 사용자, 시각장애인, 어린이, 외국인 등 맞춤형 안내 부족
- **미응답자 파악 불가**: 의식 상실, 부상, 폐쇄 공간 갇힘 등 미응답자 위치 파악 어려움

**사례:**
- 2017년 런던 그렌펠 타워 화재: 정전으로 인해 안내방송 중단, 미응답자 위치 파악 실패
- 2003년 대구 지하철 화재: 연기로 인해 시야 차단, 출구 위치 혼선

---

### 4. 재난 신호 표준화 및 융합 부재

기존 시스템은 **이질적인 신호**(센서 데이터, 사용자 신고, 설비 신호, 관제센터 명령)를 통합하여 재난 상황을 종합 판단하는 구조가 부족하다.

#### 문제점
- **신호 표준화 부재**: 센서별, 설비별로 신호 형식이 달라 통합 처리 어려움
- **의미 추론 부재**: 원시 신호(Raw Signal)를 재난 의미로 변환하는 온톨로지 구조 없음
- **교차검증 부재**: 단일 신호만으로 재난 판단 시 오경보 위험
- **신뢰도 평가 부재**: 신호원별 신뢰도 차이를 반영한 가중치 부여 없음

**사례:**
- 스마트폰 마이크로 화재경보음 감지 → 실제 화재인지, 안전교육 영상인지 구분 불가
- 사용자 SOS 신고 → 실제 위험인지, 오작동인지 교차검증 없음

---

### 5. 재난 모드 단계화 및 자동 활성화 부재

종래 시스템은 **재난 여부를 이진 판단**(정상 / 비상)하는 경우가 많아, **경미한 징후**와 **실제 위험** 사이의 단계적 대응이 부족하다.

#### 문제점
- **과도한 경보**: 경미한 징후에도 즉시 대피 지시 → 사용자 피로도 증가, 실제 위험 시 무시
- **과소한 경보**: 징후를 무시하다가 늦게 대피 → 골든타임 놓침
- **모드 전환 수동**: 관제센터 관제사가 수동으로 모드 전환 → 지연 발생
- **개인별 차별화 부재**: 모든 사용자에게 동일한 안내 → 위치·상태 반영 불가

**사례:**
- 화재 초기 징후 발생 → 즉시 전체 대피 명령 → 허위 경보로 판명 → 다음 재난 시 무시
- 화재 징후 감지 후 관제센터 확인 대기 → 확산 후 대피 지시 → 골든타임 놓침

## 선행기술 현황

### 국내 선행기술

#### 1. 한국공개특허 제10-2020-0123456호 (가상)
**제목**: 화재 감지 시스템 및 방법  
**내용**: 화재감지기와 연기감지기 신호를 이용한 화재 감지  
**한계**: 시설 설비에만 의존, 스마트폰 센서 활용 없음, 온톨로지 매핑 없음

#### 2. 한국공개특허 제10-2021-0098765호 (가상)
**제목**: 스마트폰 기반 긴급 신고 시스템  
**내용**: 사용자가 앱에서 SOS 버튼을 누르면 관제센터에 신고  
**한계**: 수동 신고 의존, 교차검증 없음, 대피 경로 안내 없음

#### 3. 한국공개특허 제10-2022-0111222호 (가상)
**제목**: 실내 위치 기반 대피 경로 안내 시스템  
**내용**: WiFi 기반 실내 측위 후 미리 저장된 대피 경로 제공  
**한계**: 재난 감지 기능 없음, 실시간 위험 지도 갱신 없음, 신뢰도 점수 개념 없음

---

### 국제 선행기술

#### 1. US 2020/0123456 A1 (가상)
**Title**: Fire Detection System Using IoT Sensors  
**Content**: IoT 센서 네트워크를 이용한 화재 감지  
**Limitation**: 고정 센서 의존, 모바일 기기 활용 없음, 온톨로지 매핑 없음

#### 2. US 2021/0098765 A1 (가상)
**Title**: Emergency Alert System for Mobile Devices  
**Content**: 모바일 기기에서 비상 알림 수신 및 표시  
**Limitation**: 단방향 알림만 제공, 센서 신호 수집 없음, 대피 경로 안내 없음

#### 3. EP 3456789 A1 (가상)
**Title**: Crowd Monitoring System Using Smartphone Sensors  
**Content**: 스마트폰 센서를 이용한 군중 밀집도 모니터링  
**Limitation**: 밀집도 감지만 수행, 재난 모드 전환 없음, 개인별 경로 안내 없음

## 종래 기술의 핵심 문제 요약

| 문제점 | 종래 기술 | 본 발명의 해결 방안 |
|--------|-----------|---------------------|
| 설비 의존 | 고정 센서만 사용 | 스마트폰 센서 + 설비 신호 융합 |
| 초기 징후 감지 불가 | 일정 기준 이상에서만 감지 | 다중 신호 조기 수집 및 온톨로지 매핑 |
| 오경보 위험 | 단일 신호 의존 | 신뢰도 점수 기반 교차검증 |
| 단계적 대응 부재 | 정상/비상 이진 판단 | 주의→확인→대피→구조 4단계 모드 |
| 개인별 안내 부재 | 일괄 안내방송 | 위치·상태 기반 개인별 경로 추천 |
| 미응답자 파악 불가 | CCTV 수동 확인 | 자동 미응답자 위치 추적 및 구조대 연계 |

---

## 본 발명의 필요성

위와 같은 종래 기술의 한계를 극복하기 위해, 본 발명은:

1. **다중 외부 자극 수집**: 스마트폰 센서, 사용자 신고, 설비 신호, 관제센터 명령을 통합 수집
2. **재난 이벤트 온톨로지 매핑**: 이질적 신호를 재난 의미 노드로 정규화
3. **신뢰도 점수 산출**: 다수 단말 일치성, 시간·공간 근접성, 교차검증을 통한 오경보 방지
4. **단계별 재난 모드 자동 전환**: 주의→확인→대피→구조 모드 자동 결정
5. **대피 연동부 자동 활성화**: 위험지도, 개인별 경로, 관제센터, 구조대 연계 자동 실행

을 통해 다중이용시설의 재난 대응 능력을 획기적으로 향상시키는 시스템 및 방법을 제공한다.
