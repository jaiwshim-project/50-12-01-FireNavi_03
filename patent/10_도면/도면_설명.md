# 도면 설명 (Drawing Descriptions)

## 도면 1: 시스템 구성도 (System Architecture Diagram)

화이어내비(FireNavi) 시스템의 전체 구성을 나타내는 블록도.

| 부호 | 명칭 | 설명 |
|------|------|------|
| 100 | 데이터 수집부 | 센서 및 장치로부터 데이터를 수집하는 모듈 |
| 101 | IoT 센서 | 온도, 연기, CCTV 등 화재 감지 센서 |
| 102 | WiFi 비콘 | 실내 위치 측위를 위한 WiFi 비콘 장치 |
| 110 | 표준 장치 (Standard Device) | 일반 탑승객/이용자용 수신 장치 |
| 120 | 우선구조 장치 (Priority Rescue Device) | 거동불편자, 어린이 등 우선 구조 대상자용 장치 (점선 표시) |
| 200 | AI 엔진부 | 3종 AI 엔진으로 구성된 분석 모듈 |
| 210 | Prediction Engine | 화재/연기 확산 예측 엔진 |
| 220 | Behavior Engine | 군중 행동 분석 엔진 |
| 230 | Decision Engine | 최적 대피 의사결정 엔진 |
| 300 | 동적 리스크맵 생성부 | R(x,y,t) 함수 기반 실시간 위험도 맵 생성 |
| 400 | 플랫폼 모드 관리부 | 평상시/비상시 모드 전환 관리 |
| 410 | Normal Mode | 평상시 운영 모드 |
| 420 | Emergency Mode | 비상시 대피 모드 |
| 500 | 시각화 및 안내부 | 대피 경로 시각화 및 사용자 안내 |

## 도면 2: 처리 흐름도 (Processing Flowchart)

화이어내비 시스템의 데이터 처리 및 대피 안내 절차를 나타내는 흐름도.

| 부호 | 명칭 | 도형 | 설명 |
|------|------|------|------|
| S100 | 센서 데이터 수집 | 사각형 | IoT 센서로부터 데이터 수집 |
| S200 | WiFi 위치 파악 | 사각형 | WiFi 비콘 기반 실내 위치 측위 |
| S300 | 화재 감지? | 마름모 | 화재 발생 여부 판단 분기점 |
| S310 | Normal Mode 유지 | 사각형 | 화재 미감지 시 평상 모드 유지 (S100으로 루프) |
| S400 | Emergency Mode 전환 | 사각형 | 화재 감지 시 비상 모드로 전환 |
| S410 | 3 AI 엔진 동시 가동 | 사각형 | Prediction, Behavior, Decision 엔진 병렬 가동 |
| S420 | 동적 리스크맵 생성 | 사각형 | R(x,y,t) 기반 실시간 위험도 맵 생성 |
| S430 | 우선구조 대상 식별 | 사각형(점선) | 거동불편자 등 우선 구조 대상 식별 (점선 강조) |
| S440 | 개인별 대피 경로 생성 | 사각형 | A* 알고리즘 기반 개인별 최적 대피 경로 생성 |
| S450 | 상황 변화? | 마름모 | 화재 상황 변화 여부 판단 분기점 |
| S460 | 대피 완료 판정 | 사각형 | 전원 대피 완료 여부 판정 |
| S500 | 통계 및 보고 | 타원 | 대피 결과 통계 생성 및 보고 (종료) |

## 도면 3: 데이터 흐름도 (Data Flow Diagram)

시스템 내 데이터의 변환 및 흐름을 나타내는 다이어그램.

### Input Layer (입력 계층)
| 부호 | 명칭 | 설명 |
|------|------|------|
| 101 | 센서 데이터 | 온도, 연기, CCTV 영상 데이터 |
| 102 | WiFi 신호 | 실내 위치 측위 데이터 |
| 110 | 표준 장치 ID | 일반 이용자 장치 식별자 |
| 120 | 우선구조 장치 ID | 우선 구조 대상 장치 식별자 (점선 표시) |

### Processing Layer (처리 계층)
| 부호 | 명칭 | 입력 → 출력 |
|------|------|-------------|
| 210 | Prediction Engine | 센서 데이터 → 화재 위험도 (F) |
| 220 | Behavior Engine | 군중 밀도 데이터 → 행동 분석 (D) |
| 230 | Decision Engine | 위치/장치 데이터 → 위치 매핑 (S, C) |
| 300 | 동적 리스크맵 통합 | R(x,y,t) = w1*F + w2*S + w3*D + w4*C |
| 400 | 모드 관리부 | 리스크맵과 연동하여 모드 제어 |

### Output Layer (출력 계층)
| 부호 | 명칭 | 설명 |
|------|------|------|
| 500 | 우선구조 대피경로 | 우선 구조 대상 전용 경로 (점선 화살표) |
| 500 | 표준 대피경로 | 일반 이용자 대피 경로 (실선 화살표) |
| 500 | 보안 알림 | 관리자/소방 당국 알림 |
| 500 | 통계/보고 | 대피 결과 통계 데이터 |

---

### 범례 (Legend)
- **실선 사각형**: 일반 구성요소/프로세스
- **점선 사각형**: 우선구조 관련 구성요소 (특별 식별)
- **실선 화살표**: 일반 데이터 흐름
- **점선 화살표**: 우선구조 데이터 흐름
- **마름모**: 판단/분기점
- **타원**: 시작/종료
