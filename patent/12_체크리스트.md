## 2. 청구범위 검토 사항

### 2.1 형식 검토

- [ ] 독립항이 방법·시스템·기록매체의 3가지 카테고리를 포함하는가
- [ ] 종속항이 독립항의 범위를 적절히 한정하는가
- [ ] 각 청구항이 하나의 문장으로 기재되었는가
- [ ] "~에 있어서", "~를 포함하는", "~것을 특징으로 하는" 등 정형 표현을 사용하였는가
- [ ] 청구항에 사용된 용어가 발명의 상세한 설명에 기재된 용어와 일치하는가
- [ ] 참조 부호(100, 200 등)가 청구항에 괄호로 표기되었는가

### 2.2 내용 검토

- [ ] 독립항 1(방법)이 본 발명의 핵심 단계 (a)~(h)를 빠짐없이 포함하는가
- [ ] 독립항 5(시스템)가 모든 핵심 구성부(100~500)를 포함하는가
- [ ] 종속항이 독립항과 중복되지 않으면서 추가적 한정을 제공하는가
- [ ] 청구 범위가 지나치게 넓거나 좁지 않은가
- [ ] 수식(R(x,y,t), P_score 등)이 정확히 기재되었는가
- [ ] 가중치 값(w₁=0.35 등)의 구체적 수치가 독립항이 아닌 종속항 또는 상세한 설명에 기재되었는가

### 2.3 권리 범위 검토

- [ ] 크루즈선뿐 아니라 빌딩·공항·지하철 등에도 적용 가능하도록 "대규모 밀폐 구조물"로 상위 개념화하였는가
- [ ] WiFi 이외의 무선 측위 기술(BLE, UWB 등)로의 변형 실시가 가능하도록 기재하였는가
- [ ] 회피 설계 가능성을 최소화하기 위해 핵심 구성요소의 기능적 표현을 포함하였는가

## 3. 도면 요구사항 (특허청 규정)

### 3.1 필수 도면

| 도면 번호 | 내용 | 상태 |
|-----------|------|------|
| 도면 1 | 시스템 전체 구성도 (블록 다이어그램) | ⬜ 확인필요 |
| 도면 2 | 처리 흐름도 (플로우차트, S100~S500) | ⬜ 확인필요 |
| 도면 3 | 데이터 구조도 | ⬜ 확인필요 |

### 3.2 KIPO 도면 규격

- [ ] 용지 크기: A4 (210mm × 297mm)
- [ ] 여백: 상 2.5cm, 하 1cm, 좌 2.5cm, 우 1.5cm
- [ ] 도면 번호: 각 도면 하단에 "【도면 1】" 등으로 표기
- [ ] 선 두께: 명확하게 판독 가능한 흑백 선화
- [ ] 참조 부호: 아라비아 숫자 사용, 상세한 설명과 일치
- [ ] 문자: 도면 내 최소한의 텍스트만 사용, 한글 또는 영문
- [ ] 색상: 흑백 원칙 (컬러 도면은 별도 허가 필요)
- [ ] 해상도: 전자출원 시 300dpi 이상 권장

## 4. 신규성·진보성 자가 평가

### 4.1 신규성 평가

| 핵심 구성요소 | 선행기술 존재 여부 | 판정 |
|--------------|-------------------|------|
| WiFi 룸키/출입카드 내장 위치추적 | 미발견 | ✅ 신규 |
| 3중 AI 엔진 동시 병렬 가동 | 미발견 | ✅ 신규 |
| 우선구조 디바이스 (5유형, μ계수) | 미발견 | ✅ 신규 |
| 4요소 동적 리스크맵 R(x,y,t) | 미발견 | ✅ 신규 |
| 보호자-취약자 동기화 경로 | 미발견 | ✅ 신규 |
| Normal/Emergency 이중 모드 | 유사 개념 존재 | ⚠️ 종속항 수준 |
| A* 경로탐색 | 공지 기술 | ❌ 단독 불가 → 위험도 가중 변형으로 청구 |

### 4.2 진보성 평가

- **기술적 과제의 비자명성**: 화재 대피에서 4요소 동적 리스크맵과 개인별 이동능력 계수를 A* 알고리즘에 통합하는 발상은 당업자에게 자명하지 않음
- **효과의 현저성**: 크루즈선 6,000명 시나리오에서 대피 시간 약 35% 단축, 취약 계층 조기 대피 달성이라는 현저한 효과
- **구성의 유기적 결합**: 9개 수리 모델과 2종 디바이스, 이중 모드 운영의 유기적 결합은 단순 조합이 아닌 기술적 창작에 해당

## 5. 출원 절차 (특허로 patent.go.kr)

### 5.1 출원 전 준비

| 단계 | 내용 | 비고 |
|------|------|------|
| 1 | 특허로 회원가입 및 공동인증서 준비 | patent.go.kr |
| 2 | 특허고객번호 발급 | 출원인 식별번호 |
| 3 | 명세서 최종 검토 | 전체 서류 정합성 확인 |
| 4 | 도면 파일 준비 | TIFF 또는 PDF 형식 |

### 5.2 전자출원 절차

| 단계 | 내용 | 소요 시간 |
|------|------|-----------|
| 1 | 특허로 로그인 → 전자출원 → 특허출원 | - |
| 2 | 출원서 작성 (출원인·발명자 정보 입력) | 30분 |
| 3 | 명세서·청구범위·요약서·도면 첨부 | 30분 |
| 4 | 수수료 납부 | 10분 |
| 5 | 출원 접수 확인 및 출원번호 부여 | 즉시 |

### 5.3 출원 후 절차 타임라인

```
출원일 (D-day)
  │
  ├─ 출원 공개: 출원일로부터 1년 6개월 후 (조기공개 신청 가능)
  │
  ├─ 심사청구 기한: 출원일로부터 3년 이내
  │   └─ 우선심사 신청 가능 (요건 충족 시 2~4개월 내 심사)
  │
  ├─ 심사 착수: 심사청구일로부터 약 12~18개월
  │
  ├─ 의견제출통지서(OA) 수령: 심사 착수 후 약 2~3개월
  │   └─ 응답 기한: 통지일로부터 2개월 (연장 가능)
  │
  ├─ 등록결정 또는 거절결정
  │   ├─ 등록결정 시: 등록료 납부 후 등록
  │   └─ 거절결정 시: 거절결정 불복심판 (30일 이내)
  │
  └─ 특허 등록 및 공고
```

- **개인 출원인**: 중소기업이 아닌 개인의 경우 출원료·심사청구료 70% 감면 적용
- **감면 신청**: 출원 시 수수료 감면 신청서 함께 제출
- **근거 법령**: 특허법 시행규칙 별표 (수수료 감면 규정)

## 7. 최종 점검 사항

### 7.1 출원 전 최종 체크

- [ ] 발명의 명칭이 발명 내용을 명확히 표현하는가
- [ ] 청구범위의 용어가 상세한 설명의 용어와 일치하는가
- [ ] 도면의 참조 부호가 상세한 설명과 일치하는가
- [ ] 요약서가 400자 이내인가
- [ ] 대표도가 지정되어 있는가 (도면 1)
- [ ] 발명자·출원인 정보가 정확한가
- [ ] 선행기술 조사 결과 신규성·진보성에 문제가 없는가
- [ ] 변형 실시예가 충분히 기재되어 권리 범위를 뒷받침하는가
- [ ] 수식·알고리즘이 정확히 기재되었는가
- [ ] 오탈자 및 참조 부호 불일치가 없는가

### 7.2 유의사항

- **출원일 확보**: 명세서·청구범위·도면이 모두 준비된 후 출원하여 완전한 출원일을 확보할 것
- **공지 예외 적용**: 출원 전 발명 내용을 공개(논문, 발표, 웹사이트 등)한 경우, 공개일로부터 12개월 이내에 공지 예외 적용 신청 필요
- **영문 출원 고려**: 해외 출원(PCT)을 계획하는 경우, 국내 출원일로부터 12개월 이내에 PCT 출원 필요
- **프로그램 저작권 등록**: 소프트웨어 소스코드에 대한 프로그램 저작권 등록을 병행하면 이중 보호 가능
