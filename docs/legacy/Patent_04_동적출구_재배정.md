# 특허 명세서 — PAT-NEW-04

## 발명의 명칭

**화재 대피 시 출구별 예상 도착 인원에 비례하는 혼잡 페널티를 실시간 갱신하여 전체 대피 완료 시간을 최소화하는 동적 출구 재배정 방법**

---

## 기술분야

본 발명은 화재 대피 시스템에서의 출구 배정 최적화 기술에 관한 것으로, 보다 구체적으로는 각 출구에 배정된 예상 도착 인원 수에 비례하는 혼잡 페널티(CrowdPenalty)를 경로 비용 함수에 실시간으로 반영하여, 대피자가 자동으로 덜 혼잡한 출구로 분산되도록 하고, 화재 진행에 따른 출구 차단 시 잔여 출구로의 즉각 재배정을 수행하는 방법에 관한 것이다.

---

## 배경기술

대규모 시설(크루즈선, 초고층 빌딩)에는 복수의 비상 출구가 존재한다. 종래의 대피 시스템은 각 대피자를 최근접 출구에 배정한다. 이 방식의 문제점은:

1. 특정 출구에 인원이 과도하게 집중되어 극심한 병목이 발생한다.
2. 병목에 의해 전체 대피 완료 시간이 최근접 배정 대비 40~60% 증가한다.
3. 화재 진행으로 출구가 차단되면, 해당 출구에 배정된 수백 명의 경로가 즉시 무효화되나 재배정이 지연된다.

기존 연구에서 출구 배정 최적화는 주로 사전 계획(pre-plan) 방식으로, 대피 시작 전에 최적 배정을 계산한다. 그러나 화재는 동적으로 변화하므로 사전 계획은 즉시 무효화된다. 실시간으로 출구 배정을 갱신하면서 대피자 간 충돌까지 고려하는 통합 방법은 제시되지 않았다.

---

## 해결하려는 과제

본 발명은 출구별 예상 도착 인원 수에 비례하는 혼잡 페널티를 정의하고, 이를 경로 비용 함수에 실시간으로 반영하여, 추가적인 전역 최적화 연산 없이도 대피자가 자연스럽게 분산되는 자기 균형(Self-Balancing) 메커니즘을 제공하는 것을 목적으로 한다.

---

## 과제의 해결수단

### 1. CrowdPenalty 정의 및 도출

#### 1.1 CrowdPenalty 공식

```
CrowdPenalty(exit_j) = N_assigned(exit_j) × κ
```

- `N_assigned(exit_j)`: 출구 j에 현재까지 배정된 대피자 수
- `κ`: 인당 지연 계수 (초)

#### 1.2 κ의 도출

κ는 출구의 통과 용량(throughput)으로부터 도출된다.

```
출구 통과 용량 = W × φ (명/초)
여기서:
  W = 출구 폭 (m)
  φ = 단위 폭당 통과률 (명/m/초)
      = 1.3 명/m/초 (SFPE 핸드북 권장값)

1인 추가 시 통과 대기 시간 증가분:
  Δt = 1 / (W × φ)

표준 출구 (W=1.2m):
  Δt = 1 / (1.2 × 1.3) = 0.641초

안전 마진 및 혼잡 시 비선형 지연을 고려하여
정수 근사: κ = 40초

κ = 40의 물리적 의미:
  출구 j에 100명이 배정된 경우
  CrowdPenalty = 100 × 40 = 4000
  이는 경로 비용에 4000이 추가됨을 의미하며,
  직선 거리로 약 400m를 추가 이동하는 것과 동등한 비용이다.
  따라서 400m 이내에 덜 혼잡한 출구가 있다면
  A* 알고리즘이 자동으로 그 출구를 선택한다.
```

#### 1.3 κ의 출구별 차등 적용

출구 폭이 다른 경우 κ를 차등 적용한다:

```
κ(exit_j) = κ_base × (W_standard / W_j)

여기서:
  κ_base = 40 (표준 출구 기준)
  W_standard = 1.2m
  W_j = 출구 j의 실제 폭

예시:
  폭 2.4m 출구: κ = 40 × (1.2/2.4) = 20 → 절반의 페널티
  폭 0.9m 출구: κ = 40 × (1.2/0.9) = 53 → 더 큰 페널티
```

### 2. 자기 균형 메커니즘

CrowdPenalty가 경로 비용 함수에 포함됨으로써 전역 최적화 없이 자기 균형이 달성된다.

#### 2.1 경로 비용 함수에의 통합

```
f(n, exit_j, person_i) = g(n) + h(n, exit_j)
                         + α_i × [w₁F(n) + w₂S(n)]
                         + w₃D(n) + w₄C(n)
                         + CrowdPenalty(exit_j)
```

#### 2.2 자기 균형 작동 원리

```
[초기 상태]
  출구 A: 가까움, N_assigned=0, CrowdPenalty=0
  출구 B: 멀음,   N_assigned=0, CrowdPenalty=0
  → 대피자 1~50: 출구 A가 총비용 최소 → 출구 A 배정

[중간 상태]
  출구 A: 가까움, N_assigned=50, CrowdPenalty=2000
  출구 B: 멀음,   N_assigned=0,  CrowdPenalty=0
  → 대피자 51: 출구 A 총비용 = 200(거리) + 2000(혼잡) = 2200
              출구 B 총비용 = 500(거리) + 0(혼잡) = 500
  → 출구 B가 총비용 최소 → 출구 B 배정

[균형 상태]
  각 출구의 총비용이 수렴하여 추가 배정이 자동 분산됨
```

이 메커니즘의 핵심은 **중앙 집중식 전역 최적화를 수행하지 않고도**, 각 대피자가 자신의 비용 함수만으로 최적 출구를 선택하면 **전체 시스템이 자동으로 균형에 수렴**한다는 것이다.

#### 2.3 수렴 증명

```
정리: CrowdPenalty가 N_assigned에 비례할 때,
      모든 대피자의 배정이 완료된 후
      임의의 두 출구 j₁, j₂에 대해
      |TotalCost(j₁) - TotalCost(j₂)| ≤ κ
      가 성립한다.

증명 스케치:
  마지막으로 배정된 대피자 p*가 출구 j*를 선택했다면,
  j*의 총비용이 다른 모든 출구보다 작았기 때문이다.
  따라서 다른 출구 j'에 대해:
    Distance(p*, j*) + κ×N(j*) ≤ Distance(p*, j') + κ×N(j')
  이는 출구 간 총비용 차이가 최대 κ 이내임을 의미한다.
```

### 3. 출구 차단 시 동적 재배정

화재 진행으로 출구가 차단되면 즉각적으로 재배정을 수행한다.

#### 3.1 출구 차단 감지

```
단계 B1: 출구 차단 조건 평가
    Prediction AI로부터 출구 j 주변의 위험도를 수신한다.

    if R(exit_j, t) > R_threshold:
        # R_threshold = 0.8 (극도 위험)
        mark_exit_blocked(exit_j)
        trigger_reassignment(exit_j)

    추가 조건: 출구 j까지의 모든 경로가 R > 0.8인 경우
              해당 출구를 "도달 불가"로 판정한다.
```

#### 3.2 재배정 프로토콜

```
단계 B2: 영향 대피자 식별
    blocked_exit_j에 배정된 대피자 집합 S_affected를 식별한다.
    |S_affected| = N_affected

단계 B3: 잔여 출구의 CrowdPenalty 재계산
    차단된 출구의 N_assigned를 0으로 초기화한다.
    잔여 출구들의 CrowdPenalty는 기존값을 유지한다.

단계 B4: 영향 대피자 재배정
    S_affected의 각 대피자에 대해 비용 함수를 재평가한다:

    for person_i in S_affected:
        for exit_k in remaining_exits:
            cost_ik = Distance(person_i, exit_k)
                    + α_i × [w₁F(path_ik) + w₂S(path_ik)]
                    + CrowdPenalty(exit_k)
        assign(person_i, argmin_k(cost_ik))
        N_assigned(selected_exit) += 1
        # CrowdPenalty 즉시 갱신 → 다음 대피자의 비용에 반영

단계 B5: 경로 재계산
    재배정된 대피자의 경로를 새로운 출구를 목표로 재산출한다.
    소요 시간: 40ms 이내 (Decision AI 경로 산출 모듈)
```

#### 3.3 재배정 시 우선순위

```
재배정 순서는 위험도 기반으로 결정한다:

priority(person_i) = R(person_i.position, t)
                   + (1 - α_i⁻¹) × 100
                   + distance_to_blocked_exit(person_i) × (-1)

# 현재 위치가 위험할수록,
# 취약계층일수록,
# 차단된 출구에 가까울수록(이미 이동 중) 우선 재배정
```

### 4. 비선형 혼잡 모델 (고급 실시형)

인원이 일정 수를 초과하면 지연이 비선형적으로 증가하는 현상을 반영한다:

```
CrowdPenalty_NL(exit_j) = κ × N × (1 + η × max(0, N - N_threshold)²)

여기서:
  N = N_assigned(exit_j)
  N_threshold = W_j × 50 (출구 폭 1m당 50명, 선형 구간 임계값)
  η = 0.001 (비선형 증폭 계수)

예시 (W=1.2m, N_threshold=60):
  N=50:  CrowdPenalty = 40×50×(1+0) = 2000 (선형)
  N=80:  CrowdPenalty = 40×80×(1+0.001×400) = 4480 (비선형 증폭)
  N=100: CrowdPenalty = 40×100×(1+0.001×1600) = 10400 (강한 억제)
```

이 비선형 모델에 의해, 임계값 이상의 인원이 배정되면 혼잡 페널티가 급격히 증가하여 해당 출구로의 추가 배정이 자연스럽게 억제된다.

## 청구범위

**[청구항 1]**
복수의 출구를 갖는 시설의 화재 대피 시스템에서,
(a) 각 출구에 배정된 예상 도착 인원 수(N_assigned)에 인당 지연 계수(κ)를 곱한 혼잡 페널티(CrowdPenalty)를 산출하는 단계;
(b) 상기 CrowdPenalty를 경로 비용 함수에 포함시켜, 각 대피자에 대해 모든 출구까지의 총비용을 산출하고, 총비용이 최소인 출구를 배정하는 단계;
(c) 배정 시마다 해당 출구의 N_assigned를 갱신하여 다음 대피자의 비용 산출에 즉시 반영하는 단계;
를 포함하며, 상기 (a)~(c)에 의해 추가적인 전역 최적화 연산 없이 대피자가 복수의 출구로 자동 분산되는 것을 특징으로 하는 동적 출구 재배정 방법.

**[청구항 2]**
제1항에 있어서,
상기 인당 지연 계수(κ)는 출구 폭(W)의 역수에 비례하며, 표준 출구 폭(1.2m) 기준으로 κ=40초이고, 출구 폭이 다른 경우 κ = 40 × (1.2/W)로 차등 적용되는 것을 특징으로 하는 방법.

**[청구항 3]**
제1항에 있어서,
화재 진행에 의해 출구의 위험도가 소정 임계값(0.8)을 초과하면,
(d) 해당 출구를 차단 상태로 전환하는 단계;
(e) 차단된 출구에 배정된 대피자를 식별하고, 현재 위치의 위험도와 대피자 유형의 취약도에 기초한 우선순위로 잔여 출구에 재배정하는 단계;
를 더 포함하는 것을 특징으로 하는 방법.

**[청구항 4]**
제1항에 있어서,
상기 혼잡 페널티는, 배정 인원이 출구 폭에 기초한 소정 임계값을 초과하면 초과 인원의 제곱에 비례하는 비선형 항이 추가되어, 과밀 출구로의 추가 배정을 억제하는 것을 특징으로 하는 방법.

**[청구항 5]**
제1항 내지 제4항 중 어느 한 항의 방법을 실행하기 위한 프로그램이 기록된 컴퓨터 판독 가능 기록매체.

## 발명의 효과

1. CrowdPenalty에 의한 자기 균형 메커니즘으로 전역 최적화 없이 대피자가 자동 분산되어 계산 비용이 O(N²)에서 O(N)으로 감소한다.
2. 출구 폭에 따른 κ 차등 적용으로 넓은 출구에 더 많은 인원이 자연스럽게 배정되어 출구 용량이 최적 활용된다.
3. 출구 차단 시 40ms 이내에 영향 대피자의 재배정과 경로 재계산이 완료되어 대피 중단 시간이 최소화된다.
4. 비선형 혼잡 모델에 의해 임계값 초과 시 과밀이 자연스럽게 억제되어 압사 위험이 사전에 방지된다.
