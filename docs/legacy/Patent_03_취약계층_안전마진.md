# 특허 명세서 — PAT-NEW-03

## 발명의 명칭

**대피자의 생체 프로필에 기초한 유형별 차등 안전 마진 계수를 경로 비용 함수에 적용하고, 동반 보호자 경로를 동기화하는 개인 맞춤형 대피 경로 생성 방법**

---

## 기술분야

본 발명은 화재 대피 경로 생성 기술에 관한 것으로, 보다 구체적으로는 대피자의 건강 상태, 이동 능력, 연기 민감도를 정량적 프로필로 수치화하고, 유형별 차등 안전 마진 계수(α)를 경로 비용 함수에 직접 적용하여 개인 맞춤형 경로를 생성하며, 취약자와 동반 보호자의 경로를 동기화하는 방법에 관한 것이다.

---

## 배경기술

종래의 화재 대피 시스템은 모든 대피자에게 동일한 경로를 안내한다. 그러나 실제로 대피자의 이동 능력은 극도로 다양하다:

- 고령자의 계단 하강 속도는 건강한 성인의 약 40%(0.4 m/s vs 0.8 m/s)에 불과하다.
- 휠체어 사용자는 계단을 이용할 수 없어 엘리베이터 또는 경사로만 사용 가능하다.
- 어린이는 연기에 대한 생리적 취약성이 성인의 약 2배이다.
- 임산부는 장시간 보행과 계단 승강에 제한이 있다.

기존 연구에서 취약계층을 고려한 대피 경로 연구는 존재하나, 다음과 같은 한계가 있다:

1. 이동 속도만 차별화하고, **위험 요소(연기, 화재)에 대한 민감도를 차별화하지 않는다.**
2. 취약자와 동반 보호자의 경로를 **독립적으로 산출하여 분리 위험이 존재한다.**
3. 유형별 차등을 **경로 비용 함수에 직접 반영하는 수학적 방법이 제시되지 않았다.**

---

## 해결하려는 과제

본 발명은 대피자 유형별 안전 마진 계수(α)를 정의하고, 이를 경로 비용 함수의 위험 페널티 항에 승수로 적용하여, 취약계층에게 위험 요소를 강하게 회피하는 경로를 자동으로 생성하며, 동반 보호자와의 경로 동기화를 보장하는 방법을 제공하는 것을 목적으로 한다.

---

## 과제의 해결수단

### 1. 대피자 생체 프로필 구조

각 대피자는 탑승/입장 시 등록된 정보에 기초한 생체 프로필을 갖는다.

```
BioProfile(person_i) = {
    type: T_i ∈ {H, E, C, W, P, I},
    v_free: 자유 보행 속도 (m/s),
    v_stair: 계단 보행 속도 (m/s),
    stair_capable: boolean,
    elevator_priority: boolean,
    α: 안전 마진 계수,
    σ_smoke: 연기 민감도 계수,
    companion_id: 동반 보호자 ID 또는 null
}
```

### 2. 유형별 파라미터 정의

각 유형의 파라미터는 다음과 같이 정의된다:

| 유형 | 코드 | v_free | v_stair | 계단 | 엘리베이터 | α | σ_smoke | 근거 |
|------|------|--------|---------|------|-----------|---|---------|------|
| 건강한 성인 | H | 1.4 | 0.8 | 가능 | 비우선 | 1.0 | 1.0 | 기준값 |
| 고령자 | E | 0.7 | 0.4 | 가능(저속) | 우선 | 2.0 | 1.5 | SFPE 핸드북: 고령자 보행 속도 0.5~0.8 m/s |
| 어린이 | C | 1.0 | 0.5 | 가능 | 허용 | 2.0 | 2.0 | WHO: 어린이 호흡률 성인 대비 2배 |
| 휠체어 | W | 0.9 | 불가 | **불가** | **필수** | 2.0 | 1.5 | ADA 기준: 배리어프리 경로 필수 |
| 임산부 | P | 0.8 | 0.5 | 가능(저속) | 우선 | 1.8 | 1.8 | 산부인과 가이드: 과도한 신체 활동 제한 |
| 부상자 | I | 0.5 | 0.3 | 제한적 | 우선 | 2.0 | 2.0 | 응급의학 기준: 부상 유형별 이동 제한 |

#### α 계수의 도출 근거

α=2.0의 의미: 취약계층은 동일한 연기 농도에서 일반인보다 **2배 더 큰 비용**을 경로에 부과받는다. 이는 다음 근거에 기반한다:

```
(근거 1) 생리적 취약성
   고령자/어린이의 CO 중독 치사량(LC50)은 건강한 성인의
   약 50~60% 수준이다. 즉, 동일 연기 농도에서 사망 위험이
   약 2배이므로 회피 강도도 2배로 설정한다.

(근거 2) 이동 속도 차이에 의한 노출 시간 증가
   v_free(E) / v_free(H) = 0.7 / 1.4 = 0.5
   동일 거리를 이동하는 데 2배의 시간이 소요되므로
   연기 노출 시간도 2배가 된다.
   따라서 경로 선택 시 연기 구역 통과 비용을 2배로 설정하여
   노출 시간 증가를 경로 수준에서 보상한다.

(근거 3) 대피 실패 시 구조 난이도
   취약계층의 자력 대피 실패 시 소방관 구조가 필요하며,
   구조 1건당 소요 시간은 평균 3~5분이다.
   사전에 안전 마진을 강화하여 자력 대피 성공률을 높이는 것이
   전체 시스템 효율에 기여한다.
```

### 3. 비용 함수에의 α 적용

#### 3.1 위험 페널티 항에의 적용

```
R_personalized(n, person_i) = α_i × [w₁×F(n) + w₂×S(n)] + w₃×D(n) + w₄×C(n)
```

**핵심:** α_i는 화재(F)와 연기(S) 관련 항에만 승수로 적용되고, 밀집도(D)와 구조물(C)에는 적용되지 않는다.

**이유:** 취약계층이 더 민감한 것은 화재 열과 연기 흡입이며, 군중 밀집도와 구조물 위험은 유형에 무관하게 동일한 위험도를 갖기 때문이다.

#### 3.2 경로 제약 조건에의 적용

유형별로 사용 불가한 경로 요소가 있으며, 이는 비용이 아닌 제약 조건으로 처리된다:

```
단계 C1: 그래프 사전 필터링
    person_i의 유형이 W(휠체어)인 경우:
        그래프에서 모든 계단 노드의 간선을 제거한다.
        엘리베이터 노드의 비용을 0으로 설정한다.

    person_i의 유형이 E(고령자) 또는 P(임산부)인 경우:
        계단 노드의 간선 비용에 추가 페널티를 부과한다:
        stair_penalty = base_cost × (v_free_H / v_stair_i - 1)
        엘리베이터 노드의 비용을 50% 감소시킨다.

단계 C2: A* 탐색 실행
    필터링된 그래프 상에서 A* 경로 탐색을 수행한다.
    비용 함수: f(n) = g(n) + h(n) + R_personalized(n, person_i)

단계 C3: 경로 유효성 검증
    산출된 경로가 person_i의 제약 조건을 모두 충족하는지 검증한다.
    미충족 시, 위반 노드를 블랙리스트에 추가하고 C2를 재실행한다.
```

#### 3.3 연기 민감도 σ_smoke의 적용

Beer-Lambert 법칙에 의한 가시거리 판정 시, 유형별 민감도를 적용한다:

```
V_effective(person_i) = V_actual / σ_smoke_i
```

- `V_actual`: 해당 위치의 실제 가시거리 (Prediction AI 산출)
- `σ_smoke_i`: person_i의 연기 민감도 계수
- `V_effective`: person_i에게 적용되는 실효 가시거리

예시:
```
실제 가시거리 = 6m (일반인 기준: "주의" 등급)
어린이(σ=2.0)의 실효 가시거리 = 6 / 2.0 = 3m → "위험" 등급으로 상향
→ 해당 구역을 우회하는 경로가 자동으로 선택됨
```

### 4. 동반 보호자 경로 동기화

취약자와 동반 보호자가 분리되지 않도록 경로를 동기화한다.

#### 4.1 동기화 프로토콜

```
단계 P1: 그룹 식별
    companion_id가 null이 아닌 대피자 쌍을 식별한다.
    (취약자 A, 보호자 B)

단계 P2: 제약 조건 병합
    두 사람의 제약 조건 중 더 엄격한 것을 적용한다:
    merged_constraints = {
        stair_capable: A.stair AND B.stair,
        v_free: min(A.v_free, B.v_free),
        v_stair: min(A.v_stair, B.v_stair),
        α: max(A.α, B.α),
        σ_smoke: max(A.σ_smoke, B.σ_smoke)
    }

단계 P3: 통합 경로 산출
    merged_constraints를 적용하여 단일 경로를 산출한다.
    이 경로는 두 사람 모두에게 동일하게 제공된다.

단계 P4: 실시간 분리 감시
    대피 진행 중, 두 사람의 실시간 위치 간 거리를 모니터링한다:

    if distance(A.position, B.position) > D_separation:
        # 분리 경고 발생
        # D_separation = 5m (기본값)
        trigger_alert(A, B)
        # 두 사람 모두에게 경로 재계산
        # 현재 더 뒤처진 사람의 위치를 기준으로 통합 경로 재산출
        lagging_person = argmax_distance_to_exit(A, B)
        new_path = compute_path(lagging_person.position, merged_constraints)
        assign_path(A, new_path)
        assign_path(B, new_path)
```

#### 4.2 분리 방지 메커니즘의 수학적 정의

```
동기화 조건:
    ∀t, |pos_A(t) - pos_B(t)| ≤ D_separation

위반 시 보정:
    wait_time = |pos_A(t) - pos_B(t)| / min(v_A, v_B)
    뒤처진 사람이 앞선 사람의 위치에 도달하는 데 필요한 시간을
    경로 타이밍에 반영한다.
```

### 5. 전체 프로세스 흐름

```
[ID 프로필 카드 등록]
(탑승/입장 시 건강 정보 입력)
        ↓
[BioProfile 생성]
(유형 분류, α/σ 할당, 동반자 연결)
        ↓
[화재 발생]
        ↓
[단계 C1] 유형별 그래프 필터링
(휠체어: 계단 제거 / 고령자: 계단 페널티 / 일반: 제약 없음)
        ↓
[단계 C2] α 적용 A* 탐색
(R = α × [w₁F + w₂S] + w₃D + w₄C)
        ↓
[단계 P2~P3] 동반자 쌍 경로 동기화
(제약 병합 → 통합 경로)
        ↓
[경로 전송 → 대피 시작]
        ↓
[단계 P4] 실시간 분리 감시
(5m 초과 시 경고 + 재계산)
        ↓
[전원 대피 완료]
```

## 청구범위

**[청구항 1]**
화재 대피 시스템에서 개인 맞춤형 경로를 생성하는 방법에 있어서,
(a) 대피자의 건강 상태에 기초하여 복수의 유형 중 하나로 분류하고, 각 유형에 대응하는 안전 마진 계수(α)를 할당하는 단계;
(b) 동적 위험지도의 위험 요소 중 화재 열(F)과 연기 밀도(S)에 대해서만 상기 α를 승수로 적용한 개인화 위험 페널티를 산출하는 단계;
(c) 상기 개인화 위험 페널티를 포함하는 비용 함수로 해당 대피자의 최적 경로를 탐색하는 단계;
를 포함하는 것을 특징으로 하는 방법.

**[청구항 2]**
제1항에 있어서,
상기 유형은 건강한 성인(α=1.0), 고령자(α=2.0), 어린이(α=2.0), 휠체어 사용자(α=2.0), 임산부(α=1.8), 부상자(α=2.0)를 포함하고, 상기 α=2.0은 취약계층의 CO 중독 치사량이 건강한 성인의 약 50%인 생리적 근거와, 이동 속도 저하에 의한 연기 노출 시간 2배 증가의 물리적 근거에 기초하는 것을 특징으로 하는 방법.

**[청구항 3]**
제1항에 있어서,
상기 (c) 단계 이전에, 대피자 유형에 따라 경로 그래프에서 사용 불가한 노드를 제거하는 단계를 더 포함하되, 휠체어 사용자에 대해서는 계단 노드의 간선을 제거하고, 고령자에 대해서는 계단 노드에 추가 페널티를 부과하는 것을 특징으로 하는 방법.

**[청구항 4]**
제1항에 있어서,
상기 대피자에게 동반 보호자가 등록된 경우,
(d) 두 사람의 제약 조건 중 더 엄격한 것을 병합하여 통합 제약 조건을 생성하는 단계;
(e) 통합 제약 조건으로 단일 경로를 산출하여 두 사람 모두에게 동일한 경로를 제공하는 단계;
(f) 대피 진행 중 두 사람의 위치 간 거리가 소정 임계값(5m)을 초과하면, 뒤처진 사람의 현재 위치를 기준으로 경로를 재산출하는 단계;
를 더 포함하는 것을 특징으로 하는 방법.

**[청구항 5]**
제1항에 있어서,
상기 대피자의 연기 민감도 계수(σ_smoke)를 정의하고, Prediction AI가 산출한 실제 가시거리를 σ_smoke로 나누어 실효 가시거리를 산출하며, 상기 실효 가시거리에 기초하여 위험 등급을 판정하는 것을 특징으로 하는 방법.

**[청구항 6]**
제1항 내지 제5항 중 어느 한 항의 방법을 실행하기 위한 프로그램이 기록된 컴퓨터 판독 가능 기록매체.

---

## 발명의 효과

1. 취약계층의 대피 경로가 화재와 연기를 일반인보다 2배 강하게 회피하여, 동일 화재에서 취약계층의 연기 노출량을 50% 이상 감소시킨다.
2. α가 비용 함수에 직접 반영되므로, 별도의 전용 알고리즘 없이 기존 A* 경로 탐색 인프라를 그대로 활용하면서 개인 맞춤화를 달성한다.
3. 동반 보호자 경로 동기화에 의해 취약자-보호자 분리가 방지되어, 취약자의 심리적 안정과 보호자의 즉각적 보조가 보장된다.
4. 실효 가시거리(V/σ) 개념에 의해, 동일 연기 농도에서도 유형별로 다른 위험 등급이 판정되어 더욱 세밀한 개인화가 가능하다.

## 도면의 간단한 설명

- [도 1] 대피자 생체 프로필 구조도
- [도 2] 유형별 α 적용에 따른 경로 비교도 (동일 화재 시나리오)
- [도 3] 실효 가시거리 산출 다이어그램
