# 배경기술

## 종래 기술의 현황

### 1. 기존 화재 대피 시뮬레이션 시스템의 제한사항

#### 1.1 정적 화재 모델
종래의 화재 시뮬레이션 도구(FDS, FlueNT 등)는 **물리 엔진 기반의 고정밀 화재 모델**을 제공하나, 다음과 같은 제약을 가진다:

- **계산량 과다:** 실시간 계산이 불가능하여 사전 계산(Pre-calculation)에 수시간 소요
- **대피 전략 미흡:** 화재 물리 시뮬레이션에만 집중, 소방관 배치 최적화 기능 부재
- **사용자 전문성 요구:** 엔지니어 수준의 복잡한 매개변수 설정 필요
- **실시간 상호작용 불가:** 시뮬레이션 도중 변수 조정 불가

#### 1.2 경로 최적화 도구의 한계
대피 경로 최적화 소프트웨어(Pathfinder, Legion, Exodus)는 **승객 대피 경로 계산**에 특화되어 있으나:

- **소방관 배치 미고려:** 소방관의 최적 위치 결정 알고리즘 부재
- **단일 경로 계산:** 대피 경로만 제공, 화재 진압 전략과의 연계 부재
- **수동 조작:** 사용자가 직접 소방관 투입 위치를 선택해야 함
- **다변수 미종합:** 바람, 연기, 승객 흐름을 독립적으로만 분석

### 2. 현재 소방관 투입 시스템의 문제점

#### 2.1 수동 배치의 비효율성
**현재 시스템:** 사용자가 캔버스에서 마우스 클릭으로 소방관 투입 위치 선택

```
문제점:
┌─────────────────────────────────────────┐
│ 1. 최적 위치 판단 불가                  │
│    - 수백 가지 가능한 위치 중            │
│    - 사용자의 직관적 선택만 가능         │
│    - 객관적 평가 기준 부재              │
│                                         │
│ 2. 바람 방향 미고려                     │
│    - 연기가 확산되는 방향을 무시        │
│    - 가시성 악화 상황에서 투입          │
│                                         │
│ 3. 승객 대피 경로 방해                  │
│    - 소방관과 승객의 충돌 가능          │
│    - 대피 경로 블로킹으로 진퇴양난      │
│                                         │
│ 4. 우선순위 결정 불명확                │
│    - 어떤 화재부터 진압할지 기준 부재  │
│    - 화재 크기, 승객 수 등을 미종합    │
│                                         │
│ 5. 효율성 저하                          │
│    - 최악의 위치 선택 시 소방관 손실    │
│    - 재난 대응 훈련 신뢰성 저하        │
└─────────────────────────────────────────┘
```

#### 2.2 소방관 경로 탐색의 오류
**현재 문제:** 소방관이 일반 승객과 동일한 경로 탐색 알고리즘 사용

```
[기존 소방관 경로 탐색]
화재 위치         소방관 시작 위치
    X                 O
    │                 │
    │◄────────────────│  A* 경로 (화재 회피)
    │      (일반 승객용)
    │
    └─ 문제: 화재를 피해 돌아감 (우회로 선택)
             화재까지 거리 증가 → 진압 지연
             승객과 경로 충돌 가능성 높음
```

**구체적 문제:**
- A* 경로 탐색 시 화재 근처는 높은 비용(fireDangerAt)으로 설정
- 소방관도 이 비용을 고려하여 화재를 최대한 피함
- 결과적으로 화재까지의 최단 거리 대신 안전한 우회로 선택
- 화재 진압에 필요한 빠른 진입이 불가능

### 3. 구체적 문제 시나리오

#### 시나리오 1: 크루즈선 대규모 화재

```
상황:
- A 구역에 화재 발생 (승객 150명 영향)
- 연기가 북쪽으로 확산 (남풍 존재)
- B, C 구역으로도 화재 확산 중

기존 시스템의 문제:
┌────────────────────────────────┐
│  남풍(→북쪽)                   │
│  ───────>                       │
│                                 │
│     연기 영향 범위              │
│   ┌──────────┐                  │
│   │ 🔥A구역 │                  │
│   │ (화재)  │                  │
│   └──────────┘                  │
│                                 │
│  사용자가 임의로 X 위치 선택    │
│        X (소방관 투입)          │
│                                 │
│  문제점:                        │
│  1. X는 연기 영향 범위 내       │
│  2. 가시거리 불량              │
│  3. 화재까지 거리 먼 우회로     │
│  4. B, C 구역 화재는 미대응     │
│  5. 결과: 화재 확산 방지 실패  │
└────────────────────────────────┘
```

#### 시나리오 2: 대형건물 복도 화재

```
기존 문제:
┌─────────────────────────────────┐
│ 복도 구조도                      │
│                                 │
│ 방1  [연기]  방2                │

│  ├─────────┼──────┐             │
│  │         │      │             │
│  └─────────┴──────┘             │
│         복도                     │
│                                 │
│ 사용자가 방1 근처 입구 선택 →    │
│ (연기로 가득찬 방향)             │
│                                 │
│ 소방관 경로 탐색 결과:           │
│ └─ 연기를 피해 반대편(방2) 방향  │
│    으로 돌아감                  │
│ └─ 화재까지 거리 2배 증가       │
│ └─ 진입 시간 연장               │
└─────────────────────────────────┘
```

### 4. 종래 기술의 핵심 결함 정리

| 구분 | 문제점 | 영향 |
|------|--------|------|
| **배치 결정** | 사용자 수동 선택, 최적화 알고리즘 없음 | 비효율적 배치, 화재 진압 지연 |
| **풍향 미고려** | 연기 확산 방향을 무시한 배치 | 가시성 악화, 소방관 피해 증가 |
| **승객 충돌** | 대피 경로와의 교차 지점 미분석 | 승객 대피 지연, 이중 피해 |
| **우선순위 부재** | 어떤 화재부터 대응할지 기준 없음 | 화재 우선순위 오판, 확산 방지 실패 |
| **경로 회피** | 소방관도 화재를 피하는 경로 선택 | 진입 지연, 화재 진압 불가 |
| **다변수 미종합** | 6가지 요소를 동시에 고려 불가 | 종합 최적화 불가능 |

### 5. 기술적 필요성

위의 문제들을 해결하기 위해서는:

1. **자동 최적 위치 결정 알고리즘** 필요
   - 6가지 이상의 평가 요소를 수학적으로 통합
   - 실시간으로 최적 위치 계산 및 업데이트
   - 사용자 개입 최소화

2. **이중 경로 탐색 시스템** 필요
   - 승객: 화재 회피 경로 (안전 최우선)
   - 소방관: 최단 거리 경로 (신속 진입)

3. **의사결정 엔진** 필요
   - 화재별 위협도 점수 계산
   - 소방관 투입 우선순위 자동 결정
   - 다중 화재 동시 대응 전략

4. **실시간 시각화** 필요
   - 추천 위치를 직관적으로 표시
   - 접근 방향 명확화
   - 의사결정 근거 제시

## 종래 기술의 참고 자료

- **FDS (Fire Dynamics Simulator):** NIST 화재 물리 시뮬레이션 표준 (화재 모델만 포함)
- **Pathfinder:** Thunderhead Engineering 대피 경로 도구 (대피만 포함)
- **IMO SOLAS Regulation II-2/13:** 선박 화재 안전 규칙 (정성적 기준)
- **NFPA 101 Life Safety Code:** 미국 화재 안전 기준 (건축 기준)
