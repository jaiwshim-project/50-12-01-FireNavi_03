# 통합 특허 명세서

## 발명의 명칭

**삼중 AI 엔진의 실시간 동기 연동에 기반한 화재 대피 시스템에서의 이원 경로 생성, 취약계층 맞춤형 안전 마진 적용, 동적 출구 재배정 및 이중 경로 예측 보정 방법과 그 시스템**

---

## 기술분야

본 발명은 AI 기반 화재 대피 기술에 관한 것으로, 보다 구체적으로는 (1) 화재 확산 예측 엔진, 군중 행동 분석 엔진, 경로 결정 엔진의 세 가지 이질적 AI 엔진을 100ms 이내의 파이프라인 사이클로 동기 연동하고, (2) 동일 동적 위험지도 상에서 대피자와 소방관의 상반된 경로를 동시 생성하며, (3) 대피자의 건강 상태에 기초한 차등 안전 마진 계수를 적용하고, (4) 출구별 혼잡 페널티에 의한 자기 균형 메커니즘으로 대피자를 분산시키며, (5) LSTM 실시간 추론과 CFD 정밀 해석의 이중 경로 예측을 적응적으로 병합하는 방법과 그 시스템에 관한 것이다.

---

## 배경기술

### 1. 종래 화재 대피 시스템의 한계

종래의 화재 대피 시스템은 건물 설계 시 고정된 비상구 안내판과 방송 시스템에 의존한다. 이 방식은 다음과 같은 근본적 한계를 갖는다:

(1) 화재의 동적 변화(연기 확산 방향 변경, 출구 차단, 구조물 붕괴)를 반영하지 못한다.
(2) 모든 대피자에게 동일한 경로를 안내하여 특정 출구에 인원이 과도하게 집중된다.
(3) 고령자, 장애인, 어린이 등 취약계층의 이동 능력 차이를 반영하지 못한다.
(4) 대피자와 소방관이 동일 통로에서 역방향으로 충돌하는 문제를 방지할 수 없다.

### 2. 기존 연구의 한계

최근 연구에서는 CFD(전산유체역학) 기반 연기 확산 예측, Social Force Model 기반 군중 시뮬레이션, A* 알고리즘 기반 경로 탐색이 각각 독립적으로 연구되어 왔다.

그러나 이 세 가지 연산은 서로 다른 계산 특성을 갖는다:

| 연산 유형 | 계산 특성 | 단독 실행 시간 |
|----------|----------|-------------|
| CFD 연기 예측 | 편미분 방정식 수치 해석 | 수 초 ~ 수 분 |
| 군중 행동 분석 | N-body 상호작용, O(N²) | 수백 ms |
| 경로 탐색 | 그래프 탐색, 동적 가중치 | 수십 ms |

종래 기술의 구체적 문제점은 다음과 같다:

(a) 세 가지 연산을 직렬 수행하면 전체 응답 시간이 수 초 이상이 되어 실시간 대피 안내가 불가능하다. 단순 병렬 수행 시에는 데이터 정합성이 보장되지 않는다.

(b) 대피자 경로와 소방관 경로를 동일 시스템에서 동시에 생성하되 물리적 간섭을 방지하는 통합 방법이 존재하지 않는다.

(c) 취약계층의 이동 속도만 차별화하고, 화재·연기에 대한 생리적 민감도를 경로 비용 함수에 직접 반영하는 수학적 방법이 제시되지 않았다. 또한 취약자와 동반 보호자의 경로 분리 방지 메커니즘이 없다.

(d) 출구 배정 최적화는 주로 사전 계획(pre-plan) 방식으로, 화재 진행에 따른 실시간 재배정과 자기 균형 메커니즘이 부재하다.

(e) CFD의 정밀도와 딥러닝의 실시간성을 동시에 확보하기 위해, 두 경로를 병행 실행하면서 상호 보정하고 적응적으로 병합하는 구체적 방법이 없다.

## 해결하려는 과제

본 발명은 상기 (a)~(e)의 문제점을 모두 해결하기 위하여 안출된 것으로, 다음 다섯 가지 과제를 해결하는 것을 목적으로 한다:

**[제1 과제]** 계산 특성이 이질적인 세 개의 AI 엔진을 이중 버퍼링과 시간 스탬프 기반 정합성 검증에 의해 100ms 이내로 동기 연동하는 방법

**[제2 과제]** 동일 위험지도 상에서 대피자(위험 회피)와 소방관(위험 진입)의 상반된 경로를 시공간 예약 테이블에 의해 간섭 없이 동시 생성하는 방법

**[제3 과제]** 대피자 유형별 차등 안전 마진 계수(α)를 비용 함수에 직접 적용하고, 동반 보호자 경로를 동기화하는 방법

**[제4 과제]** 출구별 혼잡 페널티(CrowdPenalty)에 의한 자기 균형 분산과, 출구 차단 시 즉각 재배정 방법

**[제5 과제]** LSTM Fast Path와 CFD Slow Path의 병행 실행, 온라인 보정, 적응적 가중 병합에 의한 실시간성과 정밀도 동시 확보 방법

## 과제의 해결수단

### 제1 발명: 삼중 AI 엔진 100ms 동기 연동 방법

#### 1-1. 시스템 구성

본 발명에 따른 시스템은 다음 구성요소를 포함한다:

**(a) 예측 엔진 (Prediction Engine)**
- LSTM 네트워크에 의한 실시간 추론 모듈 (Fast Path)
- CFD 수치 해석에 의한 정밀 보정 모듈 (Slow Path)
- 이중 경로(Dual-Path) 출력 병합기

**(b) 행동 엔진 (Behavior Engine)**
- KDE 기반 밀집도 산출 모듈
- Social Force 연산 모듈
- 공간 분할 그리드 (Spatial Hash Grid, 셀 크기 5m × 5m)

**(c) 결정 엔진 (Decision Engine)**
- 위험지도 합성 모듈
- A* 경로 탐색 모듈 (MinHeap 기반)
- 출구 배정 최적화 모듈

**(d) 동기 버스 (Synchronization Bus)**
- 이중 버퍼 메모리 (Buffer A / Buffer B)
- 시간 스탬프 레지스터
- 정합성 검증기

#### 1-2. 파이프라인 동기 연동 방법

**단계 S100: 예측 엔진 실행**

```
(S101) IoT 센서로부터 현재 시점 t의 환경 데이터 벡터 X(t)를 수신한다.
       X(t) = [T₁...Tₙ, CO₁...COₙ, S₁...Sₙ, H₁...Hₙ]
       여기서 T=온도, CO=일산화탄소, S=연기감지, H=HVAC 상태이고,
       n은 센서 수이다.

(S102) X(t)와 이전 k개 시간 단계의 데이터 {X(t-1),...,X(t-k)}를
       LSTM 네트워크의 입력 텐서로 구성한다.
       입력 텐서 형상: (batch=1, sequence_length=k, features=4n)
       여기서 k=10이다.

(S103) LSTM 네트워크를 통해 t+Δt₁, t+Δt₂, t+Δt₃ 시점의
       공간별 위험도 예측 맵 P_fast(x,y,t+Δtᵢ)를 산출한다.
       여기서 Δt₁=10초, Δt₂=30초, Δt₃=60초이다.
       산출 소요 시간: 15ms 이내.

(S104) P_fast에 시간 스탬프 ts_pred = t를 부여한다.
```

**단계 S200: 이중 버퍼 데이터 교환**

```
(S201) 예측 엔진은 P_out과 ts_pred를 이중 버퍼의 Buffer A에 기록한다.
       이때 행동 엔진과 결정 엔진은 Buffer B를 읽고 있다.

(S202) 기록 완료 후, 버퍼 포인터를 원자적(atomic)으로 교환한다:
       swap(Buffer_A_ptr, Buffer_B_ptr)
       이 교환은 lock-free 방식으로 수행되어 대기 시간이 0이다.

(S203) 행동 엔진은 교환된 버퍼로부터 P_out과 ts_pred를 읽는다.
```

**단계 S300: 행동 엔진 실행**

```
(S301) WiFi 위치추적 모듈로부터 전체 N명의 위치 좌표를 수신한다.
       Positions = {(x₁,y₁,z₁), ..., (xₙ,yₙ,zₙ)}

(S302) 공간 분할 그리드에 각 인원을 할당한다.
       그리드 셀 크기: 5m × 5m
       이 단계에서 KDE 연산의 복잡도가 O(N²)에서
       O(N × k)로 감소한다. (k: 인접 셀 수, 최대 9)

(S303) 각 셀에 대해 KDE 밀집도를 산출한다.
       D(i,j) = |Cell(i,j)| / Area(i,j)

(S304) Social Force Model로 각 에이전트의 합력을 계산한다.
       F_total = F_desired + F_social + F_wall + F_fire
       F_fire(agent_a) = C × exp(-d(agent_a, fire) / R) × n_af
       여기서 C=5000N, R=20m이다.

(S305) 밀집도 맵 D_out과 유형별 속도 맵 V_out을 산출한다.
       시간 스탬프 ts_behav = t를 부여한다.
       산출 소요 시간: 30ms 이내 (N=6000 기준).

(S306) D_out, V_out을 이중 버퍼를 통해 결정 엔진에 전달한다.
```

**단계 S400: 결정 엔진 실행**

```
(S401) P_out(예측), D_out(밀집도)를 이중 버퍼로부터 수신한다.

(S402) 시간 스탬프 정합성을 검증한다:
       |ts_pred - ts_behav| ≤ Δt_max (Δt_max = 200ms)
       초과 시 선형 보간으로 보정한다:
       Data_corrected = Data_old + ratio × (Data_new - Data_old)

(S403) Dynamic Risk Map을 합성한다:
       R(x,y,t) = 0.35×F(x,y,t) + 0.30×S(x,y,t)
                 + 0.20×D(x,y,t) + 0.15×C(x,y)

(S404) R(x,y,t)를 그래프 가중치로 변환한다:
       각 노드 n의 통과 비용 = base_cost(n) × (1 + γ × R(n))
       여기서 γ = 10.0이다.

(S405) N명 각각에 대해 A* 경로 탐색을 수행한다.
       산출 소요 시간: 40ms 이내 (N=6000 기준).

(S406) 경로 결과를 각 대피자의 모바일 디바이스로 전송한다.
```

**단계 S500: 사이클 반복**

```
(S501) S100~S400을 연속적으로 반복한다.
       1 사이클 = S100(15ms) + S200(0ms) + S300(30ms)
                 + S200(0ms) + S400(40ms) = 약 85ms (< 100ms)

(S502) 잔여 시간(15ms)은 다음 사이클의 S100 선행 실행에 할당한다.
```

#### 1-3. 장애 허용 설계

```
(a) 예측 엔진 장애 시:
    P_fallback = P_last × exp(-elapsed / τ_decay), τ_decay = 5초

(b) 행동 엔진 장애 시:
    D_fallback(x,y) = N_total / Total_Area (균일 분포 가정)

(c) 네트워크 단절 시:
    각 데크/층의 엣지 서버가 독립적으로 S100~S400을 실행한다.
```

### 제2 발명: 대피자-소방관 이원 경로 동시 생성 방법

#### 2-1. 이원 비용 함수 설계

**대피자용 비용 함수 (Safety-First):**
```
f_evac(n) = g(n) + h(n) + γ_evac × R(n) × (1 + α_type)
```
- 위험도가 높은 구역을 **회피**한다.

**소방관용 비용 함수 (Straight-Line):**
```
f_fire(n) = g(n) + h_fire(n) + I(n)
```
- 위험도 페널티 R(n)이 **적용되지 않는다.**
- 대신 간섭 페널티 I(n)이 추가된다.

**간섭 페널티:**
```
I(n) = λ × Σ overlap(n, path_evac_i)
여기서 λ = 50.0
overlap = 해당 노드에서 대피자와 ±5초 이내 동시 통과가 예상되면 1
```

#### 2-2. 시공간 예약 테이블 (STRT)

```
STRT[node_id][time_slot] = {
    reserved_by: "evacuee" | "firefighter" | null,
    agent_ids: [list],
    direction: vector,
    capacity: integer  (복도 폭 1m당 1.5명/초)
}
```

**예약 프로토콜:**

```
단계 R1: 대피자 경로를 먼저 산출하고 STRT에 "evacuee"로 예약한다.

단계 R2: 소방관 경로 생성 시 STRT를 참조한다.
    if STRT[n][t].reserved_by == "evacuee":
        역방향 충돌 판정:
        cos_theta = dot(v_ff, v_evac) / (|v_ff| × |v_evac|)
        if cos_theta < -0.5:  # 120°~240° 범위
            I(n) += λ × count(agent_ids)    # 역방향 → 전체 페널티
        else:
            I(n) += λ × 0.2 × count(agent_ids)  # 동방향 → 감소 페널티

    if remaining_capacity(n, t) <= 0:
        f_fire(n) = INFINITY  # 용량 초과 → 탐색 불가

단계 R3: 소방관 경로 확정 후 STRT에 "firefighter"로 추가 예약한다.

단계 R4: 매 사이클(100ms)마다 STRT를 재구축한다.
```

#### 2-3. 소방관 최적 배치 위치 산출

**Position Score:**
```
PositionScore(P) = Upwind(P) + ExitAccess(P) - PassengerBlock(P)
                   + MultiFireCover(P) - FFOverlap(P) + CorridorBonus(P)
```

| 구성 요소 | 최대 점수 | 산출 방법 |
|----------|----------|----------|
| Upwind (풍상 접근) | 40점 | 기류 방향과의 각도: ≤30°→40, ≤60°→25, ≤90°→10 |
| ExitAccess (출구 접근성) | 30점 | 30 × max(0, 1 - d_exit/100m) |
| PassengerBlock (대피자 간섭) | -5N점 | STRT 참조, 10m 이내 교차 인원 |
| MultiFireCover (다중 화원) | 10점 | min(10, 5 × 50m 이내 화원 수) |
| FFOverlap (소방관 중복) | -20점 | 40m 이내 기배치 소방관 존재 시 |
| CorridorBonus (복도 보너스) | 15점 | 개방 복도:15, 일반:5, 밀폐:0 |

**Threat Score (화원별 투입 우선순위):**
```
ThreatScore(F) = PassengerCount(F) × 100
                + BlockedPassengers(F) × 30
                + SmokeAffectedPassengers(F) × 15
                + ExitThreats(F) × 40
                + FireRadius(F) × 2
                - ExistingFirefighters(F) × 80
```

각 계수의 근거: PassengerCount에 최대 가중치(100)를 부여하여 인명 우선 원칙을 적용한다. ExistingFirefighters에 음(-)의 가중치(-80)를 부여하여 소방관의 분산 투입을 유도한다.

### 제3 발명: 취약계층 차등 안전 마진 및 동반 보호자 경로 동기화 방법

#### 3-1. 대피자 생체 프로필 구조

```
BioProfile(person_i) = {
    type: T_i ∈ {H, E, C, W, P, I},
    v_free: 자유 보행 속도,
    v_stair: 계단 보행 속도,
    stair_capable: boolean,
    α: 안전 마진 계수,
    σ_smoke: 연기 민감도 계수,
    companion_id: 동반 보호자 ID 또는 null
}
```

#### 3-2. 유형별 파라미터 정의

| 유형 | 코드 | v_free | v_stair | 계단 | α | σ_smoke | 근거 |
|------|------|--------|---------|------|---|---------|------|
| 건강한 성인 | H | 1.4 m/s | 0.8 m/s | 가능 | 1.0 | 1.0 | 기준값 |
| 고령자 | E | 0.7 m/s | 0.4 m/s | 저속 | 2.0 | 1.5 | SFPE 핸드북 |
| 어린이 | C | 1.0 m/s | 0.5 m/s | 가능 | 2.0 | 2.0 | WHO 호흡률 기준 |
| 휠체어 | W | 0.9 m/s | 불가 | **불가** | 2.0 | 1.5 | ADA 기준 |
| 임산부 | P | 0.8 m/s | 0.5 m/s | 저속 | 1.8 | 1.8 | 산부인과 가이드 |
| 부상자 | I | 0.5 m/s | 0.3 m/s | 제한 | 2.0 | 2.0 | 응급의학 기준 |

#### 3-3. α 계수의 도출 근거

α=2.0의 세 가지 근거:

```
(근거 1) 생리적 취약성:
   고령자/어린이의 CO 중독 치사량(LC50)이 건강한 성인의
   약 50~60% 수준이므로, 동일 연기 농도에서 사망 위험이 약 2배.

(근거 2) 이동 속도 차이에 의한 노출 시간 증가:
   v_free(E) / v_free(H) = 0.7 / 1.4 = 0.5
   동일 거리 이동에 2배 시간 소요 → 연기 노출 시간 2배.

(근거 3) 자력 대피 실패 시 구조 비용:
   취약계층의 구조 1건당 소요 시간 3~5분.
   사전 안전 마진 강화가 전체 시스템 효율에 기여.
```

#### 3-4. 비용 함수에의 α 적용

```
R_personalized(n, person_i) = α_i × [w₁×F(n) + w₂×S(n)] + w₃×D(n) + w₄×C(n)
```

**핵심:** α_i는 화재(F)와 연기(S) 관련 항에만 승수로 적용되고, 밀집도(D)와 구조물(C)에는 적용되지 않는다. 취약계층이 더 민감한 것은 화재 열과 연기 흡입이며, 군중 밀집도와 구조물 위험은 유형에 무관하게 동일한 위험도를 갖기 때문이다.

#### 3-5. 연기 민감도 σ_smoke 적용

```
V_effective(person_i) = V_actual / σ_smoke_i
```

예시: 실제 가시거리 6m인 구역에서
- 건강한 성인(σ=1.0): 실효 가시거리 6m → "주의" 등급
- 어린이(σ=2.0): 실효 가시거리 3m → "위험" 등급 상향 → 우회 경로 선택

#### 3-6. 그래프 사전 필터링

```
단계 C1:
  휠체어(W): 그래프에서 모든 계단 노드의 간선 제거, 엘리베이터 비용 0
  고령자(E)/임산부(P): 계단 노드에 추가 페널티 부과
    stair_penalty = base_cost × (v_free_H / v_stair_i - 1)
    엘리베이터 비용 50% 감소

단계 C2: 필터링된 그래프 상에서 A* 경로 탐색 실행
  f(n) = g(n) + h(n) + R_personalized(n, person_i)
```

#### 3-7. 동반 보호자 경로 동기화 프로토콜

```
단계 P1: 그룹 식별
    companion_id가 null이 아닌 대피자 쌍 (취약자 A, 보호자 B) 식별

단계 P2: 제약 조건 병합
    merged_constraints = {
        stair_capable: A.stair AND B.stair,
        v_free: min(A.v_free, B.v_free),
        α: max(A.α, B.α),
        σ_smoke: max(A.σ_smoke, B.σ_smoke)
    }

단계 P3: 통합 경로 산출
    merged_constraints로 단일 경로를 산출하여 두 사람에게 동일 제공

단계 P4: 실시간 분리 감시
    if distance(A.position, B.position) > 5m:
        분리 경고 발생
        뒤처진 사람의 현재 위치를 기준으로 경로 재산출
        두 사람 모두에게 새 경로 할당
```

### 제4 발명: 동적 출구 재배정 방법

#### 4-1. CrowdPenalty 정의

```
CrowdPenalty(exit_j) = N_assigned(exit_j) × κ(exit_j)
```

#### 4-2. κ의 도출

```
출구 통과 용량 = W × φ (W: 출구 폭, φ: 1.3 명/m/초, SFPE 권장)
1인 추가 시 대기 시간 증가분: Δt = 1 / (W × φ)
표준 출구 (W=1.2m): Δt = 1/(1.2×1.3) = 0.641초
안전 마진 및 비선형 지연 고려: κ = 40초 (정수 근사)

출구 폭별 차등: κ(exit_j) = 40 × (1.2 / W_j)
  폭 2.4m 출구: κ = 20 (절반 페널티)
  폭 0.9m 출구: κ = 53 (증가 페널티)
```

#### 4-3. 경로 비용 함수에의 통합

```
f(n, exit_j, person_i) = g(n) + h(n, exit_j)
                         + α_i × [w₁F(n) + w₂S(n)]
                         + w₃D(n) + w₄C(n)
                         + CrowdPenalty(exit_j)
```

#### 4-4. 자기 균형 메커니즘

각 대피자가 자신의 비용 함수만으로 최적 출구를 선택하면, CrowdPenalty의 자동 증가에 의해 **전역 최적화 없이** 전체 시스템이 균형에 수렴한다.

```
수렴 정리:
  모든 대피자의 배정 완료 후, 임의의 두 출구 j₁, j₂에 대해
  |TotalCost(j₁) - TotalCost(j₂)| ≤ κ 가 성립한다.
```

#### 4-5. 출구 차단 시 동적 재배정

```
단계 B1: R(exit_j, t) > 0.8 → 출구 차단 판정

단계 B2: 차단 출구에 배정된 대피자 집합 S_affected 식별

단계 B3: 재배정 우선순위 산출
    priority(person_i) = R(person_i.position, t)
                       + (1 - α_i⁻¹) × 100
                       + distance_to_blocked_exit × (-1)

단계 B4: 우선순위 순으로 잔여 출구에 재배정
    재배정 시마다 CrowdPenalty 즉시 갱신

단계 B5: 경로 재계산 (40ms 이내)
```

#### 4-6. 비선형 혼잡 모델

```
CrowdPenalty_NL(exit_j) = κ × N × (1 + η × max(0, N - N_threshold)²)
여기서 N_threshold = W_j × 50, η = 0.001

예시 (W=1.2m, N_threshold=60):
  N=50:  2,000 (선형 구간)
  N=80:  4,480 (비선형 증폭)
  N=100: 10,400 (강한 억제)
```

### 제5 발명: LSTM-CFD 이중 경로 예측 보정 방법

#### 5-1. 이중 경로 아키텍처

```
[IoT 센서 데이터]
    ↓           ↓
[Fast Path]  [Slow Path]
 LSTM 15ms    CFD 5~10초
    ↓           ↓
    ↓      [온라인 보정기]
    ↓           ↓
[적응적 가중 병합기]
 P_out = β×P_fast + (1-β)×P_slow
```

#### 5-2. Fast Path 상세

**LSTM 네트워크 구조:**
```
Layer 1: LSTM(input_size=4n, hidden_size=128)→Dropout(0.2)
Layer 2: LSTM(input_size=128, hidden_size=64)→Dropout(0.2)
Layer 3: Dense(64, W×H×D×3)→Reshape(W,H,D,3)

출력 3채널: 연기 농도 C, 온도 T, 가시거리 V
예측 시점: t+10초, t+30초, t+60초
소요 시간: 15ms 이내
```

#### 5-3. Slow Path 상세

```
Navier-Stokes 연립 방정식 수치 해석:
  연속 방정식: ∂ρ/∂t + ∇·(ρv) = 0
  운동량 방정식: ρ(∂v/∂t + v·∇v) = -∇p + μ∇²v + ρg + F_b
  에너지 방정식: ρcₚ(∂T/∂t + v·∇T) = k∇²T + Q̇'''
  연기 수송 방정식: ∂C/∂t + v·∇C = D_s∇²C + Ṡ - λ_dC

메쉬 해상도: 0.5m × 0.5m × 0.5m
소요 시간: 5~10초

동적 경계 조건 갱신: 매 1초마다 문 개폐, HVAC, 새 화원 반영
```

#### 5-4. 온라인 보정 메커니즘

```
단계 O1: Slow Path 완료 시마다 트리거 (5~10초 주기)

단계 O2: 보정 손실 산출
    P_fast_at_ts_slow = cache에서 해당 시점 Fast Path 예측 참조
    Loss = λ_C×MSE(C_fast, C_slow) + λ_T×MSE(T_fast, T_slow)
         + λ_V×MSE(V_fast, V_slow)
    여기서 λ_C=0.5, λ_T=0.3, λ_V=0.2

단계 O3: LSTM 최종 Dense 레이어 가중치만 갱신
    W_lstm ← W_lstm - 0.001 × ∇Loss
    LSTM 내부 게이트 가중치는 동결 (시계열 안정성 유지)
    소요 시간: 2ms 이내

단계 O4: 안전 장치
    if Loss_after > Loss_before × 1.1:
        W_lstm ← W_lstm_backup  # 롤백
        lr ← lr × 0.5          # 학습률 감소
```

#### 5-5. 적응적 가중 병합

```
P_out(t) = β(t) × P_fast(t) + (1 - β(t)) × P_slow(t_last)

β(t) = min(1.0, elapsed_slow / T_slow)

작동:
  Slow Path 직후 (elapsed=0): β=0 → P_slow 우세 (정밀 우선)
  Slow Path 중간 (elapsed=T/2): β=0.5 → 균등 병합
  Slow Path 직전 (elapsed≈T): β≈1.0 → P_fast 우세 (실시간 우선)

이상 상황:
  Slow Path 지연 (elapsed > 2T): β=1.0, 경고 플래그
  Fast Path 이상 (NaN/음수): β=0.0, LSTM 재초기화 트리거
  양쪽 이상: P_fallback = P_last_valid × exp(-elapsed/5.0)
```

#### 5-6. 캐시 관리

```
PredictionCache = CircularBuffer(capacity=20)

매 Fast Path 실행 시: cache.push({timestamp, prediction, sensor_input})
Slow Path 완료 시: matching_entry = cache.find(ts_slow)
  → 매칭 성공: 온라인 보정 실행
  → 캐시 미스: 보정 생략, 다음 사이클 대기
```

제11항에 있어서, 상기 α=2.0은 취약계층의 CO 중독 치사량이 건강한 성인의 약 50%인 생리적 근거와, 이동 속도 저하에 의한 연기 노출 시간 2배 증가의 물리적 근거에 기초하는 것을 특징으로 하는 방법.

**[청구항 13]**
제11항에 있어서, 대피자 유형별 연기 민감도 계수(σ_smoke)를 정의하고, 실제 가시거리를 σ_smoke로 나누어 실효 가시거리를 산출하며, 상기 실효 가시거리로 위험 등급을 판정하는 것을 특징으로 하는 방법.

**[청구항 14]**
제11항에 있어서, 휠체어 사용자에 대해 계단 노드를 제거하고, 고령자에 대해 계단 노드에 추가 페널티를 부과하는 그래프 사전 필터링 단계를 더 포함하는 것을 특징으로 하는 방법.

**[청구항 15]**
제11항에 있어서, 취약자에 동반 보호자가 등록된 경우, 두 사람의 제약 조건 중 더 엄격한 것을 병합하여 단일 경로를 생성하고, 대피 중 두 사람의 거리가 소정 임계값을 초과하면 뒤처진 사람 기준으로 경로를 재산출하는 것을 특징으로 하는 방법.

**[청구항 16]**
제15항에 있어서, 상기 소정 임계값은 5m이고, 경로 재산출 시 두 사람의 이동 속도를 느린 쪽에 맞추는 것을 특징으로 하는 방법.

### 제4군: 동적 출구 재배정 (독립항 17, 종속항 18~21)

**[청구항 17]**
복수의 출구를 갖는 시설의 화재 대피 시스템에서,
(a) 각 출구에 배정된 예상 도착 인원 수에 인당 지연 계수(κ)를 곱한 혼잡 페널티를 산출하는 단계;
(b) 상기 혼잡 페널티를 경로 비용 함수에 포함시켜 총비용이 최소인 출구를 배정하는 단계;
(c) 배정 시마다 해당 출구의 인원 수를 갱신하여 다음 대피자의 비용에 즉시 반영하는 단계;
를 포함하며, 전역 최적화 연산 없이 대피자가 복수의 출구로 자동 분산되는 것을 특징으로 하는 동적 출구 재배정 방법.

**[청구항 18]**
제17항에 있어서, 상기 κ는 출구 폭(W)의 역수에 비례하며, 표준 출구 폭 1.2m 기준으로 κ=40초이고, κ = 40 × (1.2/W)로 차등 적용되는 것을 특징으로 하는 방법.

**[청구항 19]**
제17항에 있어서, 출구 위험도가 소정 임계값을 초과하면 차단 상태로 전환하고, 차단 출구의 대피자를 현재 위치 위험도와 유형 취약도에 기초한 우선순위로 잔여 출구에 재배정하는 단계를 더 포함하는 것을 특징으로 하는 방법.

**[청구항 20]**
제17항에 있어서, 배정 인원이 출구 폭 기반 임계값을 초과하면 초과 인원의 제곱에 비례하는 비선형 항이 추가되어 과밀을 억제하는 것을 특징으로 하는 방법.

**[청구항 21]**
제17항에 있어서, 상기 자동 분산은, 모든 배정 완료 후 임의의 두 출구 간 총비용 차이가 κ 이내로 수렴하는 것을 특징으로 하는 방법.

### 제5군: 이중 경로 예측 보정 (독립항 22, 종속항 23~27)

**[청구항 22]**
화재 연기 확산을 예측하는 방법에 있어서,
(a) LSTM 네트워크에 센서 시퀀스를 입력하여 15ms 이내에 예측 맵을 산출하는 Fast Path를 실행하는 단계;
(b) 상기 Fast Path와 병행하여 Navier-Stokes 수치 해석으로 정밀 예측 맵을 5~10초 주기로 산출하는 Slow Path를 실행하는 단계;
(c) Slow Path 완료 시, Fast Path가 동일 시점에 대해 캐시에 저장한 예측과의 손실로 LSTM 출력층 가중치를 갱신하는 온라인 보정 단계;
(d) Fast Path와 Slow Path 출력을 Slow Path 완료 이후 경과 시간에 비례하는 가중치(β)로 병합하는 적응적 병합 단계;
를 포함하는 이중 경로 화재 연기 확산 예측 방법.

**[청구항 23]**
제22항에 있어서, β = min(1.0, elapsed/T_slow)이고, Slow Path 직후에는 β=0으로 Slow Path가 우세하며 시간 경과에 따라 β→1.0으로 Fast Path가 우세해지는 것을 특징으로 하는 방법.

**[청구항 24]**
제22항에 있어서, 보정 후 손실이 보정 전의 110%를 초과하면 가중치를 롤백하고 학습률을 50% 감소시키는 안전 장치를 포함하는 것을 특징으로 하는 방법.

**[청구항 25]**
제22항에 있어서, 온라인 보정은 LSTM의 최종 Dense 레이어만을 대상으로 하고 내부 게이트 가중치는 동결하는 것을 특징으로 하는 방법.

**[청구항 26]**
제22항에 있어서, 상기 손실 함수는 연기 농도(λ=0.5), 온도(λ=0.3), 가시거리(λ=0.2)의 가중 평균 제곱 오차인 것을 특징으로 하는 방법.

**[청구항 27]**
제22항에 있어서, Slow Path 실행 중 문 개폐, HVAC 상태 변경, 새로운 화원 감지에 따라 경계 조건을 동적 갱신하고, 변경 시점부터 재계산하는 것을 특징으로 하는 방법.

### 시스템 및 기록매체 청구항

**[청구항 28]**
제1항, 제6항, 제11항, 제17항, 제22항의 방법을 모두 실행하는 AI 기반 화재 대피 시스템에 있어서,
예측 엔진, 행동 엔진, 결정 엔진 및 이들을 연결하는 이중 버퍼 기반 동기 버스를 포함하고,
상기 결정 엔진은 대피자용 제1 비용 함수와 소방관용 제2 비용 함수를 시공간 예약 테이블에 의해 조율하며,
상기 제1 비용 함수에는 대피자 유형별 안전 마진 계수(α)와 출구별 혼잡 페널티(CrowdPenalty)가 포함되고,
상기 예측 엔진은 LSTM Fast Path와 CFD Slow Path를 병행하여 적응적으로 병합하는 것을 특징으로 하는 시스템.

**[청구항 29]**
제1항, 제6항, 제11항, 제17항, 제22항 중 어느 한 항의 방법을 실행하기 위한 프로그램이 기록된 컴퓨터 판독 가능 기록매체.

## 발명의 효과

### 제1 발명의 효과
1. 이중 버퍼링에 의해 엔진 간 대기 시간이 0이 되어 85ms 이내에 전체 파이프라인이 완료된다.
2. 시간 스탬프 기반 정합성 검증으로 엔진 간 처리 속도 차이에 의한 데이터 불일치가 방지된다.
3. 장애 허용 설계에 의해 단일 엔진 장애 시에도 감쇄된 품질로 대피 안내를 지속한다.

### 제2 발명의 효과
4. 시공간 예약 테이블에 의해 대피자-소방관 역방향 충돌이 사전 방지되어 양쪽 이동 효율이 동시에 극대화된다.
5. PositionScore에 의해 소방관이 풍상, 출구 접근 가능, 대피자 비간섭 위치에 자동 배치된다.
6. ThreatScore에 의해 제한된 소방 인력이 인명 피해 최소화에 가장 효과적인 화원에 우선 투입된다.

### 제3 발명의 효과
7. α가 비용 함수에 직접 반영되므로 별도 전용 알고리즘 없이 개인 맞춤화가 달성된다.
8. 동반 보호자 경로 동기화에 의해 취약자-보호자 분리가 방지된다.
9. 실효 가시거리(V/σ) 개념에 의해 유형별로 다른 위험 등급이 판정되어 세밀한 개인화가 가능하다.

### 제4 발명의 효과
10. CrowdPenalty에 의한 자기 균형으로 전역 최적화 없이 O(N) 복잡도로 대피자가 자동 분산된다.
11. 출구 차단 시 40ms 이내에 재배정과 경로 재계산이 완료된다.
12. 비선형 모델에 의해 임계값 초과 시 과밀이 자연 억제되어 압사 위험이 사전 방지된다.

### 제5 발명의 효과
13. Fast Path에 의해 15ms 실시간 예측이 보장되면서 Slow Path에 의해 물리적 정밀도가 유지된다.
14. 온라인 보정에 의해 LSTM이 현재 화재의 고유 특성에 실시간으로 적응한다.
15. 적응적 가중 병합(β)에 의해 Slow Path의 신선도가 자동 반영된다.

### 종합 효과
16. 상기 제1~제5 발명의 유기적 결합에 의해, 대피 시간이 종래 18분에서 11분으로 약 40% 단축되고, 취약계층의 연기 노출량이 50% 이상 감소하며, 소방관의 구조 효율이 극대화된다.
