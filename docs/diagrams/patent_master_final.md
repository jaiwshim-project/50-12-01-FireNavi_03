## 📌 청구항 1 [독립항 · System · 핵심 결합]

> **재난 상황에서 다수 거주자의 개인별 대피 경로를 실시간 생성하는 통합 시스템에 있어서,**
>
> (a) **WiFi 모듈을 포함하는 실내 위치추적부** — 거주자가 평상시 소지하는 카드에 임베디드된 WiFi 모듈로 약 2~3미터 정밀도의 실내 위치를 실시간 추적하며, 거주자의 일상 동선 데이터로부터 RF 지문 맵을 무감독 학습으로 자동 생성·갱신;
>
> (b) **3개의 AI 엔진을 포함하는 인공지능 다중 엔진부** — 화재·연기 확산을 예측하는 제1 엔진, 군중 흐름·밀집도를 산출하는 제2 엔진, 개인별 최적 경로를 결정하는 제3 엔진이 약 80~120밀리초의 동기 사이클로 동시 작동하며, Lock-free 이중 버퍼를 통해 데이터 정합성이 유지됨;
>
> (c) **개인별 안전 마진 차등 적용부** — 거주자를 6개 유형(고령자·장애인·어린이·임산부·환자·동반보호자)으로 자동 분류하고, 취약계층에게 일반 거주자의 약 1.5~2.5배(바람직하게는 2.0배)의 안전 가중치를 적용하여 차등 경로를 생성하며, 취약자와 보호자가 약 3~7미터 분리 시 보호자 경로를 자동 재계산;
>
> (d) **Cloud-Edge-Device 3계층 분산 처리부** — 클라우드 계층은 모델 학습, 엣지 계층은 시설 내부 실시간 AI 추론, 디바이스 계층은 약 15~60초 분량의 캐시 경로 보유로 네트워크 단절 시에도 무중단 대피 가이드 제공;
>
> 을 포함하며, 상기 (a)~(d) 구성요소의 결합으로 단일 화원 대피 시간을 종래 대비 약 60% 이상 단축하고 취약계층 사상자를 90% 이상 감축하는 **기술적 효과(Technical Effect)**를 달성하는 것을 특징으로 하는, **인공지능 기반 실시간 화재 대피 통합 결정 시스템**.

### ⚙️ 청구항 1의 방어 메커니즘
- **신규성**: 4중 결합 단일 선행 문헌 부재
- **진보성**: 4개 분야 (위치추적·AI·생리학·분산컴퓨팅) 학제 간 결합
- **EPO Art.52 회피**: "기술적 효과 (60% 단축, 90% 감축)" 명시
- **균등론 방어**: 모든 정량값에 범위 표현 (±20ms, 1.5~2.5, 3~7m, 15~60s)

## 📌 청구항 2 [종속항 · 정량 파라미터 + 알고리즘 통합]

> 청구항 1에 있어서,
>
> 상기 인공지능 다중 엔진부는 다음 알고리즘 결합으로 구체화되며:
> (i) 상기 제1 엔진은 **Navier-Stokes 방정식 기반 CFD + LSTM 신경망 + Beer-Lambert 가시거리 산출**의 통합 파이프라인을 포함하고,
> (ii) 상기 제2 엔진은 **Social Force Model + Kernel Density Estimation**을 결합한 군중 동역학을 포함하며,
> (iii) 상기 제3 엔진은 **A* Dynamic Pathfinding + 4-Factor Risk Map** `R(x,y,t) = w₁·F + w₂·S + w₃·D + w₄·C` **+ PPO 강화학습**을 결합한 개인별 경로 결정을 포함하고,
>
> 상기 (c)의 안전 가중치 α=2.0의 근거는 **(i) CO 중독 LC50가 일반 대비 50% 수준**, **(ii) 이동속도 0.5배 → 연기 노출시간 2배 비례**, **(iii) 자력대피 실패 시 구조 평균 3~5분 추가 소요**라는 생리학적·통계학적 근거에 기반하는 것을 특징으로 하는, 시스템.

### ⚙️ 청구항 2의 효과
- **단일 종속항에 알고리즘 + 정량 근거 통합** → 보호 범위 최대화
- **CO LC50 등 의학 데이터** 명시 → KSR 자명성 거절 회피
- **다수 알고리즘 결합** → 회피 설계 거의 불가능

## 📌 청구항 3 [종속항 · 다중 화원 + Monte Carlo 통합 보강]

> 청구항 1에 있어서,
>
> 상기 시스템은 추가로 다음을 더 포함하는 것을 특징으로 하는, 시스템:
> (i) **다중 화원 처리부** — 5개 이상의 동시 발화점에 대해 GPU 코어를 동적으로 분할 할당하고, 위험지도를 `R_total = max(Rᵢ) + Σ interaction(Rᵢ, Rⱼ)` 수식으로 합성하며, 단일 화원 대비 약 1.5배 이내의 응답 시간을 유지;
> (ii) **Monte Carlo 검증부** — 생성된 경로의 안전성을 약 10,000~100,000회 무작위 시뮬레이션으로 검증하여 약 99% 신뢰구간을 산출하고, IMO MSC/Circ.1533 및 NFPA 101 호환 자동 인증 보고서를 생성;
> (iii) **연속 학습부** — Slow Path(CFD) 결과로 Fast Path(LSTM)의 Dense 레이어만 점진 보정하며, 손실값이 110% 초과 시 자동 롤백.

### ⚙️ 청구항 3의 효과
- **3개 보강 기능을 단일 종속항에 통합** → 청구항 간소화
- **IMO/NFPA 표준 호환** 명시 → 산업이용가능성 확보
- **자동 롤백** 명시 → 안전성 확보 + 실용성 입증

## 📌 청구항 4 [독립항 · Apparatus · §101 Alice 회피 확실]

> **하드웨어 구성요소를 포함하는 화재 대피 결정 장치에 있어서,**
>
> (a) **WiFi RF 송수신 모듈** — 거주자 카드에 임베디드된 WiFi 비콘과 약 2.4 GHz 및 5 GHz 대역에서 양방향 통신;
> (b) **GPU 연산 장치** — CUDA Streams를 지원하며, 3개 AI 엔진의 병렬 추론 및 다중 화원 동시 처리를 수행;
> (c) **엣지 컴퓨팅 서버** — 시설 내부에 물리적으로 설치되어 약 80~120밀리초 응답 시간을 보장하는 실시간 AI 추론 수행;
> (d) **디바이스 캐시 메모리** — 거주자 디바이스에 약 15~60초 분량의 경로 데이터를 저장하고 약 5초 주기로 갱신;
> (e) **진동 액추에이터 및 음성 출력 인터페이스** — 시야 차단 환경에서 다국어 가이드를 진동 패턴과 사전 녹음된 음성으로 전달;
> (f) **WebSocket 기반 양방향 실시간 통신 인터페이스** — 약 50밀리초 이하 지연으로 엣지 서버와 디바이스 간 통신;
>
> 을 포함하며, 상기 구성요소들이 청구항 1의 시스템을 물리적으로 구현하고, 컴퓨터 기술의 개선(Improvement to Computer Technology)을 통해 인명 보호의 기술적 효과(Technical Effect)를 달성하는 것을 특징으로 하는, **장치**.

# 🛡️ 5항 청구의 4중 방어 매트릭스

### 방어선 1: **결합 청구항** (Anticipation 회피)
- C-1의 (a)~(d) 4개 필수 구성 요소 결합
- 어떤 단일 선행 문헌도 4개 동시 개시 부재
- → 신규성 (Novelty) 충족 자동

### 방어선 2: **정량 파라미터 7개** (Non-Obviousness)
| 파라미터 | 위치 | 범위 표현 |
|---------|------|---------|
| 2~3m 위치 정밀도 | C-1(a) | 명시 |
| 80~120ms 동기 | C-1(b) | 범위 명시 (균등론 방어) |
| α=1.5~2.5 가중 | C-1(c) | 범위 명시 |
| 3~7m 보호자 분리 | C-1(c) | 범위 명시 |
| 15~60초 캐시 | C-1(d) | 범위 명시 |
| 5+ 다중 화원 | C-3(i) | 하한 명시 |
| 99% 신뢰구간 | C-3(ii) | 명시 |

### 방어선 3: **§101 Alice 회피** (USPTO)
- C-4 Apparatus 독립항 → **물리적 하드웨어** 명시
- 6개 hardware 구성요소 (WiFi RF · GPU · 서버 · 메모리 · 액추에이터 · WebSocket)
- "Improvement to Computer Technology" (Enfish 판례)
- "Technical Effect" (60% 단축, 90% 감축) 정량 효과

### 방어선 4: **EPO Art.52 회피** (유럽)
- "Technical Effect" 명시 (C-1, C-5)
- "Technical Means" = 물리적 hardware (C-4)
- "Solves Technical Problem" = 0.5초 의사결정 + 60% 단축
- COMVIK 판례 (T 0641/00) 적용
