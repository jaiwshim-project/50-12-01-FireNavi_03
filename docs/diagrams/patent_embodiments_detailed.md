## 🔥 화재 발생 시나리오

### 상황 설정

### 🕐 시간대별 AI 엔진 대응 (분 단위 시각화)

#### **t = 0초 (화재 감지)**
- IoT 열감지기 + CCTV가 7층 갤리 화재 감지
- 자동 알람 발령
- FireNavi 시스템 활성화

#### **t = 50ms (Prediction Engine 작동)**
- Navier-Stokes CFD가 연기 확산 예측
- LSTM이 60초 후 7~9층 연기 도달 예측
- Beer-Lambert로 갤리 인근 가시거리 0.5m 산출

#### **t = 100ms (Behavior Engine 작동)**
- Social Force Model로 6,000명 위치·이동 예측
- KDE로 8층 메인 다이닝 (1,200명) 밀집도 위험 감지
- 5층 카지노 (600명) 정상 흐름 확인

#### **t = 150ms (Decision Engine 작동)**
- A* Dynamic으로 각 거주자별 최적 경로 생성
- 4-Factor Risk Map: w₁·F + w₂·S + w₃·D + w₄·C
- 6,000개 개인 경로 동시 결정

#### **t = 200ms (Edge 서버 전송)**
- 6,000명 디바이스로 개인 경로 전송
- 진동 패턴: "긴급 대피, 우측 방향"
- 다국어 음성 가이드 자동 선택

#### **t = 500ms (Device 작동 시작)**
- 객실 키 카드 진동 시작 (LRA 액추에이터)
- 압전 스피커 음성 가이드 (모국어)
- 화살표 표시 (소형 LED)

### 🕐 AI 엔진 대응 (병원 특화)

#### **t = 0 (감지)**
- 5층 502호 화재 감지
- FireNavi 활성화 + **의료 시설 특화 알고리즘**

#### **t = 100ms (병원 특화 분류)**
- 5층 환자 자동 분류:
  - 자력 대피 가능: 8명
  - 거동 보조: 22명 (휠체어·보행보조기)
  - 침대 이송: 18명 (수술 후·중환자)
- **의료진 매칭 동시 산출**: 환자당 의료진 배정

#### **t = 200ms (3계층 대피 경로)**

#### **t = 500ms (의료진 통합 지시)**
- 의료진 디바이스에 환자 구조 명단 + 동선 표시
- 응급실·수술실은 별도 안전 확인
- 외부 119 자동 알림 (위치·환자 수·중증도 자동 전송)

### 👤 5명 대표 페르소나 대피

#### **페르소나 1: 김 할머니 (82세, 5층 502호, 화재 발생 병실)**
- 분류: 침대 이송 필요 (α=2.5)
- 의료 장비: 산소공급기·심전도 모니터
- 매칭 의료진: 간호사 2명 + 의사 1명 (3인 1조)
- 경로: 502호 침대 → 5층 동측 → **수평 대피** (같은 5층 별관) → 안전 확인
- 대피 시간: **3분 10초** (수평 대피로 단축)
- AI 가이드: "환자 침대를 별관 5층으로 이동, 의료 장비 동행"

#### **페르소나 2: 최 환자 (45세, 7층 ICU)**
- 분류: 중환자 (α=3.0)
- 의료 장비: 인공호흡기·ECMO
- 매칭 의료진: ICU 전담팀 4명
- 경로: ICU 환자는 **위치 유지 + 음압 차단** (연기 차단 시스템 작동)
- 대피 우선순위: 화재가 ICU에 도달할 때까지 대기 → 도달 임박 시 별관 ICU로 이동
- AI 모니터링: 5층 → 7층 연기 도달 시간 실시간 예측

#### **페르소나 3: 이 환자 (10세, 6층 소아과)**
- 분류: 어린이 (α=1.8) + 부모 보호자
- 경로: 소아과 → 6층 비상계단 → 1층 정문
- 대피 시간: **4분 30초**
- 부모 동기화: 부모 위치 즉시 알림 → 함께 대피
- AI 가이드: "엄마 손 잡고 천천히, 119가 기다리고 있어요"

#### **페르소나 4: 박 외과의 (당직, 35세)**

- 위치: 7층 의국
- 역할 배정: 5층 침대 이송 환자 3명 담당
- 경로: 의국 → 5층 (즉시 진입) → 환자 502·504·506호 순차 이송
- AI 정보: 각 환자 의료 정보 + 이동 시 주의사항 디바이스 표시

#### **페르소나 5: 응급실 의료진 (1층)**
- 분류: 응급실 운영 (대피 vs 유지 결정)
- AI 판단: 1층 응급실은 안전 (화원 5층, 직접 위협 없음)
