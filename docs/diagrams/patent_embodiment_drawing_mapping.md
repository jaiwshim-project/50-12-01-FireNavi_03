## 1. 표준 인용 양식

### KIPO 양식
```
"도 N을 참조하면, ..."
"도 N에 도시된 바와 같이, ..."
"도 N의 (a)~(d)는 ...을 나타낸다."
```

### 다중 도면 인용
```
"도 1 및 도 6을 참조하면, ..."
"도 8, 도 9 및 도 10을 함께 참조하면, ..."
```

### 부호 표시 인용
```
"위치추적부(110, 도 4)는 ..."
```
