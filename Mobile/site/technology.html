Stage 5 · Bayesian Map + Adaptive Routing

🗺️ 베이지안 화재맵 + 적응 경로 — 4채널 융합 → 30유형 Health-Aware 경로

4채널(F/S/D/C) 베이지안 사후확률 화재맵을 2m×2m 격자로 5초마다 갱신하고, A* Dynamic + Risk Penalty + α=2.0 가중치로 개인별 적응 경로를 계산합니다.

격자 2m×2m · 갱신 5초 · 4채널 F/S/D/C · α=2.0 취약계층 · 30유형 Health-Aware · Exit Crowd Balancing
베이지안 융합 공식
P(Fire_c | R_1, R_2, ..., R_M)
  = α · P(R_1, ..., R_M | Fire_c) · P(Fire_c)

가중치 w_m:
  w_visual    = 1.0   # 사용자 직접 시각 보고
  w_olfactory = 0.7   # 후각·냄새
  w_audio     = 0.5   # 마이크 비명
  w_imu       = 0.4   # 가속도 추정
  w_light     = 0.3   # 조도 추정
4채널 출력
채널입력의미
F Fire시각 보고 + 폰 온도직접 화염 위치
S Smoke후각 + 조도 감소연기 확산 영역
D Damage진동 IMU + BIM구조 손상
C Crowd위치 군집 + 비명군중 패닉 영역
시공간 스무딩
P_smoothed(c, t) =
  Σ K_spatial(c, c') · P(c', t)
+ Σ K_temporal(t, t') · P(c, t')

K_spatial:  Gaussian
  (σ_xy=4m, σ_z=1층)
K_temporal: Exponential
  (반감기 30초)
A* Dynamic + Risk Penalty + α=2.0
f(n) = g(n) + h(n) + R(n) + Penalty
- g(n): 시작→현재 누적 비용
- h(n): 현재→목표 휴리스틱
- R(n): 동적 위험 페널티 (4채널 합성)
- α   : 1.0 (일반) / 2.0 (취약계층)

# Exit Crowd Balancing (출구 분산)
Score(exit_j, person_i)
  = Distance + FirePenalty×α + SmokePenalty×α + CrowdPenalty
CrowdPenalty(exit_j) = N_assigned × 40
→ 먼 출구라도 혼잡하지 않으면 자동 배정, 병목 차단
30유형 Health-Aware Routing (v3.0 확장)

v2.0의 6유형(건강한 성인·고령자·어린이·휠체어·시각장애·청각장애)을 30유형으로 6배 정밀 확대합니다. 신체·거동·부상·감각·인지·언어외적 6개 카테고리로 분류, 각 유형별 자유속도·계단 회피·E/V 필수·연기마진·안내 채널을 차별화합니다.
