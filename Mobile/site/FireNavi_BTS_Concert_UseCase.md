# FireNavi BTS 공연장 활용 시나리오

## 핵심 요약 (1문장)

FireNavi는 BTS 공연장에서 위급상황 발생 시, 관객의 스마트폰을 통해 위험 신호를 감지하고, 개인 위치와 군중 밀집도를 분석한 뒤, 가장 안전한 출구·대피구역·집결지로 사람마다 다른 경로를 안내하는 AI 재난대피 시스템입니다.

즉, 공연장 전체를 하나의 "살아 있는 안전 네트워크"로 바꾸는 솔루션입니다.

---

## 1. BTS 공연장의 특수성

BTS 공연장은 일반 공연장과 다릅니다:

- **관객 수**: 수만 명 동시 집결
- **외국인 비율**: 글로벌 팬 비율 높음
- **공연 중 사용량**: 조명·음향·통신 사용량 과다
- **감정적 몰입도**: 관객의 집중도와 흥분도 매우 높음

### 발생 가능한 위급상황

1. **정전**: 조명, 전광판, 안내 시스템 마비 → 방향 감각 상실
2. **화재**: 무대 장치, 전기 설비, 조명 장비, 푸드존, 배터리 장비
3. **지진**: 실내 공연장, 돔구장, 체육관, 스타디움 진동 → 동시 이동 위험
4. **테러·폭발물 의심**: 의심 물체 발견, 폭발음, 비정상 행동, 특정 구역 통제
5. **인파 밀집·압사 위험**: 입장, 퇴장, 굿즈 판매대, 포토존, 지하철 연결 통로, 출구 계단
6. **외국인 관객 혼란**: 한국어 안내방송 이해 불가
7. **통신망 과부하**: 수만 명 동시 스마트폰 사용 → 긴급 안내 전달 실패

→ FireNavi는 이 모든 상황에 대해 **"감지 → 판단 → 안내 → 관제 → 구조"** 의 흐름으로 대응합니다.

## 2. FireNavi 5단계 작동 구조

### 1단계: 위급상황 감지

FireNavi는 여러 신호를 동시에 감지합니다:

- 화재경보음
- "불이야", "도와줘", "연기" 같은 음성
- 비명, 폭발음, 유리 파손음
- 조도 급감 또는 정전
- 스마트폰 급진동
- 다수 관객의 급격한 이동
- 관객 SOS 신고
- 공연장 화재감지기, CCTV, 출입게이트, 비상방송 시스템
- 관제센터 비상 푸시

**신호 조합 예시**:
- 화재경보음 1건 → "주의 모드"
- 화재경보음 + 연기 신고 + 특정 구역 관객 급이동 → "대피 모드"
- 폭발음 + 비명 + 다수 관객 역방향 이동 → "긴급 대피 및 구조 모드"

### 2단계: 관객 위치와 군중 밀집도 파악

**활용 정보**:
- 티켓 좌석 정보
- 입장 게이트 정보
- 스마트폰 Wi-Fi/BLE 신호
- 공연장 AP 접속 정보
- 기압계·IMU 기반 이동 추정
- CCTV 기반 군중 밀도
- 관객 앱 위치 동의 정보
- 출입구 통과 데이터

**구역 파악 수준**:
- A구역 스탠딩존
- 2층 13구역
- 3층 동측 관객석
- 굿즈 판매대 주변
- 지하철 연결 통로
- 출구 7번 주변
- 화장실 앞 병목구역
- 장애인석 구역
- 외국인 단체 관람 구역

### 3단계: 위험지도 생성

FireNavi는 공연장 전체를 실시간 위험지도로 만듭니다:

**위험지도 표시 정보**:
- 화재 위치
- 연기 확산 방향
- 정전 구역
- 출구 혼잡도
- 계단 병목
- 넘어짐·낙상 신고 구역
- 지진 진동 감지 구역
- 테러 의심 통제 구역
- 안전한 대피 가능 구역
- 임시 집결지
- 구급차 접근로
- 구조대 진입로

**차별점**: 연기 확산 방향, 관객 밀집도, 출구 수용량, 계단 폭, 장애인석 위치, 외국인 관객 위치를 함께 고려합니다.

### 4단계: 개인별 맞춤 대피 경로 안내

**FireNavi의 가장 큰 차별점**: "모두에게 같은 출구를 안내하지 않는다"

**관객 유형별 안내**:

| 관객 유형 | 안내 방식 |
|---------|---------|
| 일반 관객 | 혼잡도 낮고 위험 낮은 출구 |
| 스탠딩존 관객 | 구역별 분산 대피 경로 |
| 2층·3층 관객 | 계단 혼잡도 반영 출구 분산 |
| 휠체어 이용 관객 | 엘리베이터, 경사로, 장애인 대피구역, 구조대 접근로 |
| 어린이 동반 관객 | 보호자와 동기화된 경로 |
| 외국인 관객 | 다국어 안내 (영어, 일본어, 중국어, 스페인어 등) |
| 고령자·호흡기 취약자 | 연기 위험 낮고 이동 부담 적은 경로 |
| 미응답 관객 | 관제센터에 "확인 필요" 또는 "구조 우선 후보" 표시 |

## 3. 상황별 시나리오

### 시나리오 1: 공연 중 정전 발생

**상황**:
- 공연 중 조명이 갑자기 꺼지고, 일부 전광판도 멈춤
- 관객들이 놀라 스마트폰 플래시를 켜고 움직이기 시작

**FireNavi 작동**:
- 조도 급감 감지
- 다수 스마트폰의 움직임 증가 감지
- 관제센터에서 정전 이벤트 확인
- 앱이 자동으로 "주의 모드" 전환
- 좌석 구역별로 대기 안내 또는 순차 이동 안내
- 비상등이 켜진 통로를 기준으로 경로 안내
- 출구 혼잡도에 따라 퇴장 순서 조정

**관객 안내 예시**:
> "현재 공연장 동측 구역에 정전이 발생했습니다. 이동하지 말고 좌석에서 대기해 주세요. 2층 A구역은 3분 후 4번 출구 방향으로 순차 이동합니다."

**효과**:
- 패닉 방지
- 동시 이동 방지
- 압사 위험 감소
- 외국인 관객에게 다국어 안내 가능

### 시나리오 2: 무대 후면 화재 발생

**상황**:
- 무대 후면 장비 구역에서 연기 발생
- 일부 관객이 냄새와 연기를 신고

**FireNavi 작동**:
- 화재경보음 감지
- 연기 신고 접수
- CCTV 또는 화재감지기 신호 연동
- 무대 후면 위험구역 표시
- 연기 확산 방향 예측
- 가까워도 위험한 출구는 제외
- 구역별 대체 출구 자동 배정
- 관객 스마트폰에 경로 표시

**관객 안내 예시**:
> "현재 무대 오른쪽 후면에서 연기 위험이 감지되었습니다. 1층 C구역 관객은 5번 출구가 아닌 3번 출구 방향으로 이동해 주세요. 안내 화살표를 따라 천천히 이동하십시오."

**효과**:
- 위험 출구 회피
- 군중 분산
- 연기 노출 감소
- 관제센터와 구조대가 취약자 위치 확인 가능

### 시나리오 3: 지진 발생

**상황**:
- 공연 중 흔들림 발생
- 관객이 동시에 출구로 몰릴 위험

**FireNavi 작동**:
- 다수 스마트폰의 동시 진동 패턴 감지
- 관제센터 지진 경보 연동
- 즉시 "대피"가 아니라 "보호 행동 안내" 우선
- 낙하물 위험 구역 표시
- 흔들림 종료 후 순차 대피 안내
- 계단·출구 혼잡도에 따라 퇴장 순서 조정

**관객 안내 예시**:
> "지진 흔들림이 감지되었습니다. 즉시 뛰지 마시고, 머리를 보호하고 좌석 아래 또는 주변 구조물에서 떨어져 대기하십시오. 흔들림이 멈춘 후 순차 대피 안내가 제공됩니다."

**효과**:
- 동시 이동으로 인한 압사 방지
- 낙상 방지
- 안정적 순차 대피 가능

### 시나리오 4: 테러 의심 또는 폭발음 발생

**상황**:
- 특정 게이트 주변에서 폭발음 또는 의심 물체 신고 접수

**FireNavi 작동**:
- 폭발음·비명 감지
- 사용자 신고 접수
- 해당 구역 위험도 상승
- 관제센터 확인
- 위험구역 주변 접근 차단
- 반대 방향 우회 경로 안내
- 해당 구역 관객에게는 낮은 자세 유지 또는 즉시 이탈 안내
- 구조대·보안팀 접근 경로 표시

**관객 안내 예시**:
> "현재 7번 게이트 주변 접근이 제한되었습니다. 2층 동측 관객은 7번 게이트로 이동하지 말고 5번 또는 6번 출구 방향으로 안내를 따라 이동해 주세요."

**효과**:
- 위험구역 접근 차단
- 관객 역류 방지
- 보안팀 대응 지원
- 구조대 진입 경로 확보

### 시나리오 5: 공연 종료 후 압사 위험

**상황**:
- 공연 종료 후 관객 수만 명이 동시에 출구, 지하철 연결 통로, 굿즈존, 포토존으로 몰림

**FireNavi 작동**:
- 출구별 밀집도 분석
- 다수 스마트폰 이동 방향 분석
- CCTV 군중 밀도 연동
- 출구별 혼잡도 점수 계산
- 관객 구역별 퇴장 순서 안내
- 혼잡 구역 우회 안내
- 굿즈존·포토존 접근 제한 안내

**관객 안내 예시**:
> "현재 3번 출구와 지하철 연결 통로가 매우 혼잡합니다. 1층 B구역 관객은 2분간 대기 후 5번 출구로 이동해 주세요. 예상 퇴장 시간은 6분입니다."

**효과**:
- 압사 위험 감소
- 출구 분산
- 현장 스태프 업무 부담 감소
- 관객 만족도 향상

## 4. BTS 공연장 특화 기능

### 1. 다국어 AI 대피 안내

**지원 언어**:
- 한국어, 영어, 일본어, 중국어, 스페인어, 프랑스어, 태국어, 베트남어, 아랍어

**안내 예시**:
- 한국어: "오른쪽 출구가 혼잡합니다. 왼쪽 3번 출구로 이동하세요."
- 영어: "Exit 4 is overcrowded. Please move to Exit 3 on your left."
- 일본어: "右側の出口は混雑しています。左側の3番出口へ移動してください。"

### 2. 좌석·티켓 기반 개인별 안내

**연동 정보**:
- 좌석 구역, 층, 열
- 입장 게이트
- 가장 가까운 출구
- 장애인석 여부
- 동반자 여부
- VIP 구역 여부
- 스탠딩존 입장 순번

### 3. 응원봉 연동 가능성 (향후)

**활용 방안** (공식 운영사 협약 필요):
- 특정 구역 응원봉 색상 변경
- 대피 방향에 따라 좌우 색상 안내
- 위험구역: 빨간색 점멸
- 안전 이동 방향: 초록색 점멸
- 대기 구역: 파란색 점등

→ 공연장 안전 UX에서 매우 독창적인 솔루션

### 4. 팬 커뮤니티형 안전 확인

**제공 기능**:
- 동행자 그룹 등록
- 일행 위치 확인
- 대피 중 이탈자 알림
- 안전 도착 확인
- 외국인 팬 전용 도움 요청
- 보호자·미성년자 동기화

**안내 예시**:
> "등록된 동행자 4명 중 3명이 안전구역에 도착했습니다. 1명은 2층 C구역에 있으며 구조 확인 대상입니다."

### 5. 공연장 스태프·보안요원 전용 모드

**스태프용 FireNavi 표시 정보**:
- 담당 구역 혼잡도
- 위험 신고 위치
- 낙상자·부상자 위치
- 출구별 병목 상황
- 관객 이동 방향
- 장애인석 지원 요청
- 외국어 도움 요청
- 구조대 접근 경로

→ 현장 스태프가 무전만으로 대응하는 한계 보완

### 6. 공연장 관제센터 통합

**관제센터 화면 제공 정보**:
- 전체 공연장 위험지도
- 구역별 관객 밀집도
- 출구별 혼잡도
- 화재·연기·정전·지진 이벤트
- 실시간 신고 위치
- 미응답자 위치
- 취약계층 위치
- 스태프 위치
- 구조대 접근로
- 대피 완료율
- 구역별 예상 퇴장 시간

**관제센터 의사결정 지원**:
- 어느 출구를 열 것인가
- 어느 출구를 막을 것인가
- 어느 구역부터 퇴장시킬 것인가
- 어느 구역에 스태프를 보낼 것인가
- 구급차는 어느 게이트로 접근해야 하는가
- 외국인 안내를 어디에 집중할 것인가
- 방송은 어떤 언어로 해야 하는가

## 5. BTS 공연장용 FireNavi 핵심 차별성 7가지

1. **개인별 안내**: 모두에게 같은 안내가 아니라 개인별 안내 제공
2. **다국어 지원**: 외국인 팬도 모국어로 안내 수신
3. **관객 분산**: 출구 혼잡도를 반영해 관객을 분산
4. **정전 대응**: 스마트폰 화면·진동·음성으로 안내 가능
5. **압사 방지**: 사전 감지 및 퇴장 순서 조절
6. **취약계층 보호**: 별도 관리 및 우선 지원
7. **통합 관제**: 관제센터와 현장 스태프가 같은 위험지도 공유

## 6. 실제 적용 구조

```
관객 스마트폰 앱
→ 좌석·위치·언어·상태 정보 확인
→ 위험상황 발생 시 개인별 안내

공연장 Wi-Fi/BLE/통신망
→ 구역별 위치와 밀집도 파악

공연장 IoT·CCTV·화재감지기
→ 화재, 연기, 정전, 군중 이상 감지

FireNavi AI 엔진
→ 위험지도 생성
→ 대피 경로 계산
→ 취약계층 우선순위 판단
→ 다국어 안내 생성

관제센터
→ 전체 상황 모니터링
→ 출구 개폐, 스태프 배치, 구조대 지원

스태프 앱
→ 구역별 임무 지시
→ 위험신고 확인
→ 관객 분산 유도

구조대 연계
→ 부상자, 미응답자, 취약계층 위치 확인
→ 최적 접근 경로 제공
```

## 7. 중간심사/발표용 데모 시나리오

**시나리오 제목**: "BTS 콘서트 종료 직전, 3번 게이트 주변 화재 및 압사 위험 발생"

**상황**:
- 공연 종료 직전, 3번 게이트 주변 푸드존에서 연기와 화재 발생
- 동시에 관객들이 퇴장 준비를 하면서 3번 게이트 방향으로 몰림

**FireNavi 작동**:
1. 화재경보음과 연기 신고 감지
2. 3번 게이트 주변 위험도 상승
3. 관객 이동 데이터에서 3번 게이트 방향 밀집도 급증
4. FireNavi가 3번 게이트를 위험·혼잡 출구로 분류
5. 1층 A구역 관객 → 2번 출구 안내
6. 1층 B구역 관객 → 4번 출구 분산 안내
7. 장애인석 관객 → 스태프 지원 경로 안내
8. 외국인 관객 → 앱 언어별 안내 자동 표시
9. 관제센터 → 3번 게이트 주변에 스태프와 소방요원 배치
10. 미응답자와 낙상 신고자 → 구조 우선순위 표시

**심사위원에게 보여줄 메시지**:
> "FireNavi는 공연장 위급상황에서 관객 모두를 한 방향으로 몰아넣지 않고, 각자의 위치와 상태에 따라 가장 안전한 출구와 이동 순서를 안내합니다."

## 9. 특허 확장 가능성

### 공연장 특화 특허 아이템

1. 공연장 관객 밀집도 기반 개인별 퇴장 경로 분산 시스템
2. 다국어 AI 대피 안내 기반 글로벌 공연장 안전 플랫폼
3. 티켓 좌석정보와 실시간 위험지도를 결합한 공연장 대피 경로 추천 시스템
4. 응원봉 또는 웨어러블 장치와 연동한 대피 방향 안내 시스템
5. 공연장 관제센터와 관객 스마트폰을 연결한 군중 안전 의사결정 시스템
6. 외국인 관객 언어설정 기반 재난 안내 자동 변환 시스템
7. 공연 종료 시 군중 밀집 예측 기반 순차 퇴장 안내 시스템

### 가장 강한 특허 (추천)

**"티켓 좌석정보, 실시간 군중 밀집도, 위험지도 및 사용자 언어 정보를 기반으로 관객별 대피 경로와 퇴장 순서를 자동 생성하는 공연장 재난대피 안내 시스템"**

→ FireNavi의 공연장 특화 버전으로 매우 유망

## 10. 최종 정리 (1문장)

**FireNavi는 BTS 공연장에서 수만 명의 팬을 하나의 군중으로 보지 않고, 각자의 위치·언어·상태·위험 노출도를 가진 개인으로 인식하여, 가장 안전한 대피 경로와 순차 이동을 안내하는 AI 기반 글로벌 공연장 안전 플랫폼으로 활용될 수 있습니다.**
