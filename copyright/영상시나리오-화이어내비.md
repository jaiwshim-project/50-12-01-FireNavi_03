## PART 1 — 왜 만드는가 (120초)

### 대사 (약 680자)

> "안녕하세요, FireNavi 대표 심재우입니다.
>
> 전 세계 크루즈 시장은 500억 달러 규모입니다. 매년 30척 이상의 크루즈선이 건조되고, 한 척에 6,000명이 탑승합니다. 그런데 매년 15건의 화재 사고가 발생하고, 평균 손실액은 5천만 달러에 달합니다. 2012년 코스타 콩코르디아호 침몰 사고에서 32명이 사망했습니다. 대형 선박에서의 재난 대응은 여전히 해결되지 않은 문제입니다.
>
> 기존 대피 시스템을 보겠습니다. 복도에 붙은 정적 대피도, 그리고 방송 안내. 이것이 전부입니다. 화재가 어디서 번지고, 연기가 어디로 퍼지는지 반영하지 못합니다. 6,000명이 동시에 대피해야 하는 상황에서, 모든 승객에게 같은 출구를 안내하면 병목이 발생하고, 취약 계층은 뒤처집니다. 고령자, 휠체어 사용자, 어린이는 일반 승객과 같은 경로를 갈 수 없습니다.
>
> FireNavi는 이 문제를 근본적으로 해결합니다.
>
> 첫째, 3개 AI 엔진이 동시에 작동합니다. Prediction AI가 Navier-Stokes 방정식과 LSTM 신경망으로 연기 확산을 예측합니다. Behavior AI가 Social Force Model로 군집 행동을 분석합니다. 그리고 Decision AI가 6,000명 각각에게 최적의 생존 경로를 실시간으로 결정합니다.
>
> 둘째, WiFi 기반 실내 위치추적으로 모든 승객의 위치를 2~3미터 정확도로 파악합니다. 객실 키에 WiFi 모듈이 내장되어, 추가 장비가 필요 없습니다.
>
> 셋째, 화재 진압이 필요한 순간, AI가 소방관의 최적 투입 위치를 자동으로 판단합니다. 바람 방향, 승객 대피 경로, 출구 접근성을 종합 분석하여 가장 효과적인 진압 위치를 추천합니다.
>
> FireNavi는 길을 안내하는 것이 아니라, 생존을 설계합니다."

## PART 2 보충 — 4개 층별 화재 시뮬레이션 녹화 가이드

> 영상 본편(30초)에서는 대표 1개 시나리오를 사용하고,
> 나머지 3개는 별도 시연 영상 또는 편집 소스로 활용

### 시나리오 ① — 5층 객실 화재 (대표 시나리오, 본편 사용 권장)

| 항목 | 내용 |
|------|------|
| **층 선택** | `5층 객실` 버튼 클릭 |
| **레이아웃** | 상·중·하 3개 수평복도 + 양쪽 밀집 객실 + 하단 기관실 |
| **화재 위치** | 중앙 객실 밀집구역 (좌표 약 x:40, y:18 부근) — 복도 교차점 근처 |
| **승객 수** | 60~80명 (객실 밀집 → 대피 경로 분산 효과가 잘 보임) |
| **관전 포인트** | 객실 출입구 → 복도 → 계단/출구 순서로 대피하는 **개인별 경로 시각화** |
| **강조할 AI 기능** | ① 출구 분산 최적화 (CrowdPenalty) ② 연기 확산 예측 ③ 취약계층 우선경로 |
| **녹화 시간** | 시뮬 시작 후 약 20~30초 (1.5x~2x 속도) |
| **녹화 팁** | 화재 발생 직후 AI 상태바가 "대기→가동 중"으로 바뀌는 순간 캡처 |

**왜 대표 시나리오인가:** 객실이 밀집되어 있어 다양한 승객 유형이 각기 다른 경로로 대피하는 모습이 가장 극적으로 보임. 복도 교차점에서의 경로 분기가 시각적으로 인상적.

### 각 시나리오 공통 녹화 절차

```
1. 층 선택 버튼 클릭
2. 승객 수 입력 (시나리오별 권장 수치)
3. 화재 위치 클릭 (시나리오별 권장 좌표)
4. "대피 시작" 클릭 → AI 상태바 변화 확인
5. 재생 속도 조절 (1.5x~2x)
6. 대피 진행 중 "🧠 AI 최적 투입" 버튼 클릭 → AI 추천 위치에 소방관 자동 투입
7. 소방관 진입 → 화재 접근 → 진압 과정 녹화
8. 대피 완료 또는 핵심 장면까지 녹화
9. 우측 통계 패널 (대피완료/잔여/위험 인원) 포함되도록 화면 구성
```

## PART 4 — 비전 + 마무리 (120초)

### 대사 (약 640자)
