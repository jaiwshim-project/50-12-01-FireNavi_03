## 3. 창작성 설명

본 저작물은 다음과 같은 독창적 창작 요소를 포함하며, 기존에 존재하지 않는 고유한 기술 저작물이다.

### 3.1 기술-1: 삼중 엔진 100ms 동기 연동의 독창적 설계

화재 확산 예측(CFD/LSTM), 군중 행동 분석(Social Force/KDE), 경로 결정(A*/CBS)이라는 계산 특성이 전혀 다른 세 가지 AI 엔진을 하나의 파이프라인 내에서 100ms 이내에 동기 연동하는 구체적 방법을 독자적으로 설계하였다.

**독창적 표현 요소:**
- 이중 버퍼(Buffer A/B) 교환에 의한 lock-free 엔진 간 데이터 전달 구조
- 시간 스탬프 기반 데이터 정합성 검증 메커니즘 (|ts_pred - ts_behav| ≤ 200ms)
- 정합성 불일치 시 선형 보간 보정 공식
- 파이프라인 타이밍 분배: S100(15ms) + S300(30ms) + S400(40ms) = 85ms
- 잔여 시간의 다음 사이클 선행 실행 할당
- 엔진별 장애 허용 폴백 설계: 지수 감쇄 P_fallback = P_last × exp(-elapsed/5.0)

이러한 구체적 수치, 단계별 절차, 장애 허용 로직의 조합은 기존 학술 문헌에서 발견되지 않는 독창적 기술 표현이다.

### 3.2 기술-2: 이원 비용 함수 및 시공간 예약 테이블의 독창적 설계

동일한 동적 위험지도 위에서 대피자(위험 회피)와 소방관(위험 진입)이라는 정반대 목적을 가진 두 그룹의 경로를 동시에 생성하고, 물리적 간섭을 자동으로 방지하는 통합 시스템을 독자적으로 설계하였다.

**독창적 표현 요소:**
- Safety-First A* 비용 함수: f_evac(n) = g(n) + h(n) + γ×R(n)×(1+α)
- Straight-Line A* 비용 함수: f_fire(n) = g(n) + h_fire(n) + I(n) (R(n) 배제)
- 시공간 예약 테이블(STRT) 구조: [node_id][time_slot] = {reserved_by, direction, capacity}
- 역방향 충돌 판정 공식: cos(θ) < -0.5 (120°~240° 범위)
- 예약 우선순위: 대피자 우선 → 소방관 후순위
- PositionScore 합산 공식: Upwind(40) + ExitAccess(30) - PassengerBlock(5N) + MultiFireCover(10) - FFOverlap(20) + CorridorBonus(15)
- ThreatScore 합산 공식: PassengerCount×100 + BlockedPassengers×30 + SmokeAffected×15 + ExitThreats×40 + FireRadius×2 - ExistingFF×80
- 각 계수(100, 30, 15, 40, 2, -80)의 도출 근거 기술

이러한 이원 비용 함수의 상반된 설계와 STRT에 의한 간섭 방지 메커니즘의 조합은 기존 연구에서 발견되지 않는 독창적 기술 표현이다.

### 3.3 기술-3: α 계수 체계 및 동반 보호자 동기화의 독창적 설계

대피자의 건강 상태에 기초한 안전 마진 계수(α)를 정의하고, 이를 비용 함수의 화재·연기 항에만 선택적으로 승수 적용하며, 동반 보호자와의 경로를 동기화하는 방법을 독자적으로 설계하였다.

**독창적 표현 요소:**
- 6가지 대피자 유형별 파라미터 체계: {v_free, v_stair, stair_capable, α, σ_smoke}
- α=2.0의 세 가지 정량적 도출 근거:
  - 생리적: CO 중독 LC50이 건강 성인의 50% → 위험 2배
  - 물리적: 이동 속도 0.5배 → 노출 시간 2배
  - 시스템적: 자력 대피 실패 시 구조 비용 3~5분/건
- 선택적 α 적용 공식: R = α×[w₁F + w₂S] + w₃D + w₄C (F,S에만 적용, D,C에는 미적용)
- 실효 가시거리 공식: V_effective = V_actual / σ_smoke
- 동반 보호자 제약 병합: min(v_free), max(α), max(σ)
- 분리 감지 임계값 5m 및 뒤처진 사람 기준 경로 재산출 프로토콜

이러한 α의 선택적 적용 논리, 도출 근거의 다면적 기술, 동반 보호자 동기화 프로토콜의 조합은 기존 연구에서 발견되지 않는 독창적 기술 표현이다.

### 3.4 기술-4: CrowdPenalty 자기 균형 메커니즘의 독창적 설계

출구별 혼잡 페널티에 의해, 전역 최적화 연산 없이 각 대피자가 개별 비용 함수만으로 최적 출구를 선택하면 시스템 전체가 자동으로 균형에 수렴하는 자기 균형(Self-Balancing) 메커니즘을 독자적으로 설계하였다.

**독창적 표현 요소:**
- CrowdPenalty 공식: N_assigned × κ
- κ=40의 물리적 도출: 출구 통과 용량(W×φ=1.2×1.3=1.56명/초)으로부터 1인 추가 지연 시간 산출, 안전 마진 포함 정수 근사
- 출구 폭별 κ 차등: κ(j) = 40 × (1.2/W_j)
- 자기 균형 수렴 정리: 배정 완료 후 |TotalCost(j₁) - TotalCost(j₂)| ≤ κ
- 출구 차단 시 재배정 우선순위: R(position) + (1-α⁻¹)×100 + distance×(-1)
- 비선형 혼잡 모델: κ×N×(1 + η×max(0, N-N_threshold)²), η=0.001

이러한 자기 균형 메커니즘의 수학적 정의, κ의 물리적 도출, 비선형 확장, 수렴 증명의 조합은 기존 연구에서 발견되지 않는 독창적 기술 표현이다.

### 3.5 기술-5: Dual-Path 예측 아키텍처의 독창적 설계

LSTM 실시간 추론(Fast Path)과 CFD 정밀 해석(Slow Path)을 동일 시스템 내에서 병행 실행하고, Slow Path에 의한 Fast Path 온라인 보정과 경과 시간 기반 적응적 가중 병합을 수행하는 방법을 독자적으로 설계하였다.

**독창적 표현 요소:**
- Dual-Path 아키텍처: Fast(LSTM, 15ms) + Slow(CFD, 5~10초) 병행 실행
- LSTM 네트워크 구조: LSTM(4n,128)→LSTM(128,64)→Dense(64,W×H×D×3)
- 출력 3채널 설계: 연기 농도 C, 온도 T, 가시거리 V
- 온라인 보정: Slow Path 결과로 Dense 레이어만 경사하강법 갱신 (LSTM 게이트 동결)
- 채널별 가중 손실: λ_C=0.5, λ_T=0.3, λ_V=0.2
- 롤백 안전 장치: Loss_after > Loss_before×1.1이면 롤백 + lr×0.5
- 적응적 가중 병합: β = min(1.0, elapsed/T_slow)
- 이상 상황별 폴백: Slow 지연→β=1.0, Fast 이상→β=0.0, 양쪽 이상→지수 감쇄
- 예측 캐시: CircularBuffer(capacity=20)에 과거 예측 저장, Slow 완료 시 매칭 참조

이러한 Dual-Path 구조, 부분 미세 조정(Dense만), 적응적 β, 롤백 안전 장치, 캐시 기반 보정의 조합은 기존 연구에서 발견되지 않는 독창적 기술 표현이다.

### 3.6 시각 저작물: FireNavi 기술 인포그래픽의 독창적 표현

본 저작물에는 FireNavi의 핵심 기술을 시각적으로 종합한 2건의 독창적 도형저작물(인포그래픽 및 아키텍처 다이어그램)이 포함되며, 이는 어문저작물의 내용을 보완하는 미술저작물로서 독립적 보호 가치를 갖는다.

#### 3.6.1 FireNavi 전체 개요 인포그래픽 (FireNavi_인포그래픽.png)

FireNavi 플랫폼의 전체 기술 체계를 하나의 시각적 구성으로 종합한 인포그래픽이다.

**독창적 시각 표현 요소:**
- 기존 고정 표지판 방식과 FireNavi 동적 AI 경로의 대비적 시각 구성
- 3대 AI 엔진(Prediction·Behavior·Decision)의 동시 작동 구조를 화재 현장 투시도 위에 중첩 배치한 복합 레이어 구성
- 6가지 대피자 유형(건강한 성인 v:0.9~1.0, 고령자/임산부 v:0.5~, 휠체어 v:0.2~0.4)의 이동 특성을 아이콘과 수치로 병렬 배치한 유형 분류 시각 체계
- 우선 구조 디바이스(PRD) 시스템의 기능을 아이콘 흐름도로 표현
- 다중 요소 동적 위험지도의 히트맵 시각화와 대피 시간 40% 단축(기존 18분→AI 최적화 11분)의 정량적 성과를 하나의 화면에 통합한 편집적 구성

이러한 복합적 정보를 단일 인포그래픽으로 구성한 시각적 편집과 배치는 기존에 존재하지 않는 독창적 미술 표현이다.

**독창적 시각 표현 요소:**

- 우측: WiFi 위치추적→검증→Monte Carlo 시뮬레이션→포함→소방관 AI의 순차적 데이터 흐름을 표현
- 하단 슬로건: "단절된 정보를 하나로 연결하는 FireNavi 아키텍처는, 단순한 대피 안내를 넘어 초단위로 변화하는 재난 현장의 생존율을 극대화하는 유일한 솔루션입니다"
- 다크 테마 배경에 네온 글로우 효과를 적용한 기술적 심미성

이러한 3엔진 연동 관계, 외부 시스템 연결, 데이터 흐름을 하나의 다이어그램으로 구성한 시각적 표현은 기존에 존재하지 않는 독창적 도형 표현이다.

이러한 15페이지의 기술 프레젠테이션은 각 슬라이드의 시각 구성, 정보 배치, 그래픽 요소의 조합이 독창적 편집저작물에 해당하며, 전체를 하나의 스토리라인으로 구성한 서사적 편집 구조가 창작성의 핵심이다.

#### 3.6.4 FireNavi 브랜드 로고 (FireNavi_로고.png)

FireNavi 플랫폼의 정체성을 시각적으로 표현한 독창적 미술저작물이다.

**독창적 시각 표현 요소:**
- 방패(Shield) 형상을 기본 프레임으로 사용하여 "안전·보호"의 의미를 전달
- 방패 내부에 네비게이션 화살표(나침반 형상)를 배치하여 "경로 안내" 기능을 시각화
- 상단에 불꽃(Fire) 그래픽을 결합하여 "화재 대피"라는 기술 영역을 직관적으로 표현
- 불꽃 속에 위치 핀(Location Pin) 아이콘을 삽입하여 "위치추적" 기술을 암시
- 방패 표면에 격자(Grid) 패턴을 적용하여 "디지털·AI 기반 시스템"임을 표현
- "FireNavi" 텍스트의 "Fire"는 빨강(#CC0000), "Navi"는 남색(#1B3A6B)으로 색상 분리하여 화재(위험)와 네비게이션(해결)의 대비를 표현
- 전체적으로 방패+불꽃+나침반+위치핀+격자라는 5가지 시각 요소를 하나의 로고로 융합한 복합적 도안

이러한 복수의 상징적 요소를 하나의 로고 도안으로 융합한 시각적 표현은 기존에 존재하지 않는 독창적 미술 표현이며, 상표 등록과 별도로 미술저작물로서 저작권 보호 대상에 해당한다.

### 3.7 플랫폼 종합 자료의 독창적 편집

FireNavi 플랫폼의 사업 개요, 시장 분석, 기술 체계, 특허 전략, 수학 모델, 시스템 아키텍처를 하나의 종합 문서(929줄)로 체계화한 편집저작물이다.

**독창적 편집 표현 요소:**

- 5대 특허 기술, 3대 AI 엔진, 9개 수학 모델, 29개 방정식을 하나의 문서 체계로 통합한 편집적 구성

### 3.8 영상 시나리오의 독창적 창작

AI 챔피언 대회 출품용 3분 영상 시나리오(266줄)로, 대사(Script), 화면 구성(Shot), 편집 지시(Direction)가 포함된 각본 저작물이다.

**독창적 창작 표현 요소:**
- 4파트 구성: (1) 왜 만드는가(120초) → (2) 시연(30초) → (3) 팀 소개(60초) → (4) 비전+마무리(120초)
- 각 파트별 대사 전문, 화면 지시, 자막 텍스트, 타이밍 배분이 포함된 완결된 각본
- 기술적 내용(3대 AI 엔진, WiFi 위치추적, 취약계층 우선구조)을 비전문가도 이해할 수 있는 서사로 재구성한 독자적 표현
- "길을 안내하는 것이 아니라 생존을 설계합니다"라는 슬로건의 극적 활용
