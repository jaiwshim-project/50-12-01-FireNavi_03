## 2. 프로그램 내용 요약

AI 기반 실시간 화재 대피 경로 최적화 플랫폼. 크루즈선 및 대형 건물에서 화재 발생 시 3개 AI 엔진(Prediction, Behavior, Decision)이 동시 작동하여 6,000명의 생존을 실시간으로 결정한다. WiFi 실내 위치추적(정밀도 2~3m), 취약 계층 우선 구조(α=2.0), AI 출구 분산 최적화, 개인화 경로 배정, 이중 모드(Security+Safety) 등 15개 핵심 기능을 포함한다. 9개 수학 모델과 29개 방정식을 Canvas 2D 기반 인터랙티브 시뮬레이션으로 구현하였다.

## 3. 창작성 설명

본 프로그램은 다음과 같은 독창적 창작 요소를 포함하며, 기존에 존재하지 않는 고유한 소프트웨어 저작물이다.

### 3.1 9개 수학 모델의 독자적 통합 구현

기존에 개별적으로 연구되어 온 9개의 수학적 모델(Navier-Stokes 유체역학, Social Force 군중 모델, A* 경로탐색, LSTM 시계열 예측, Beer-Lambert 연기 확산, 열전달 방정식, 가시거리 감소 모델, 군중 밀도 모델, 구조적 내화 모델)을 하나의 실시간 시뮬레이션 엔진으로 통합 구현하였다. 이러한 다학제적 통합은 본 프로그램만의 독자적 창작물이다.

### 3.2 다중 위험 가중합 동적 리스크맵

실시간 위험도를 다차원적으로 계산하는 독자적 알고리즘을 개발하였다.

```
R(x, y, t) = w₁F + w₂S + w₃D + w₄C
```

여기서 F는 화재 위험도, S는 연기 위험도, D는 밀집도 위험도, C는 구조적 위험도를 의미하며, 각 가중치(w₁~w₄)는 상황에 따라 동적으로 조정된다. 이 리스크맵은 Canvas 2D 기반 히트맵으로 실시간 시각화된다.

### 3.3 취약 계층 우선 구조 AI

취약 계층(노약자, 장애인, 유아 동반자 등)에 대해 우선 구조 디바이스(Priority Rescue Device)를 할당하고, 연기 회피 배수 α=2.0을 적용하여 안전 경로를 최우선으로 배정하는 독자적 알고리즘을 구현하였다. 이는 단순 최단 경로가 아닌 생존 확률 극대화를 목표로 한다.

### 3.4 AI 출구 분산 최적화

특정 출구에 군중이 집중되는 현상을 방지하기 위해 독자적 군중 패널티(CrowdPenalty = N × 40) 알고리즘을 설계하였다. 각 출구의 현재 이용자 수(N)에 비례하는 패널티를 부과하여, AI가 자동으로 군중을 분산시키는 최적화를 수행한다.

### 3.5 개인화 AI 출구 배정

6개 승객 유형(일반 성인, 노약자, 장애인, 유아 동반, 승무원, VIP)별로 차별화된 경로 배정 로직을 구현하였다. 각 유형별 이동 속도, 위험 허용도, 우선순위가 상이하며, AI가 개인 특성을 고려한 최적 출구를 실시간으로 배정한다.

### 3.6 WiFi 디바이스 전략

객실 키카드 및 출입증에 WiFi 모듈을 내장하는 방식으로 실내 위치추적(2~3m 정밀도)을 구현하는 전략을 설계하였다. 별도의 앱 설치 없이 모든 탑승객의 실시간 위치를 파악할 수 있는 독자적 아키텍처이다.

### 3.7 이중 모드 플랫폼 (Security + Safety)

하나의 플랫폼이 평상시에는 보안 시스템(Security Mode)으로, 비상시에는 대피 시스템(Safety Mode)으로 자동 전환되는 이중 모드 아키텍처를 설계 및 구현하였다. 이러한 듀얼 모드 통합은 본 프로그램의 고유한 창작적 설계이다.

### 3.8 보안구역 침입 감지 시스템

WiFi 위치추적 데이터를 활용하여 제한 구역에 대한 비인가 접근을 실시간으로 감지하고 경고하는 시스템을 구현하였다. 대피 시스템과 보안 시스템을 하나의 인프라로 통합한 독자적 접근이다.

### 3.9 Canvas 2D 기반 실시간 물리 시뮬레이션 엔진

별도의 게임 엔진이나 물리 엔진 라이브러리 없이, 순수 JavaScript와 HTML5 Canvas 2D API만으로 화재 확산, 연기 이동, 군중 이동, 경로 탐색을 실시간으로 시뮬레이션하는 엔진을 자체 개발하였다. 외부 의존성 없는 독립적 구현이다.

## 7. 핵심 알고리즘 목록 (저작권 보호 대상)

본 프로그램에 포함된 핵심 알고리즘은 독창적 표현으로서 저작권 보호 대상에 해당한다.

### 7.1 기반 수학 모델 (9개)

| 번호 | 모델명 | 설명 |
|------|--------|------|
| M-1 | **Navier-Stokes 유체역학 모델** | 화재 시 연기 및 유독 가스의 유체적 확산을 시뮬레이션. 비압축성 유체 방정식을 2D 격자 기반으로 근사 |
| M-2 | **Social Force 군중 행동 모델** | Helbing의 사회적 힘 모델을 기반으로, 개인 간 반발력, 벽면 반발력, 목적지 흡인력을 통합하여 군중 이동 시뮬레이션 |
| M-3 | **A* 경로탐색 알고리즘** | MinHeap + Spatial Grid 최적화를 적용한 A* 경로탐색. 동적 장애물(화재, 연기) 회피 및 실시간 경로 재계산 |
| M-4 | **LSTM 시계열 예측 모델** | 화재 확산 패턴을 학습하여 향후 위험 구역을 사전 예측. 예방적 대피 경로 산출의 기반 |
| M-5 | **Beer-Lambert 연기 확산 모델** | 연기 농도에 따른 가시거리 감소를 정량화. 광학적 밀도와 소광 계수를 기반으로 실시간 가시거리 계산 |
| M-6 | **열전달 방정식 모델** | 복사, 대류, 전도를 통한 열에너지 전파를 시뮬레이션. 구역별 온도 변화를 실시간 추적 |
| M-7 | **가시거리 감소 모델** | 연기 확산에 따른 가시거리 변화를 모델링하여, 대피자의 이동 속도 감소 및 경로 선택에 반영 |
| M-8 | **군중 밀도 모델** | 단위 면적당 인원수를 기반으로 보행 속도, 병목 현상, 압사 위험을 계산. Fruin의 서비스 수준(LOS) 기준 적용 |
| M-9 | **구조적 내화 모델** | 건축 구조물의 내화 등급, 방화 구획, 구조적 붕괴 시점을 모델링하여 대피 가용 시간 산출 |

### 7.2 독자 AI 알고리즘 (3개)

| 번호 | 알고리즘명 | 설명 |
|------|-----------|------|
| A-1 | **Prediction Engine (예측 엔진)** | 화재 확산 패턴, 연기 이동 경로, 구조적 위험 시점을 LSTM 기반으로 예측하여 선제적 대피 경로를 산출하는 AI 엔진 |
| A-2 | **Behavior Engine (행동 엔진)** | 군중 행동 패턴(패닉, 군집화, 역류 등)을 Social Force 모델 기반으로 분석하고, 비정상 행동을 감지하여 개입하는 AI 엔진 |
| A-3 | **Decision Engine (의사결정 엔진)** | 다중 위험 가중합 리스크맵(R(x,y,t) = w₁F + w₂S + w₃D + w₄C)을 기반으로 개인별 최적 출구를 실시간 배정하고, 출구 분산 최적화(CrowdPenalty = N × 40)를 수행하는 AI 엔진 |

### 7.3 핵심 방정식 (29개)

본 프로그램에는 총 29개의 수학적 방정식이 소스코드로 구현되어 있으며, 이들의 조합과 통합 구현 방식이 본 프로그램의 핵심 창작적 표현에 해당한다. 주요 방정식은 다음과 같다:
