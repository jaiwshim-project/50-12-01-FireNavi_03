## 1. 플랫폼 개요

### 1-1. FireNavi란?

FireNavi(화이어내비)는 **크루즈선 및 대형 건물에서 AI 기반 실시간 생존 의사결정을 수행하는 플랫폼**이다. 3개 AI 엔진(Prediction, Behavior, Decision)이 동시에 작동하여 6,000명의 생존을 실시간으로 결정한다.

기존 대피 시스템이 정적 대피도와 방송 안내에 의존했다면, FireNavi는 **WiFi 실내 위치추적, 3개 AI 엔진 동시 가동, 취약 계층 우선 구조, 동적 위험도 맵, 이중 모드 플랫폼(Security+Safety)**을 통합하여 대피 시간을 55% 단축한다.

> **핵심 비전:** "AI + IoT + 시뮬레이션으로 크루즈선 화재 대피의 패러다임을 전환" — 실시간 센서 데이터와 AI 예측으로 모든 승객에게 최적 대피 경로를 제공

## 3. 모듈 A — 기술 공식화 (Technical Formulation)

### 3-1. 9대 수학적 모델

| # | 모델 | 분야 | 수식/방법 |
|---|------|------|----------|
| 1 | Social Force Model | 군집 밀도 | F_i = F_desire + Σ F_social + Σ F_wall + F_random |
| 2 | Kernel Density Estimation | 군집 밀도 | 2D 가우시안 커널, Silverman's bandwidth |
| 3 | LWR Conservation Model | 거시적 흐름 | ∂ρ/∂t + ∂(ρ·v(ρ))/∂x = 0 |
| 4 | Navier-Stokes 방정식 | 연기 확산 | 운동량 보존 방정식 |
| 5 | Advection-Diffusion 방정식 | 연기 농도 | 이류-확산 모델 |
| 6 | LSTM 신경망 | 실시간 예측 | 시계열 연기 확산 예측 |
| 7 | Beer-Lambert 가시도 모델 | 가시도 | V(C) = K/C |
| 8 | A* / Dijkstra 경로 탐색 | 대피 경로 | 최단 경로 알고리즘 |
| 9 | Monte Carlo 시뮬레이션 | 보험 리스크 | 10만+ 반복 확률 시뮬레이션 |

### 3-2. 군집 밀도 예측

| 항목 | 내용 |
|------|------|
| 기본 속도 모델 | Greenshields: v(ρ) = v_max × (1 - ρ/ρ_max) |
| 정상 상태 v_max | 1.34 m/s |
| 패닉 상태 v_max | 1.78 m/s |
| 최대 밀도 ρ_max | 5.4 인/m² (정상), 6.2 인/m² (패닉) |

### 3-3. 연기 확산 예측 비교

| 방법 | 정확도 | 처리 시간 | 용도 |
|------|--------|----------|------|
| Full CFD (OpenFOAM) | 매우 높음 | 수 시간 | 사전 시뮬레이션 |
| Zone Model | 중간 | 수 초 | 실시간 근사 |
| LSTM 신경망 | 높음 | 밀리초 | 실시간 예측 |
| Hybrid (추천) | 높음 | 수 초 | 실시간 + 정밀 예측 |

### 3-4. 동적 리스크맵 생성

다중 위험 가중치 합산 공식:

```
R(x,y,t) = w₁·F(x,y,t) + w₂·S(x,y,t) + w₃·D(x,y,t) + w₄·C(x,y,t)
```

| 위험 요소 | 변수 | 기본 가중치 |
|-----------|------|------------|
| 화재 (Fire) | F | w₁ = 0.35 |
| 연기 (Smoke) | S | w₂ = 0.25 |
| 구조 (Structural) | D | w₃ = 0.20 |
| 군집 (Crowd) | C | w₄ = 0.12 |
| 기상 (Weather) | — | w₅ = 0.08 |

### 3-5. 건강 상태 인식 경로

### 7-2. 동적 리스크맵 (risk-map.html)

**실시간 위험도 히트맵 시각화**

**사이드바 컨트롤:**
- 4가지 위험 요소 가중치 슬라이더 (Fire, Smoke, Structural, Crowd)
- 가중치 정규화 옵션
- 데크 선택 (5~9층)
- 현재 공식 실시간 표시

**캔버스 영역:**
- 히트맵 시각화 (파랑→초록→노랑→주황→빨강 그라디언트)
- 0~100% 위험도 스케일
- 타임라인 슬라이더 (프레임별 재생)
- 재생/일시정지 애니메이션

**통계 섹션:**
- 위험 구역 수, 영향 면적, 평균 위험도, 최대 위험도
- 위험도 분포 히스토그램 (5단계)
- 트렌드 표시 (증가/감소/안정)
- 대피 경로 하이라이팅

### 7-3. 경로 최적화 (route-optimizer.html)

**다중 에이전트 개인화 대피 경로 계산**

**승객 패널 (사이드바):**
- 개별 승객 프로필 카드
- 이름, 나이, 건강 상태, 이동 능력 (0~100%)
- 특수 필요 태그 (휠체어, 고령자, 어린이, 부상)
- 클릭 시 개별 경로 하이라이트

**컨트롤 패널:**
- 화재 위치 설정 모드
- 최적화 실행 버튼
- 전체 경로 표시 (다중 에이전트 뷰)
- 혼잡 패널티 슬라이더 (0~1, 기본 0.50)
- 위험 패널티 슬라이더 (0~1, 기본 0.70)
- 휠체어 전용 필터
- 충돌 최소화 체크박스

**경로 유형 3가지:**

| 유형 | 알고리즘 | 특징 |
|------|---------|------|
| Standard Route | A*/Dijkstra | 거리 기반 최단 경로 |
| Health-Aware Route | 이동 계수 적용 | 건강 상태별 속도 조정 |
| AI Optimized Route | 강화학습 정책 | 혼잡·연기·충돌 종합 최적화 |

**비교 통계:** 3가지 경로 유형별 거리, 시간, 위험도, 충돌 횟수 비교 차트

### 18-8. AI 출구 분산 최적화 (Exit Crowd Balancing)

기존 대피 시스템은 모든 승객에게 가장 가까운 출구만 안내하여 특정 출구에 병목이 발생했다.
FireNavi는 각 출구의 실시간 배정 인원을 추적하여 혼잡도 패널티를 부과한다.

```
Score(exit) = Distance + FirePenalty×α + SmokePenalty×α + CrowdPenalty
CrowdPenalty = N_assigned × 40
```

| 항목 | 설명 |
|------|------|
| N_assigned | 해당 출구에 현재 배정된 승객 수 |
| 패널티 계수 | 1명당 40 추가 비용 |
| 효과 | 승객이 자연스럽게 여러 출구/계단으로 분산 |

### 18-9. 취약 계층 우선 경로 AI (Priority Rescue Routing)

취약 계층(고령자, 장애인, 어린이, 임산부, 부상자)과 동반 보호자에게는 화재/연기 패널티가 2배(α=2.0)로 적용된다.

```
Score_priority(exit) = Distance + FirePenalty × α + SmokePenalty × α + CrowdPenalty
α = 2.0 (우선구조), α = 1.0 (일반)
```

| 경로 유형 | 대상 | 연기 패널티 | 출구 선택 기준 |
|----------|------|-----------|-------------|
| Standard Route | 건강한 성인 | 1.0x | 거리 우선 |
| Priority Route | 취약 계층 + 보호자 | 2.0x | 안전 우선 |

### 18-10. 개인화 AI 출구 배정 (Personalized Exit Assignment)

```
findNearestSafeExit(x, y, passenger)
```

승객 개인의 건강 상태, 이동 능력, 유형 정보를 입력받아 각 개인에게 최적화된 출구를 배정한다.
같은 위치에 있더라도 건강한 성인과 휠체어 사용자는 서로 다른 출구를 안내받을 수 있다.

**AI 출구 배정 5단계 의사결정:**
1. 모든 출구/계단의 안전 여부 판정 (화재 내부 제외)
2. 승객~출구 거리 계산 + 근접 보너스 (50px/100px)
3. 출구 주변 화재/연기 패널티 산정 (× α)
4. 경로상 화재 장애물 체크 (직선 샘플링)
5. 출구별 혼잡도 패널티 + 유형별 가중치 합산 → 최저 스코어 출구 배정

### 18-11. 유형별 컬러 경로 시각화

대피 중 각 승객 유형별로 구분된 색상과 대시 패턴으로 경로를 시각화한다.

| 유형 | 색상 | 선 두께 | 대시 패턴 | 라벨 |
|------|------|--------|----------|------|
| 건강한 성인 | #4A90D9 (파랑) | 1.5px | 실선 | - |
| 고령자 | #F59E0B (주황) | 2.0px | [6,3] | 고령 |
| 어린이 | #8B5CF6 (보라) | 2.0px | [4,2] | 아동 |
| 휠체어 | #EC4899 (핑크) | 2.5px | [8,4] | 휠체어 |
| 임산부 | #14B8A6 (청록) | 2.0px | [5,3] | 임산 |
| 부상자 | #EF4444 (빨강) | 2.5px | [3,3] | 부상 |
